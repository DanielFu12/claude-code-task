# M03《不当行业第一，也能做成好生意吗？》· 生态位理论（竖屏版）

《50个自然法则，看懂商业世界》第 03 期。本期话题：**需求定位 / 差异化 / 经营取舍**。

- 成片：`M03_不当行业第一也能做成好生意吗_生态位_竖屏.mp4`（**1080×1920 竖屏** · 30fps · 3:31 · 无人声，字幕叙事）
- 针对“评论说字太小”专门做成竖屏，适合手机全屏观看：
  - 字幕 56–62 px，大字 76–104 px，约为横屏版的 1.3–2 倍；每行不超过约 13 个字。
  - 画面主体放在上中部（约 y 250–1100），字幕在中下部（约 y 1250）。底部约 25% 和右侧留空，避开视频号/抖音的按钮和文案区。
  - 章节标签在左上角，进度线在它下方；右上角是 `brand.Hud(frame_w=1080)` 画的官方角标（BRAND.md 边距 52/30，1080 宽度下 scale=1）。
- 配乐与音效全部为原创合成（`src/music.py`），没有外部采样：
  - 配乐：112.5 BPM、F 小调，节奏比前两期更紧凑。**1 拍 = 0.5333 s = 正好 16 帧**，每个拍点和转场都落在整数帧上。
  - 转场音效只用 sub drop、低频 boom、低沉膨胀和闷击。全部经过 4 阶 180 Hz 低通，实测 **99.99% 的能量在 200 Hz 以下**。不用白噪声、whoosh 或尖锐的上升音。
  - 每个音效都按所在位置的音乐响度自动压低，至少比音乐低 4 dB，起音对准转场那一帧。
  - 混音：整片约 −13.8 LUFS，峰值 −1 dBFS。慢速电平器把安静段托起来，保留「安静段 → 高潮」的起伏。

## 事实、出处与制作约束

| 内容 | 出处 / 处理方式 |
|---|---|
| 生态位包括资源使用、环境需求和物种相互作用，不只是地理位置；资源分割 | 素材《01 生态位理论事实核查》；OpenStax Biology 2e §45.6 |
| 基本生态位与实际生态位不应混同；差异化不保证需求充足或获利 | 素材核查卡“主要限制” |
| 森林里不同树层取食的鸟 | 核查卡指定的示意图演示，画面标注“示意图 · 非实测数据”，不用虚构物种数据 |
| 「战略的本质，是选择不做什么。」 | Michael E. Porter, “What Is Strategy?”, *Harvard Business Review*, 1996（“The essence of strategy is choosing what not to do.”） |
| 工业零件公司 | **假设情景**。核查卡写明 Costco 与山姆仍是待核候选，公司故事必须先补原始公告、口径、时间线和因果证据，不足时改用标注“假设”的教学情景 |
| 社区小店 | 标注“示意”的身边映射，不涉及具体公司或数据 |
| 巴菲特、芒格引语 / 企业财务数字 | 核查卡写明“本卡不使用”，本片遵守 |

结尾按投资研究视角落到研究问题（服务谁、怎样交付、放弃了什么），不给买卖建议。
