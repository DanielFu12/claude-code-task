# 科学思维 · 4 分 54 秒科普短片

- 成片：`科学思维.mp4`（1920×1080 · 30 fps · 4:54 · H.264 + AAC）
- 旁白：中文男声，离线神经网络语音合成（Kokoro v1.1-zh，经 sherpa-onnx 运行），每句合成后用 SenseVoice 语音识别回听校对；最终混音后整片识别字错率约 4%，与纯人声几乎相同，说明配乐没有盖住旁白。
- 配乐：原创，`src/music.py` 在 numpy 里逐音符合成（D 小调，100 BPM，结尾落在 D 大调）。每个章节在重拍上开始，重拍前 0.3 秒抽空；硬币每淘汰一天、黑天鹅推翻命题、四道检验门亮起、诺贝尔奖等画面事件都有对应音效。旁白出现时音乐自动压低，响度标准化到 −14 LUFS。
- 字幕：全程中文字幕（手机静音也能看懂），「」里的关键词用品牌金色高亮；全片最小字号 22 px。
- 品牌：右上角全程是 `brand.Hud` 画的官方角标（logo + 金色「巴芒价值」+「BUFFETT · MUNGER」，约每 7.5 秒扫一次流光）。片尾不隐藏，只随整片最终淡出。
- 片尾：终句「真相，从不害怕被检验」化作 7000 颗粒子，以官方 `brand/logo_baman.png` 的透明通道为遮罩汇聚成 logo → 原始 logo 清晰浮现（在辉光、调色之后单独合成，颜色不被改动）→ 金色「巴芒价值」在重拍上划入、「BUFFETT · MUNGER」两端对齐到与主标题等宽 → 扫过一次流光 → 淡出。logo 用 `brand.load_logo`，字体用 `brand._font`（思源宋体 Black / Cormorant Garamond），金色用 `brand.GOLD_STOPS` / `brand.SUB_GOLD`，均从 `brand/` 读取。

## 事实与出处

- **棋盘阴影错觉**：按 Edward Adelson（1995）的构造原理自行重绘。亮格反射率 0.82、暗格 0.47、阴影系数 0.47 / 0.82，所以阴影里的亮格与光照下的暗格像素值完全相同（RGB 122）。这一段关闭了辉光和暗角，保证两格像素严格相等。
- **华盛顿之死**（1799 年 12 月 14 日）：一天之内被放血四次，合计约 80 盎司（约 2.4 升），常见估计约为全身血量的 40%（画面按约 6 升估算，并注明）。
- **放血疗法**：从希波克拉底医派、盖伦一直沿用到 19 世纪。1835 年皮埃尔·路易用分组计数的「数值方法」质疑了它的疗效。画面里两组 100 人的康复率是示意数据（已标注）。
- **相关与因果**：消防员散点图、随机对照实验的数据是示意（已标注）。
- **黑天鹅**：1697 年荷兰探险家威廉·德·弗拉明的船队在澳大利亚西部首次记录黑天鹅；波普尔《科学发现的逻辑》（1934）提出可证伪性。
- **1919 年日食**：广义相对论预言太阳边缘的星光偏折 1.75″，牛顿式计算为 0.87″；戴森、爱丁顿、戴维森 1920 年报告索布拉尔 1.98″ ± 0.12″、普林西比 1.61″ ± 0.30″。图中的偏折角度已放大示意。
- **福勒实验**（1948）：39 名学生，同一段性格描述（大多摘自一本星座书），0–5 分平均 4.26。画面上的评分分布为示意，均值是原始结果；卡片上的句子节选自福勒原文的中文意译。
- **MBTI**：重测信度研究（如 Pittenger 1993）发现相隔数周重测，常有近半数人类型改变；**平行宇宙**按参考材料的口径处理为「目前无法检验，暂不算科学」。
- **马歇尔与沃伦**：1984 年马歇尔喝下幽门螺杆菌培养液，约一周后出现胃炎；2005 年两人获诺贝尔生理学或医学奖。
- **光速测量**：罗默 / 惠更斯 1676 约 220,000 km/s；布拉德雷 1729 约 301,000；斐索 1849 约 315,000；傅科 1862 约 298,000；迈克耳孙 1879 299,910、1926 299,796；埃森 1950 299,792.5；1972 激光测量 299,792.4562；1983 年定义为 299,792.458。
- **费曼**：1974 年加州理工毕业典礼演讲《草包族科学》。
- **抛硬币大赛**：巴菲特 1984 年哥伦比亚大学演讲《格雷厄姆-多德村的超级投资者》：2.25 亿人，10 天后约 22 万人，20 天后约 215 人（2.25 亿 ÷ 2²⁰ ≈ 215）。
- **达尔文的黄金法则**：出自《达尔文自传》；芒格在 1986 年哈佛-西湖中学演讲等场合推崇这一习惯。
- **喜诗糖果**：巴菲特 2007 年致股东信——1972 年以 2,500 万美元收购；2007 年税前利润 8,200 万美元；1972–2007 年累计税前利润 13.5 亿美元。价格台阶线是示意图（已标注）。
- **芒格**：「像我们这样的人，通过始终努力不做蠢事、而不是努力变得非常聪明，获得了多么大的长期优势」，出自 1989 年 Wesco 年报中芒格的致股东信（画面注明为大意）。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、python3：numpy scipy opencv-python-headless pillow soundfile pyloudnorm librosa skia-python sherpa-onnx
```

- `src/script.py`：唯一的文字来源（旁白、字幕）。
- `src/timeline.py`：由每句配音时长推出全部时间点；画面、字幕、配乐共用。`T.at(句子, 子串)` 估算某个词念出的时刻，用来让画面对上旁白里的具体词。
- `src/tts.py`：逐句配音 + 语音识别回听。
- `src/music.py`：配乐合成、音效点与混音。
- `src/engine.py`：小型动态图形引擎（skia 矢量绘制、逐字显现、粒子、辉光、暗角、颗粒、色差）。
- `src/scenes_a.py` / `scenes_b.py` / `scenes_c.py`：全部分镜；`src/outro.py`：片尾 logo 动画。
- `python3 src/video.py preview 12.5 101 288` 可以导出单帧；`python3 src/video.py clip 280 294 out.mp4` 渲染一段。
