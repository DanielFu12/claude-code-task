# 科学思维 · 4 分 45 秒卡点科普短片

- 成片：`科学思维.mp4`（1920×1080 · 30 fps · 4:45 · H.264 + AAC）
- **一条主线：你的「幸运数字 8」**。第一次买股票挑了代码带 8 的，涨了；第二、三次还挑 8，又涨了——从此你信了 8。全片用科学的每一件工具，把这个迷信一层层拆开，最后问观众：**你的「8」是什么？**
- **没有配音**：旁白以屏幕文字呈现——各段的大字在拍点上砸下，底部是旁白字幕（46 px，「」里的关键词用品牌金色高亮），每块字幕都在拍点上弹出。

## 卡点

- **配乐**：以仓库根目录的 `opus5.5涌现.mp4` 原曲为底（`CLAUDE.md`：根目录 mp4 是背景音乐来源）。原曲实测 112.9 BPM，拍点与固定网格的中位偏差约 3 ms，4 小节一个和声循环。`src/music.py` 按 `timeline.MUSIC_MAP` 把原曲按小节重新编排成整片长度（采样级对齐，拼接都落在和声循环起点）：前奏给钩子，第一次 drop 给「幸运数字」，间奏给「亏钱、找借口」，回升给「星光偏了」，drop 再次进入给「回到股市」，原曲的最后一个和弦留给品牌字。
- 画面、字幕、配乐共用 `src/timeline.py` 的同一张节拍网格：每句按阅读时长占若干拍、从拍点开始；每章从小节线开始。
- **每个镜头切换都落在拍点上**（硬切，0.07 s 入、0.1 s 出），切入时镜头从 1.06–1.10 倍弹回；大字在拍点上从 1.5 倍砸下，带残影与粒子迸发。
- 每章第一拍是重拍：配乐在重拍前 0.27 s 整体抽空，画面同步加速推进、变焦模糊、压暗；重拍上一记原创合成的冲击音效，画面闪白、冲击波、色差。
- 39 个段落重音（涨停章、+30%、「市场」、「牛市」、「≠」、「偏了」、四道门、诺贝尔奖、第 20 天的 215 人、五步法……）都吸附在拍点上，配乐叠一记低频「咚」，镜头轻推、微震。
- 节拍内的运动也锁在网格上：K 线每个十六分音符长一根；鸽子转圈每拍翻一次身，食物在小节线上落地；硬币每个八分音符淘汰一半；「市场」箱子每半拍掉下一根 K 线；背景与曝光随底鼓脉冲（`work/pulse.npy`，取自最终混音的低频起音）呼吸。
- 用起音检测验证：配乐中 99% 的起音落在十六分音符网格 25 ms 以内。响度 −14.5 LUFS，4 倍过采样真峰值限幅；成片 AAC 256 kbps。

## 事实与出处

- **幸运数字 8 的故事**是虚构的情景；其中的走势、涨跌幅、代码均为示意。
- **斯金纳的鸽子**：B. F. Skinner, “‘Superstition’ in the pigeon”, *Journal of Experimental Psychology* 38 (1948)。饿鸽子每天在箱中待几分钟，食物每 15 秒自动送出、与行为无关；8 只中有 6 只形成了固定动作：逆时针转两三圈、把头伸向箱子上方的一个角、钟摆式晃头等。画面中的投食间隔压缩到一小节。
- **A 股的幸运数字**：Hirshleifer, Jian & Zhang, “Superstition and Financial Decision Making”, *Management Science* 64(1), 2018：中国股市上市代码中吉利数字出现得比随机更频繁；带吉利数字的新股上市时估值溢价更高，之后跑输，溢价在三年内消失。画面中的曲线是示意（已标注）。
- **牛市、对照组**：带 8 与不带 8 的同期涨幅（+31% / +30%）是示意（已标注），用来说明对照的思路。
- **随机对照实验**：画面里的分组与好转比例是示意（已标注）。
- **1919 年日食**：广义相对论预言太阳边缘的星光偏折 1.75″，牛顿式计算为 0.87″；戴森、爱丁顿、戴维森 1920 年报告索布拉尔 1.98″ ± 0.12″、普林西比 1.61″ ± 0.30″。图中的偏折角度已放大示意。
- **MBTI**：重测信度研究（如 Pittenger 1993）发现相隔数周重测，常有近半数人类型改变。
- **马歇尔与沃伦**：1984 年马歇尔喝下幽门螺杆菌培养液，几天后出现症状、胃镜证实胃炎；2005 年两人获诺贝尔生理学或医学奖。
- **光速测量**：罗默 / 惠更斯 1676 约 220,000 km/s；布拉德雷 1729 约 301,000；斐索 1849 约 315,000；傅科 1862 约 298,000；迈克耳孙 1879 299,910、1926 299,796；埃森 1950 299,792.5；1972 激光测量 299,792.4562；1983 年定义为 299,792.458。
- **费曼**：1974 年加州理工毕业典礼演讲《草包族科学》。
- **抛硬币**：巴菲特 1984 年演讲《格雷厄姆-多德村的超级投资者》：2.25 亿人，20 天后约 215 人（2.25 亿 ÷ 2²⁰ ≈ 215）；若许多赢家来自同一个「村庄」，就值得研究原因。
- **三连胜 = 1/8**：假设每笔涨跌各半，三笔全涨的概率是 (½)³ = 1/8；A 股投资者账户数已超过 2 亿。
- **达尔文的黄金法则**：《达尔文自传》——与自己结论相反的事实，要立刻记下，因为它们比有利的事实更容易被忘记。
- **喜诗糖果**：巴菲特 2007 年致股东信——1972 年以 2,500 万美元收购；2007 年税前利润 8,200 万美元；1972–2007 年累计税前利润 13.5 亿美元。价格台阶线是示意图（已标注）。
- **芒格**：「像我们这样的人，通过始终努力不做蠢事、而不是努力变得非常聪明，获得了多么大的长期优势」（画面注明为大意）。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、python3：numpy scipy opencv-python-headless pillow soundfile pyloudnorm skia-python
```

- `src/script.py`：唯一的文字来源（屏幕旁白）。
- `src/timeline.py`：节拍网格（112.9 BPM）、每章的小节数与原曲小节编排（`MUSIC_MAP`）、全部时间点；`T.at(句子, 子串)` 给出句中某个词出现的拍点，`T.ACCENTS` 是配乐与镜头共用的重音表。
- `src/music.py`：按小节重新编排原曲、重拍抽空与冲击音效、重音打击、响度与真峰值；导出 `work/pulse.npy`。
- `src/engine.py`：小型动态图形引擎（skia 矢量绘制、砸入式大字、金色立体 8、K 线、鸽子、粒子迸发、景深光斑、辉光、变焦模糊、暗角、颗粒、色差）。
- `src/scenes_a.py` / `scenes_b.py` / `scenes_c.py`：全部分镜；`src/outro.py`：片尾 logo 动画；`src/video.py`：合成、字幕、转场。
- `python3 src/video.py preview 8.2 101 266` 导出单帧；`python3 src/video.py clip 0 12 out.mp4` 渲染一段。
