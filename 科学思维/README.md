## 事实与出处

- **瓦尔德与返航战机**：亚伯拉罕·瓦尔德 1943 年起在哥伦比亚大学统计研究小组（SRG）为美军工作，写过一组报告，讨论如何只用返航飞机的损伤来推断各部位的易损性——没飞回来的飞机恰恰是关键信息。流传最广的版本（「把装甲加在没有弹孔的地方，比如发动机」）是对这项工作的普及化简化；画面里的弹孔分布、战机造型都是原创示意图（已标注）。
- **冰淇淋与溺水**：统计学里讲混杂因素最常用的例子；画面中的月度数据是示意（已标注），用来说明两者同受气温驱动。
- **保健品与随机对照实验**：「感觉好多了」可能来自自然好转、安慰剂效应或生活方式变化；随机分组 + 外观一样的安慰剂才能把它们分开。画面里的分组比例与改善率是示意（已标注）。
- **黑天鹅**：1697 年荷兰探险家威廉·德·弗拉明的船队在澳大利亚西部首次记录黑天鹅；波普尔《科学发现的逻辑》（1934）提出可证伪性。
- **1919 年日食**：广义相对论预言太阳边缘的星光偏折 1.75″，牛顿式计算为 0.87″；戴森、爱丁顿、戴维森 1920 年报告索布拉尔 1.98″ ± 0.12″、普林西比 1.61″ ± 0.30″。图中的偏折角度已放大示意。
- **福勒实验**（1948）：39 名学生，同一段性格描述（大多摘自一本星座书），0–5 分平均 4.26。画面上的评分分布为示意，均值是原始结果；卡片上的句子节选自福勒原文的中文意译。
- **MBTI**：重测信度研究（如 Pittenger 1993）发现相隔数周重测，常有近半数人类型改变；**平行宇宙**按参考材料的口径处理为「目前无法检验，暂不算科学」。
- **马歇尔与沃伦**：1984 年马歇尔喝下幽门螺杆菌培养液，约一周后出现胃炎；2005 年两人获诺贝尔生理学或医学奖。
- **光速测量**：罗默 / 惠更斯 1676 约 220,000 km/s；布拉德雷 1729 约 301,000；斐索 1849 约 315,000；傅科 1862 约 298,000；迈克耳孙 1879 299,910、1926 299,796；埃森 1950 299,792.5；1972 激光测量 299,792.4562；1983 年定义为 299,792.458。
- **费曼**：1974 年加州理工毕业典礼演讲《草包族科学》。
- **抛硬币大赛**：巴菲特 1984 年哥伦比亚大学演讲《格雷厄姆-多德村的超级投资者》：2.25 亿人，10 天后约 22 万人，20 天后约 215 人（2.25 亿 ÷ 2²⁰ ≈ 215）。
- **达尔文的黄金法则**：出自《达尔文自传》；芒格在 1986 年哈佛-西湖中学演讲等场合推崇这一习惯。
- **喜诗糖果**：巴菲特 2007 年致股东信——1972 年以 2,500 万美元收购；2007 年税前利润 8,200 万美元；1972–2007 年累计税前利润 13.5 亿美元。价格台阶线是示意图（已标注）。
- **芒格**：「像我们这样的人，通过始终努力不做蠢事、而不是努力变得非常聪明，获得了多么大的长期优势」，出自 1989 年 Wesco 年报中芒格的致股东信（画面注明为大意）。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、python3：numpy scipy opencv-python-headless pillow soundfile pyloudnorm skia-python
```

- `src/script.py`：唯一的文字来源（屏幕旁白）。
- `src/timeline.py`：节拍网格（100 BPM）与全部时间点；`T.at(句子, 子串)` 给出句中某个词出现的拍点，`T.ACCENTS` 是配乐与镜头共用的重音表。
- `src/music.py`：配乐合成、重拍 / 重音打击、侧链与混音。
- `src/engine.py`：小型动态图形引擎（skia 矢量绘制、逐字显现、粒子、辉光、暗角、颗粒、色差）。
- `src/scenes_a.py` / `scenes_b.py` / `scenes_c.py`：全部分镜；`src/outro.py`：片尾 logo 动画；`src/video.py`：合成、字幕、转场（重拍前推入黑场、重拍闪白与冲击波、重音轻推）。
- `python3 src/video.py preview 8.2 101 266` 可以导出单帧；`python3 src/video.py clip 0 12 out.mp4` 渲染一段。
