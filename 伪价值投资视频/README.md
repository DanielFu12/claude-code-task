# 伪价值投资 · 竖屏短视频

- 成片：`伪价值投资.mp4`（1080×1920 · 30fps · 约 4 分 22 秒）。仓库的 Git LFS 额度已满，成片没有入库，需运行 `./build.sh` 生成。
- 脚本：`脚本.md`（V6 定稿，含逐句画面、事实核查表）。
- 旁白：火山引擎 Seed-TTS 2.0（沉稳男声），每句单独合成，按「内心独白 / 芒格的提问 / 陪伴式复盘」分别给语气提示。
- 配乐：原创 MIDI 编曲（`src/music.py`），用 fluidsynth + FluidR3_GM 的真实乐器音色分轨渲染（钢琴、弦乐、大提琴、低音提琴、合唱、圆号、定音鼓、太鼓），叠加 numpy 合成的重击、上升音、铁砧声和磁带倒卷声。有人声时配乐压低约 7dB，母带压缩，高频低通。
- 品牌：右上角是 `brand/` 的「巴芒价值」角标（含流光）；片尾是大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、fluidsynth、fluid-soundfont-gm，以及 python3（numpy scipy opencv-python-headless pillow soundfile librosa mido）
```

各个文件的作用：

- `src/script.py`：旁白稿，与 `脚本.md` 一致。
- `src/timeline.py`：把旁白排到 80BPM 节拍网格上；数字揭晓、三记锤击等「揭晓点」会反推台词起点，落在整拍上，三锤严格间隔一小节。`cues` 字段供配乐和画面共用。
- `src/music.py`：编曲、渲染和混音。
- `src/video.py`：全部分镜。
- `src/engine.py`：渲染引擎（加色光、辉光、贴图层、横向光晕）。
