# 伪价值投资 · 竖屏短视频

- 成片：`伪价值投资.mp4`（1080×1920 · 30fps · 约 2 分 52 秒）。仓库的 Git LFS 额度已满，成片没有入库，需运行 `./build.sh` 生成。
- 旁白：火山引擎 Seed-TTS 2.0（沉稳男声），每句单独合成，并附有语气提示。
- 配乐：原创，用 numpy/scipy 合成（`src/music.py`），D 小调、80 BPM。所有台词、转场和重击都吸附在这个节拍网格上；有人声时配乐自动压低约 7dB；全程做了低通，没有刺耳的高频音效。
- 品牌：右上角是 `brand/` 的「巴芒价值」角标（含流光）；片尾是大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」。

## 重新生成

```bash
./build.sh
```

各个文件的作用：

- `src/script.py`：旁白稿，包括配音文本、字幕文本和语气提示。
- `src/timeline.py`：把旁白排到节拍网格上，并检测句内停顿，用来切分字幕；`cues` 记录每个数字揭晓的时刻，配乐重击和画面落点共用。
- `src/music.py`：配乐和音效。
- `src/video.py`：全部分镜。
- `src/engine.py`：加色光 + 辉光渲染引擎（竖屏版）。
