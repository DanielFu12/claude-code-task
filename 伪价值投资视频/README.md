# 好公司，为什么还会亏？ · 竖屏长视频

- 成片：`好公司为什么还会亏.mp4`（1080×1920 · 30fps · 约 9 分 50 秒）。仓库的 Git LFS 额度已满，成片没有入库，需运行 `./build.sh` 生成。
- 脚本：`脚本.md`（V10：95 句全部保留，口语短句；逐句审校语病与逻辑，见文末「V10 审校」表；含逐段画面、事实核查表）。
- 旁白：火山引擎 Seed-TTS 2.0（沉稳男声），**整篇一次合成，一条录完**，全片没有拼接缝。长文本合成会越讲越高（实测首尾差约 3.7 个半音），用 Praat PSOLA 只拉平缓慢的音高趋势、保留逐句抑扬（每分钟音高中位 124–129 Hz）。用逐句参考音频做逐句推进的子序列 DTW 找句界、在停顿正中切开，97 句逐一校验。第三章（价值投资的本质）放慢 1.2 倍、句间多留停顿。只在章节卡和小节转场处插入停顿。`src/voice_check.py` 逐句报告音高、响度、亮度和语速。
- 配乐：原创 MIDI 编曲（`src/music.py`），fluidsynth + FluidR3_GM 真实乐器分轨渲染，按章节换织体：序章钢琴叹息与琶音 → 片名全奏 → 问题一弦乐律动 / 降 B 大调反思 / 时代故事的壮阔转入周期的暗涌 → 铁锤三锤卡点后抽空 → 问题二钢琴独奏慢慢回暖 → 问题三 F 大调全奏、圆号唱主题 → 尾声钢琴。数字揭晓、三锤、金句、章节卡都对齐整拍；有旁白时配乐全频压低 12 dB、人声频段再让 5 dB（实测旁白比配乐高约 15 LU），句缝不放开；闪避放在最终混音、压缩之后，响度用线性增益 + 限幅到 -14 LUFS。
- 品牌：右上角是 `brand/` 的「巴芒价值」角标（含流光）；片尾是大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」，下方浮现关注语「关注「巴芒价值」，传承大师智慧，领悟投资真谛」。

## 章节

- 序章 · 好公司也亏钱：雪球热帖里的五笔交易
- 第一章 · 好公司≠好投资（为什么买了好公司，还可能亏钱？）：价格与价值 → 护城河与能力圈 → 时代、周期与预期 → 铁锤人与反过来想
- 第二章 · 下跌≠买错（股价下跌，就说明当初买错了吗？）
- 第三章 · 价值投资的本质（真正的价值投资，究竟是什么？）
- 尾声 · 回到原点

全片思想：好公司，不一定是好投资；好投资，也不一定立刻带来好回报；真正的价值投资，是在不确定的世界里，尽可能作出有利于长期回报的决策。

## 版式（防重叠）

竖屏分成固定区域：顶栏（章节条与品牌角标同一行：好公司也亏钱 / 好公司≠好投资 / 下跌≠买错 / 价值投资的本质 / 回到原点，当前章节高亮并随进度填满）→ 标签区 → 标题区（金句、引文、问题）→ 主视觉区（图表与动画）→ 注脚区（口径、出处）→ 字幕区。每个元素只出现在自己的区域；镜头之间先淡出、再淡入，不交叠；超宽的大字会自动缩小字号。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、fluidsynth、fluid-soundfont-gm，以及 python3（numpy scipy opencv-python-headless pillow soundfile librosa mido praat-parselmouth pyloudnorm）
```

- `src/gen_script.py`：从 `脚本.md` 解析旁白，生成 `src/script.py`（配音文本 + 自动分屏的字幕）。
- `src/tts_all.py`：逐句合成参考音频（`work/vo_ref`，只用于对齐与校验）。
- `src/tts_take.py`：整篇一次合成 → 拉平音高漂移 → 逐句对齐切句（校验）→ 第三章放慢。
- `src/voice_check.py`：旁白自检。
- `src/timeline.py`：80BPM 节拍网格。同一段里的句子首尾相接，不插入人为停顿；数字揭晓只在原有停顿里挪动（≤0.19 秒）对齐半拍，金句前多留半口气，三锤按半小节间隔；章节卡与段首对齐小节。`cues` 供配乐与画面共用。
- `src/music.py`：编曲、渲染。
- `src/mix.py`：旁白粘合、配乐闪避、响度。
- `src/video.py`：全部镜头（`SHOTS` 列表按时间顺序排列）。
- `src/engine.py`：渲染引擎。
