# 伪价值投资 · 竖屏短视频

- 成片：`伪价值投资.mp4`（1080×1920 · 30fps · 约 3 分 21 秒）。仓库的 Git LFS 额度已满，成片没有入库，需运行 `./build.sh` 生成。
- 旁白：火山引擎 Seed-TTS 2.0（沉稳男声），每句单独合成，并附有语气提示。
- 配乐：原创 MIDI 编曲（`src/music.py`），用 fluidsynth + FluidR3_GM 的真实乐器音色分轨渲染，乐器包括钢琴、弦乐、大提琴、低音提琴、合唱、圆号、定音鼓和太鼓。重击、上升音、铁砧声用 numpy 合成后叠加，有人声时配乐自动压低约 7dB，母带做了压缩，高频全程低通。
- 品牌：右上角是 `brand/` 的「巴芒价值」角标（含流光）；片尾是大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」。

## 核心观点

很多人以为自己在做巴菲特、芒格式的价值投资，其实只是拿着一套公式（好公司、好价格、护城河、现金流、回购）满世界敲钉子，从没真正看懂那门生意。芒格反复讲的不是公式，而是**能力圈**和**反过来想**。

## 叙事结构（四幕）

| 时间 | 段落 | 内容 |
|---|---|---|
| 0:00 | 冷开场 | 「等到回调，买最好的公司。八年后，股价还在成本线下。」 |

| 1:47 | 第三幕 · 拔钉子 | ① 腾讯：公式「股价 = 利润 × 市盈率」就写在三根柱子上方，利润 ×4，市盈率 ÷4，股价原地 →「你买的不是公司，是当年的估值」；② 阿里：护城河翻转（反过来想），拼多多、抖音两支箭射穿，买家从缺口流走，回购托不住；③ 智谱：跌了一半 ≠ 安全边际，内在价值那条线在「三年后的格局」里散成一片雾 →「内在价值 = ?」；④ 英伟达：创纪录利润在周期柱的山顶，利润腰斩后 13× 变 26× |
| 2:40 | 第四幕 · 解药 | 「反过来想」水中倒影 → 做空报告（第三条写不出，盖「别买」章）→ 能力圈：圈外的扔进「太难」篮子，看不懂就买指数 → 终曲（F 大调，圆号唱主题）：「价值投资，从来不是买便宜的股票，而是买你真正看懂的生意」 |
| 3:09 | 结尾 | 「你手里那把锤子，敲过哪几颗钉子？」四颗钉子自查清单 → 品牌片尾 |

视觉质感：
- 加色光 + 辉光渲染，变形镜头横向光晕（重拍时增强）。
- 章节切换时做径向推镜模糊，大标题用模糊转清晰入场。
- 胶片颗粒和暗角，背景星云的色调随章节变化。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、fluidsynth、fluid-soundfont-gm，以及 python3（numpy scipy opencv-python-headless pillow soundfile librosa mido）
```

各个文件的作用：

- `src/script.py`：旁白稿。
- `src/timeline.py`：把旁白排到 80BPM 网格上，带揭晓点的台词会反推起点，让揭晓点落在整拍上。`cues` 字段供配乐和画面共用。
- `src/music.py`：编曲、渲染和混音。
- `src/video.py`：全部分镜。
- `src/engine.py`：渲染引擎，含贴图层和横向光晕。
