# 好公司，为什么还会亏？ · 竖屏长视频

- 成片：`好公司为什么还会亏.mp4`（1080×1920 · 30fps · 约 14 分钟）。仓库的 Git LFS 额度已满，成片没有入库，需运行 `./build.sh` 生成。
- 脚本：`脚本.md`（V7 定稿：以雪球热帖为底稿，旁白内容完整保留，只修正了过时数据和出处不可靠的引文；含逐段画面、事实核查表）。
- 旁白：火山引擎 Seed-TTS 2.0（沉稳男声）。整段合成（同一段话一次合成，共用一口气），再按停顿切回逐句；跨段用 Praat PSOLA 把音高中心对齐到全片中位数、按长时平均频谱做音色匹配、统一响度，并加同一个小房间的短混响和极轻底噪，段落衔接处不再像换了一次人。句间停顿沿用整段合成时的自然停顿。数字按口语读法合成，字幕仍显示阿拉伯数字。
- 配乐：原创 MIDI 编曲（`src/music.py`），fluidsynth + FluidR3_GM 真实乐器分轨渲染，按章节换织体：序章钢琴叹息与琶音 → 片名全奏 → 问题一弦乐律动 / 降 B 大调反思 / 时代故事的壮阔转入周期的暗涌 → 铁锤三锤卡点后抽空 → 问题二钢琴独奏慢慢回暖 → 问题三 F 大调全奏、圆号唱主题 → 尾声钢琴。数字揭晓、三锤、金句、章节卡都对齐整拍；有旁白时配乐全频压低 12 dB、人声频段再让 5 dB（实测旁白比配乐高约 15 LU），句缝不放开；闪避放在最终混音、压缩之后，响度用线性增益 + 限幅到 -14 LUFS。
- 品牌：右上角是 `brand/` 的「巴芒价值」角标（含流光）；片尾是大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」。

## 三个问题

1. 为什么买了好公司，还可能亏钱？（价格与价值 → 护城河与能力圈 → 时代故事、周期、预期与铁锤人）
2. 股价下跌，就说明当初买错了吗？
3. 真正的价值投资，究竟是什么？

全片思想：好公司，不一定是好投资；好投资，也不一定立刻带来好回报；真正的价值投资，是在不确定的世界里，尽可能作出有利于长期回报的决策。

## 版式（防重叠）

竖屏分成固定区域：顶栏（章节条：序章 / 问题一 / 问题二 / 问题三 / 尾声，当前章节高亮并随进度填满；品牌角标在章节条下方）→ 标签区 → 标题区（金句、引文、问题）→ 主视觉区（图表与动画）→ 注脚区（口径、出处）→ 字幕区。每个元素只出现在自己的区域；镜头之间先淡出、再淡入，不交叠；超宽的大字会自动缩小字号。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、fluidsynth、fluid-soundfont-gm，以及 python3（numpy scipy opencv-python-headless pillow soundfile librosa mido praat-parselmouth pyloudnorm）
```

- `src/gen_script.py`：从 `脚本.md` 解析旁白，生成 `src/script.py`（配音文本 + 自动分屏的字幕）。
- `src/tts_all.py`：逐句合成（`work/vo_old`，只作切句时的时长参考）。
- `src/tts_blocks.py`：整段合成 → 停顿检测 + 动态规划切句 → 跨段音高 / 音色 / 响度统一。
- `src/timeline.py`：80BPM 节拍网格；揭晓点、三锤（每两小节一锤）、金句、章节卡对齐整拍；`cues` 供配乐与画面共用。
- `src/music.py`：编曲、渲染。
- `src/mix.py`：旁白粘合、配乐闪避、响度。
- `src/video.py`：全部镜头（`SHOTS` 列表按时间顺序排列）。
- `src/engine.py`：渲染引擎。
