## 一句话主线

**人买东西，不只是回答「我需要什么」，还在回答「我是谁」和「别人怎样看我」。能把这份身份感，稳定变成定价权和资本回报的企业，才拥有身份象征型护城河。**

## 数据口径

- 毛利率：苹果 FY2024 约 46%（毛利 1,807 亿美元 / 净销售 3,910 亿美元）；Costco FY2024 商品毛利率约 11%（净销售 2,496 亿美元，商品成本 2,224 亿美元）。
- Costco FY2024：会员费约 48 亿美元，营业利润约 93 亿美元，约 52%。
- 苹果在全球智能手机中「出货量约 2 成、行业利润约 8 成」：Counterpoint 等机构对部分年份的估算，画面上标为约数。
- 品牌散点图和倒 U 曲线都是定性示意，画面上也写明了「非消费者实验排名」「理论假设示意」。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、python3，以及 numpy、scipy、opencv-python-headless、pillow、soundfile
```

- `src/timeline.py`：共享时间轴（段落、和声、重拍、上升音效），音乐和画面都从这里取时间点。
- `src/music.py`：配乐合成器。
- `src/video.py`：全部分镜，每个 `sc_*` 函数是一段画面。
- `src/engine.py`：加色光 + 辉光的小型动态图形引擎（沿用《人为什么会感到不开心》的引擎，加了 `dim()` 压暗卡片）。
