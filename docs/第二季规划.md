## 二、第二季定位：护城河的另外几种样子

**入选标准**（用户已确认，和第一季护城河表用同一套）：
1. 护城河真实存在：能说清是哪一类，并拿数字或对手的实际反应作证据。
2. 对手很难长期复制：讲清原因。
3. 资本回报照样出色，或者至少能讲清回报为什么受限、为什么仍然值得持有。
4. 和伯克希尔有实质关系：全资拥有，或者长期重仓。

**补齐第一季没讲到的类型**：

| 类型 | 第一季 | 第二季 |
|---|---|---|
| 品牌和定价权 | 可口可乐、喜诗 | 不再专门做 |
| 网络效应 | 谷歌、美国运通 | 备选：Visa / 万事达（开放网络，和运通的闭环对照） |
| 低成本 | Costco | 内布拉斯加家具城（本地低成本）；GEICO（渠道低成本，难复制的原因不同） |
| 转换成本 | 苹果（讲得不透） | 精密铸件（航空认证） |
| 有效规模 | 无 | BNSF（西部铁路双寡头） |
| 监管牌照或特许 | 无 | 穆迪（评级三巨头）、威瑞信（.com 独家运营） |
| 资本实力与信誉 | 无 | 伯克希尔再保险（只有它接得起的大单） |

## 四、沿用第一季的制作体系

**先读根目录 `CLAUDE.md` 的制作宪章**，它对第二季同样适用。可直接复用的东西：

| 环节 | 用哪个 | 位置 |
|---|---|---|
| 核实 → 脚本 → 出处 | `research/核实笔记.md`、`script.py` 的 src 字段、`make_docs.py` 生成 `docs/SOURCES.md` | 以 `内布拉斯加家具城/` 为模板 |
| 旁白 | 豆包 TTS 3.0，`multi_male_liufei2_v3_uranus_bigtts`，语速 1.06，每章一条整录，长章在中间拆开 | `内布拉斯加家具城/src/tts_take.py` |
| 对齐与切句 | 逐句 DTW 对齐，在停顿正中下刀，合成段交界处吸附到停顿；用语音识别自检 | `voice_build.py`、`check_vo.py`、`docs/旁白一致性与自然衔接.md` |
| 原声 | 原速、不改词、不拼接，单独核查尾段 1.5 秒 | `内布拉斯加家具城/src/cut_sot.py`（tail_check） |
| 配乐 | score v4：中高音区旋律，按章换调、换速度，不用噪声类打击乐 | `内布拉斯加家具城/src/score.py` |
| 混音 | −14 LUFS，旁白比配乐高约 11 LU | `audio_mix.py` |
| 画面 | 竖屏 1080×1920，品牌角标 `brand.Hud`，去颗粒，素材放大用 Lanczos 并锐化 | `engine.py`、`gg.py`、`media.py` |
| 渲染与交付 | 分 4 段并行渲染；高清版 x264 CRF 17；预览版 HEVC 1080p 两遍编码，≤30MB；`patch_render.py` 局部重渲 | `render.sh` |
| 审片 | `SLOWLOG` 慢镜头检查、循环镜头日志、抽帧（改动处、句子交界、章节转场） | 同上 |

### 第二季开工前建议先做的两件事

1. **抽出公共模板**。现在每期都把上一期的 `src/` 整个复制一份，内布拉斯加家具城那期的修复（配乐 v4、TTS 3.0、清晰度、尾段核查）在旧期里并不存在。建议把通用部分放进根目录的 `engine/`，各期只保留 `script.py`、`gg.py`（镜头）、`media.py`（素材）和配乐提示。这样大约能省掉每期一天的搬运和返修。
2. **按期列素材清单**。内布拉斯加家具城那期的遗留问题是素材不够，有镜头循环重放。第二季每期写脚本前，先按章节估算需要多少秒素材，不够的那段在稿子阶段就调整。

## 五、每期节奏（参考内布拉斯加家具城那期的实际耗时）

1. 选题确认，用一句话写出核心问题。
2. 核实笔记（股东信、年报、公开采访），标明出处和口径。
3. 脚本，10–12 分钟。开场 1 分钟内要有冲突和悬念；每章回答一个问题；结尾给能带走的道理。
4. 素材：先审再用，记入 `ia_clips.json`。
5. 旁白合成 → 对齐 → 自检。
6. 时间线 → 配乐 → 混音。
7. 画面 → 抽帧审片 → 全片渲染（约 110 分钟）。
8. 成片、预览版、`SOURCES.md`，提交推送；向用户说明改动、新时间点和片长变化。
