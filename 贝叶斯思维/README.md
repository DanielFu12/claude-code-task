- 成片：`贝叶斯思维.mp4`（1920×1080 · 30fps · 4:57 · H.264 + AAC）

## 科学准确性

- 100 扇门：你第一次选中的概率 1/100；否则（99/100）车在另外 99 扇里，主持人必须避开它，留下的那扇就是车，所以换门赢 99/100。
- 蒙提霍尔：按标准规则（主持人知道车在哪，总会打开一扇你没选、且是山羊的门；车在你选的门后时随机二选一）。贝叶斯计算：P(开 3 | 车在 1, 2, 3) = 1/2, 1, 0，后验 = 1/3, 2/3, 0。
- 3000 局模拟是真的跑出来的（种子 1990），结果 33.6% / 66.4%。
- 罕见病：10,000 人中 100 人患病，99 人真阳性；9,900 名健康人中 1% 误报 = 99 人 → 50%。第二次独立检测：98.01 / (98.01 + 0.99) = 99%。
- 投资信念曲线与"付款"例子中的似然比是示意数字（画面注明），更新用的是赔率形式：60% → ×3 → 81.8% → ×2 → 90.0% → ×1/4 → 69.2%。
- 史实：1990 年 9 月《Parade》「Ask Marilyn」专栏；约 1 万封读者来信、近千封来自博士；埃尔德什看到计算机模拟后才接受；贝叶斯（约 1701–1761）的论文在他去世后由理查德·普莱斯整理，1763 年在英国皇家学会宣读并发表。

## 重新生成

```bash
./build.sh      # 需要 ffmpeg、python3：numpy scipy opencv-python-headless pillow soundfile pyloudnorm matplotlib
```

- `src/timeline.py`：唯一的时间来源（章节、重拍、旁白字幕、开门顺序），画面与配乐共用。"100 扇门为什么是 99%"是后加的插入段（`INS_*`），插入点之后的画面和配乐整体后移 32.5 秒（13 小节）。
- `src/music.py`：配乐合成与混音。
- `src/engine.py`：小型动态图形引擎（1/16 像素精度的抗锯齿矢量、文字精灵与逐字显现、粒子、辉光、色差、颗粒）。
- `src/video.py`：全部分镜，`scene_*` 每个函数对应一段；`python3 src/video.py preview 40.2 170.0` 可以导出单帧。
