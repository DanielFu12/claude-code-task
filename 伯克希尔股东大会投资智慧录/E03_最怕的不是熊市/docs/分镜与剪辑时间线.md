- 系列一致：第 0 秒中文钩子、片头 1994 年大会原始录像 + 金色系列片名 + 背景卡、左上章节标签、字幕版式、问答收尾的金句卡、“投资启示”标题转场、总结、互动问题与品牌片尾都与前两集一致；后期同为泛光、横向光晕、重拍推镜 + 闪光 + 色散。

- 光色：金色 = 企业、买入与长期回报；冰青 = 价格与上涨；琥珀 = 下跌、泡沫与危险。
