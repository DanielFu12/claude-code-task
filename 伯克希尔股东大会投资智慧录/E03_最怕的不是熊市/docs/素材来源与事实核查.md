# 素材来源、授权与事实核查

## 原始问答

- 内容：1994-04-25 伯克希尔·哈撒韦年度股东大会上午场，CNBC Warren Buffett Archive 第 47 章「Why we have no short-term opinion on stocks」。提问者为来自加州科罗娜德尔玛的股东（逐字稿记作 Diane West，并标注为音译），回答者沃伦·巴菲特，查理·芒格补充。
- CNBC 档案页：https://buffett.cnbc.com/video/1994/04/25/morning-session---1994-berkshire-hathaway-annual-meeting.html
- 逐字稿：CNBC 档案逐字稿（经 GitHub 镜像 `pzponge/Yestoday` 获取，文件 `Warren_Buffett/Berkshire_Hathaway_Annual_Meeting/1994_Annual_Meeting.md` 第 47 节）。
- 录像来源：archive.org 条目 `youtube-A2J-_BNkqm8`（https://archive.org/download/youtube-A2J-_BNkqm8/A2J-_BNkqm8.mp4），为 YouTube 频道 Legendary Investor 上传的 1994 年全场录像；本题从录像 1:39:28（“Zone 2.”）开始，到 1:44:01（“Zone 3.”）结束。只按区间读取需要的音频与画面，不下载整片。
- 字幕时间：faster-whisper（medium.en）逐词时间戳与逐字稿做序列匹配，689 个单词中 678 个直接对上（98.4%），其余插值；识别结果只用于定时，字幕文字以逐字稿为准。
- 使用性质：评论、教育与研究目的的引用；保留问答主线，不改变原意。
