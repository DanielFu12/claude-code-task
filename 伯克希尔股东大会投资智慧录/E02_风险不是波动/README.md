## 本集的升级

### 1. 画面：流光诗意纪录片（新）

第一集是 2D 动态图形；本集按仓库 `AI视频学习资料包/渲染风格库/S4-流光诗意纪录片.md` 的**渲染风格**（只借鉴风格，不借鉴其内容）重写了整套画面：自然纪录片式的写实空镜、科学可视化的流线与网格、发光的数学公式，用优雅的衬线排印和双语字幕串起来。深底、柔光、慢镜头，追求“安静的惊叹”。

- **三类画面交替出现**（`src/s4gl.py`，三个 GLSL 全屏着色器，Mesa llvmpipe 在 CPU 上运行）：
  - 写实空镜：金色时刻的程序化海面（光线步进求交的海浪、条状暮云、太阳碎金、空气透视），镜头极慢推进；
  - 流动可视化：线积分卷积（LIC）流线、一冷一暖两颗光源的辐射流线、发光网格曲面与点阵地面（涟漪、行波、深坑、撕裂），以及加色叠加的粒子；
  - 公式屏：深底上极暗的流线纹理 + 从左到右擦除式写出的发光公式（Computer Modern）。
- **后期**（`src/s4post.py`）：柔和泛光（“雾而不是烧”）、ACES 色调映射、暗部抬到炭灰蓝 #181922、轻暗角、2% 颗粒。
- **色彩**：香槟金 #F8D998 / #D3B078 与钢蓝 #6BA0BE / #50709B 一暖一冷两套光；少量暗红只用于亏损与风险。
- **排印**：书法体片名（Ma Shan Zheng）+ 字距 1em 的全大写英文；左上章节眉用旧式数字的 Playfair Display（1994、1973、1993……）+ 全大写副行；中文字幕为思源宋体，英文为全大写小字；物体标签是中文衬线 + 全大写英文小字。
- **剪辑**：相邻镜头 1.0–1.2 秒交叉溶解，正片没有硬切；重拍上只让光线柔和地涌亮，不推镜、不闪白。片尾前按 Nerves 的 13 个拍点快闪回顾全片，最后一镜回到开场的海面，再回到片名的点阵地面落下总结。

每个画面都对应一个概念：

| 画面 | 对应 |
|---|---|
| 冷开场：金色时刻的海面 | 价格就像海浪，永远在起伏 |
| 片名：点阵地面上亮起的书法“风险” | — |
| 紫蓝网格上方，一条金色价格线一路走低，“−25%” | 一年跌掉 25% |
| 公式屏：β = Cov(rᵢ, rₘ) / Var(rₘ)，β↑ ⇒ Risk↑ | 教科书的答案：更危险 |
| 原声段：Risk = P(harm or injury)、Risk = f(T_hold)、Risk ≡ σ 被划去 → Risk ≠ σ、A/B 两条振动的光线、E[Σ X_k] > 0、Fermat · Pascal | 巴菲特与芒格的论证，一段一个公式或图示 |
| 一冷一暖两颗光源：钢蓝光源不停抖动，香槟金光源稳定发光 | 教科书的风险（σ, β） vs 巴菲特的风险（P(loss)） |
| 金色路径起伏着走到“持有期结束”，W_T / P_T ≥ W_0 / P_0 | 真正的风险看终点的购买力 |
| 网格泛起涟漪，地平线上亮起金色光点 | 波动是摆动的幅度，风险是钱还在不在 |

| 平静的网格被压出深坑，光点坠入、金色微粒流进坑底 | 德克斯特：没有波动，却永久归零 |
| 行波推过网格，一根暗红细线拴住光点；浪平了，被撕开的坑还在 | 杠杆 / 被迫卖出：暂时的下跌被锁定成永久损失 |
| 公式屏：Drawdown ≠ Permanent Loss + 两个问题 | 今天 |
| 回到开场的海面 | 收尾句 |

原声问答段保持克制：上方羽化窗口里是 1994 年的**原始录像**（第一集只有静帧；这一题有现场画面），一条细金色示波线随原声起伏，下方是发光公式与衬线标签，不做卡点特效；芒格开口时镜头缓缓推向芒格。三处节选省略在画面上用一道扫过的细光标出“· 节选 ·”。

### 2. 配乐：渐进式的电影级情绪曲线

两首新曲（每集单独选曲），从 incompetech 曲库按 Dark / Epic / Intense / Driving 筛出 16 首，逐首做能量曲线、低频占比、频谱与起音分析后选定：

- **Hiding Your Reality**（暗色合成器铺底 + 铜管打击乐，107 BPM）：冷开场里暗色铺底淡入，9.01 秒的打击乐整体进入**正好落在书法片名亮起的那一刻**。
- **Nerves**（铜管、弦乐、打击乐与合成器，140 BPM）的结构和论证一一对应：
  - 0–28 秒安静的开头 → 两种定义、持有期；
  - **28.48 秒 +27dB 的大段落进入 → 华盛顿邮报的开口与风暴**；
  - 46.27 秒回落 → 德克斯特的“平静”；
  - **62.25 秒激增 → 裂纹出现**；
  - 99.64 秒留白 → 收尾句的后半句（留白段整体抬高 6dB，并叠一段低频蓄力，不出现断档）；
  - 高潮前的 13 个拍点 → 快闪回顾；**108.26 秒高潮 → 一句话总结**；之后的强拍 →「巴芒价值」。
- 原始问答段完全不放音乐；口播期间侧链压低 11dB。
- 转场音效只用正弦合成的低频膨胀、低沉冲击、低频下潜（4 阶 180Hz 低通），没有任何 whoosh、白噪声或金属声。

### 3. 叙事

开场直接抛出反直觉问题（“跌了 25%，更危险还是更便宜？”），先给出教科书的答案“更危险”，再用巴菲特的原话推翻它；解读用一正一反两个**同时代、同一位投资人**的真实案例形成反差——一个价格大跌却赚了 40 倍，一个价格从不波动却永久归零——最后讲清适用条件（借钱、被迫卖出），落到观众今天能用的两个问题上。

## 原始问答的来源与时间戳

- **出处**：1994 年 4 月 25 日伯克希尔·哈撒韦年度股东大会上午场，CNBC Warren Buffett Archive 第 50 章「Risk is “inextricably wound up” in how long an asset is held」。提问者为来自密歇根州安阿伯的股东，回答者沃伦·巴菲特，芒格补充。
- **录像**：archive.org 条目 `youtube-A2J-_BNkqm8`（1994 年全场录像），本题在 **1:53:48–1:58:42**；四段节选的精确剪点见 `docs/分镜与剪辑时间线.md`。
- **节选省略**：提问者自我介绍；提问里衍生品与飓风保险的两个例子；回答中超级巨灾保险的十年期限例子；“只做能写出方程的交易”与抛硬币赔率的补充。核心问题与论证主线完整保留；完整逐字字幕仍在 `src/script.py`。
- **字幕**：英文逐字取自 CNBC 逐字稿（只省略口头重起的半句）；中文为本片翻译。faster-whisper 逐词时间戳与逐字稿序列匹配，754 个单词中 739 个直接对上（98.0%）。
- **竖屏处理**：只取源画面中干净的 1515×614 区域（避开第三方频道水印和烧录字幕），等比缩放进羽化的宽银幕窗口，外层用同画面的模糊放大补满，不拉伸。
- 档案录像在芒格作答后的笑声中有一处硬切（数字静音），本片在硬切前收住。

## 声音

- **配音**：Google Gemini TTS（`gemini-3.8-flash-tts`，声音 `charon`），风格指令原样放在 `speech_metadata.style`；按段落成组合成；faster-whisper 强制对齐切句；整体提速 7%（保留音高）。只用 Gemini，不设备用引擎。
- **金额复核**：Gemini 在长句里曾把“亿美元”读成“亿元”（单独合成时读得正确）；对含金额的句子逐句用 faster-whisper medium 复核“美元”是否读出，不过关的整段重新合成，并把“4.33 亿美元”改读为“四亿三千三百万美元”。最终四句全部复核通过。
- **原声**：每段节选单独统一到人声 RMS -20dBFS（提问、巴菲特、芒格的麦克风不同）；只做 70Hz 高通与档案拼接处的底噪补齐，不降噪、不变速；节选之间用同一录音的环境底噪衔接。
- **响度**：两遍 loudnorm 线性归一到 -16 LUFS、真峰值 ≤ -1.5 dBTP。

## 重新生成

```bash
./build.sh
```

依赖 ffmpeg、xvfb-run 与 Mesa（llvmpipe 软件 OpenGL），以及 `numpy scipy opencv-python-headless pillow matplotlib soundfile librosa faster-whisper moderngl`；配音需要 Gemini key（云环境由出口代理注入，本地用 `GEMINI_API_KEY`）。网络需要能访问 archive.org、Google Fonts、incompetech.com、generativelanguage.googleapis.com、Hugging Face。`data/asr_words.json` 是已存的逐词时间戳。在 4 核机器上 4 进程逐帧渲染约 1 小时（约 1.5 秒/帧）。
