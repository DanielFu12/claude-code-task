## 原始问答的来源与时间戳

- **出处**：1994 年伯克希尔·哈撒韦年度股东大会（1994 年 4 月，奥马哈）下午场，CNBC Warren Buffett Archive 第 22 章「Calculating intrinsic value」。提问者 Sean Barry（加拿大里贾纳），回答者沃伦·巴菲特。
- **录音（节选）**：archive.org 条目 `youtube-A2J-_BNkqm8`（1994 年全场录像，3:31:28）的 **3:17:41.6–3:20:22.4**，约合下午场 **45:55–48:35**（按录像标注的下午场起点 2:31:47 换算），中间不剪。
  - 从股东的核心问题 "Could you perhaps give an indication as to how you and Charlie come up with the economic value, or the intrinsic value…" 开始，到巴菲特 "That's all we do, we just do it with large businesses, basically." 结束。
  - 省略两段：提问者的自我介绍与铺垫（"Zone 2? … Sean Barry, Regina, Canada … GAAP rules leave a little to be desired"，约 22 秒）；以及回答结尾关于“会计数字有帮助、警惕粉饰数字”的补充（约 33 秒）。
  - 核心论证（经济价值 = 未来现金流现值 → 看不清就不知道值多少 → 认知失调 → 区间与把握 → 确定性优先于便宜 → 报表只有指引 → 懂生意 → 四个问题）完整保留。完整版的全部逐字字幕仍在 `src/script.py` 中。
- **没有现场画面**：CNBC 档案中 1994 年下午场本就只有音频，archive.org 录像在这一段也只是 "Audio Only" 卡片。所以原声段落的画面用的是**同日上午场的真实静帧**（提问时为巴菲特托腮倾听，回答时为他讲话的瞬间），画面上标明“画面：同日上午场静帧 ｜ 声音：下午场原始录音”。片头与过场用的是上午场的真实活动影像。全片没有 AI 生成的“历史影像”。
- **字幕**：英文逐字取自 CNBC 逐字稿（只省略 "Well, the —" 这类口头重起的半句）；中文为本片翻译。时间来自 faster-whisper 逐词时间戳与逐字稿的序列匹配（98.1% 的词直接对上）。
- **竖屏处理**：只取源画面里干净的 1515×614 区域（避开第三方频道水印和烧录字幕），等比放进 1080×438 宽银幕窗口，不拉伸人物；窗口外是同一画面的模糊放大背景。

## 声音

- **配音**：Google Gemini TTS（`gemini-3.8-flash-tts`，男低音 `charon`），风格指令原样放在 `speech_metadata.style`：“A steady authoritative male narrator for a financial documentary. Measured and deliberate pace, calm confidence, clear enunciation, quiet gravitas.”
  - 按段落成组合成（同一段的几句一次念完，语气连贯），正文只放逐字稿；关键句前加 `<breath>` / `<short pause>`。
  - Gemini 不返回逐字时间，用 faster-whisper 对合成结果做强制对齐（识别只用于定时，字幕文字以稿子为准），在句间能量最低处切句；段内句间停顿保留模型自己的节奏，段落之间按语义留白。
  - 每段合成后自动核对“稿子覆盖率”（漏读、误读或把标签念出来就重合成，最多 3 次）；原始返回另存 MP3。
  - key 在云环境中以 Network secret 形式由出口代理注入（本地运行设环境变量 `GEMINI_API_KEY`）；`TTS_ENGINE=edge` 可改用备用的微软 Edge 语音「云健」。
- **旁白提速**：整体 1.07 倍（ffmpeg rubberband，保留音高与共振峰），逐字时间同比缩放。
- **原声**：只做 70Hz 高通、电平统一和档案拼接处的底噪补齐，不降噪、不变速；节选范围内不剪。
- **配乐**（Kevin MacLeod，CC BY 4.0），从“低沉”改为“深邃、卡点、有推动力”：
  - 冷开场到系列介绍：*Undaunted*（95 BPM，电影大鼓 + 钢琴）。大鼓进入正好落在片名出现的那一帧；各段旁白的开口吸附到节拍上；进入 1994 背景卡时落在小节强拍并接低频下潜。
  - 原始问答：**完全不放音乐**。
  - 投资启示到片尾：*The Escalation*（一首持续渐强的曲子）按论证结构对位：
    - 渐强段铺在“价值公式 / 债券与股票”；
    - 大段落进入的重拍正好落在“看得清，是什么样子？”（喜诗糖果）；
    - 配乐回落对应“代价是错过”；
    - 高潮重拍落在一句话总结；
    - 5 小节后的强拍落在「巴芒价值」浮现。
  - 口播期间侧链压低 11dB（比 v2 少压 2dB，配乐更有存在感），无人声的片名、总结与片尾段音乐响度约 -16 LUFS（短时）。
- **转场音效**：低频膨胀、低沉冲击、低频下潜和低频空间混响，全部用正弦波合成、4 阶 180Hz 低通，不用任何噪声源、高频 whoosh 或金属声；只在 8 个结构转折处使用。
- **响度**：两遍 loudnorm 线性归一到 -16 LUFS、真峰值 ≤ -1.5 dBTP。

## 画面

深黑 / 炭灰底色 + 品牌金；思源宋体做标题、思源黑体做字幕，EB Garamond / Cormorant 做英文与数字。历史影像统一降饱和、偏暖、轻微抬黑并加细颗粒。

v3 的动态设计（`src/fx.py`）：
- **后期**：亮部泛光与横向镜头光晕（变形宽银幕质感）。配乐段落里，强重拍上推镜 4% + 闪光 + 色散，小节强拍上轻微脉动。原声问答段只保留轻度泛光，不做卡点，以免干扰讲话。
- **系列介绍**：逐词卡点的动态排版：“1994 — 至今”、估值 / 护城河 / 风险 / 人生智慧、“01 原声 → 02 案例”、“说了什么”被划去、“为什么这样想”；年份从 2026 倒带回 1994。
- **投资启示**：
  - 背景：透视网格地面 + 向镜头飘来的 3D 金色粒子 + HUD 圆环。
  - 公式：符号从景深飞入，分子被瞄准框锁定并爆开粒子。
  - 债券与股票：发光的票息柱对比故障化的“问号柱”。
  - 喜诗糖果：滚动计数 + 13.5 亿光柱（竖向光束与火花）+ “仅约 2.4%”。
  - 美国航空：红色警报闪烁，减记时金柱碎裂下坠，“$1 → 25¢”砸入。
  - 芒格原话：打字机效果，“错过 / 看错”卡片砸入并故障闪红。
  - 今天：旋转的 3D 点阵球只点亮 7 颗。

## 重新生成

```bash
./build.sh
```

依赖 ffmpeg 与 `numpy scipy opencv-python-headless pillow soundfile librosa edge-tts faster-whisper`，以及环境变量 `GEMINI_API_KEY`。网络需要能访问 archive.org、Google Fonts、incompetech.com、generativelanguage.googleapis.com、Hugging Face。`data/asr_words.json` 是已存的逐词时间戳，存在时不需要重新跑语音识别。在 4 核机器上逐帧渲染约 30 分钟。

单帧检查：`cd src && python3 render.py stills OUT_DIR 30 150 400 ../work`。

## 已知限制

- 1994 年下午场没有现场画面，这是档案本身的限制；本片用同日上午场静帧并明确标注，不制造“看起来像录像”的画面。
- 原始录音取自 archive.org 上第三方上传的录像（音质与 CNBC 档案一致，但不是 CNBC 官方文件）；`buffett.cnbc.com` 对本环境返回 403，无法直接取官方音频。
- “下午场时间”按第三方录像标注的下午场起点换算，和 CNBC 页面的播放时间可能有几秒偏差；片内时间与录像时间是精确的。
- 配音默认用 Gemini TTS（2026 年底前免费）；备用的 Edge TTS 公开商用前请确认平台条款。
- 音乐为 CC BY 4.0，发布时需在简介中署名（见 `docs/素材来源与事实核查.md`）。
