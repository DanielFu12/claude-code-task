## 01 · 第一性原理

| 编号 | 旁白 |
|---|---|
| p1 | 人买东西，其实在回答三个问题。 |
| p2 | 我需要什么？这是功能。 |
| p3 | 我是谁？这是认同。 |
| p4 | 我希望别人怎么看我？这是地位。 |
| p5 | 品牌能多收的钱，很大一部分来自后两个问题。 |
| p6 | 这部分溢价不全是虚荣，归属感和审美，同样让人愿意掏钱。这一期，只讲第三个问题：别人怎么看我。 |
| p7 | 人为什么这么在乎别人的眼光？ |
| p8 | 芒格说过：驱动这个世界的，不是贪婪，而是嫉妒。 |
| p9 | 因为在群体里被高看一眼，就意味着更多的机会和资源。在乎地位，是刻在人性里的。 |
| p10 | 可地位是看不见的。收入、能力、品位，都藏在一个人身上。 |
| p11 | 所以，人需要信号，让别人看见。 |
| p12 | 信号要让人相信，就得有代价。谁都能轻松发出的信号，没有人会当真。 |
| p13 | 孔雀的尾巴又长又重，还容易招来天敌。正因为弱小的孔雀负担不起，这条尾巴才让人相信。 |
| p14 | 回到买东西。我们多付的钱，往往来自三股叠在一起的力量。 |
| p15 | 第一股，是地位信号：用这个品牌，让别人觉得我更有钱、更有品位，或者属于更好的圈子。 |
| p16 | 第二股，是从众：我向往的那群人都在用，我也更愿意选它。 |
| p17 | 第三股，是门槛：价格高一些，或者要先办一张会员卡，让这个选择显得有分量；可普通的中产家庭，仍然买得起。 |
| p18 | 要分清的是，这不是凡勃伦效应。凡勃伦效应是越贵越想买；这里多付的钱，是为了信号，不是为了贵本身。 |
| p19 | 三股力量叠在一起，就有了一种特别的护城河：大众地位象征型品牌。 |
| p20 | 它的强弱，可以写成一个乘法：社会可见性，乘以身份识别度，乘以心理溢价，乘以广泛可及性。 |
| p21 | 既然是乘法，任何一项接近零，整条护城河就接近零。 |
| p22 | 麻烦在于，这几项天生互相拉扯。地位是相对的：人人都有，就等于谁都没有。 |
| p23 | 买得起的人越多，拥有的人就越多；拥有的人越多，区分就越薄。 |
| p24 | 被认可、买得起、有区分，能长期管好这三件事的品牌，才守得住这条护城河。 |

## 02 · 一把尺子

| 编号 | 旁白 |
|---|---|
| d1 | 那么，身份溢价什么时候，才算得上护城河？ |
| d2 | 巴菲特给过一把尺子：评估一家企业，最重要的是定价权。 |
| d3 | 如果涨价十分之一美分之前，都得先祷告一番，那就是糟糕的生意。 |
| d4 | 身份带来的溢价，要能长期守住，还能往上提，才算护城河。为此，它要过三道关。 |
| d5 | 认得出，对应可见性和识别度；仿不了，决定溢价可不可信；稀释不了，考验的是：买得起的人越来越多，区分会不会被冲淡。 |

## 03 · 三道关

**第一关 · 认得出**

| 编号 | 旁白 |
|---|---|
| k1 | 第一关：认得出。 |
| k2 | 信号要有人看见，还要被对的人看懂。 |
| k3 | 放在家里的东西再贵，也换不来别人看你一眼。 |
| k4 | 手机正好相反：天天拿在手上，一眼就能认出来。“爱马仕橙”走红，有分析认为，原因之一就在这里：别人一眼就能看出，这是今年的新款。 |
| k5 | 那苹果传递的，是什么信号？不是“我很有钱”，而是“我有一定的消费能力，在乎品质，过着体面的生活”。 |
| k6 | 不过，说多数人买苹果是为了面子，并没有证据；苹果还有好用的产品和生态。能确定的只是，身份这份动机确实存在。 |

**第二关 · 仿不了**

| 编号 | 旁白 |
|---|---|
| k7 | 第二关：仿不了。 |
| k8 | 信号值钱，是因为别人仿不出来。但“仿不出来”有两种：一种是暂时的，一种是长久的。 |
| k9 | 暂时的那种，靠的是一时缺货：产能跟不上，黄牛在囤货。 |
| k10 | 2025年6月18日，Labubu全渠道补货。据媒体统计，热门款的二手价当天就跌了一半以上。 |
| k11 | 仿冒也来得很快：那一年，英国边境查获的假冒玩具里，九成是假Labubu。 |
| k12 | 当二手价本身就是信号，价格一跌，信号也跟着贬值。 |
| k13 | 长久的那种，来自对手短期内追不上的东西。 |
| k14 | 比如爱马仕：皮具工匠入职，要先培训至少18个月；新的皮具工坊一座一座地建，计划已经排到了2030年。 |
| k15 | 它的高管说：稀缺从来不是我们的目标。稀缺只是结果：想多做，快不起来；想模仿，也买不来将近两百年的积累。 |
| k16 | 大众品牌也一样。手机的外观可以模仿，苹果几十年积累的设计、供应链和口碑，模仿不来；会员费谁都能收，可要让会员相信“这里的东西都被挑过”，却很难。 |

**第三关 · 稀释不了**

| 编号 | 旁白 |
|---|---|
| k17 | 第三关：稀释不了。这是大众身份品牌最难的一关。 |
| k18 | 用户越多，认得出的人越多，特别感却越少。普及会先增强信号，再削弱信号。 |
| k19 | 所以投资者该问：多一个用户，会让下一个人更想买，还是更不想买？ |
| k20 | 奢侈品可以靠少卖来守住区分。爱马仕把门分成几层：丝巾、香水，很多人买得到；最受追捧的包，往往要等。 |
| k21 | 大众品牌不能少卖，只能在规模里留出层次：苹果有Pro和标准版；山姆有一张会员卡，和一排排挑过的货架。 |
| k22 | 山姆是个特别好的例子。它给会员的感觉，不是“我买得起贵东西”，而是“我属于注重品质、懂得挑选的城市家庭”。 |
| k23 | 2025年7月，山姆下架了20多款口碑商品，换上了好丽友派这类到处都能买到的零食。 |
| k24 | 会员们炸了锅，有人说要退卡。山姆随后下架了争议商品，表示会把这些讨论纳入选品考量。 |
| k25 | 一块派能引起这么大的反应，说明很多会员担心的，不只是货架上换了零食，而是这张卡给自己的那份区分，被稀释了。 |

**最后一道算术 · 心理溢价能不能变成利润**

| 编号 | 旁白 |
|---|---|
| m1 | 三关都过了，还有最后一道算术：身份，能不能变成利润？ |
| m2 | 爱马仕把它变成了很高的价格：2025年，毛利率71%，经营利润率41%。 |
| m3 | 苹果走的是另一条路。2025年第四季度，全球卖出的手机里，大约每四部有一部是iPhone；可全球手机的销售收入，将近六成进了苹果。 |
| m4 | 按这两个数推算，一部iPhone的平均售价，大约是其他手机的四倍。 |
| m5 | 这份溢价，当然不全是为身份付的，iPhone的产品和生态本来就值钱；但身份，是其中的一部分。 |
| m6 | 爱马仕靠的是少数人付很高的价；苹果靠的是很多人都愿意多付一截。两条路，都把身份变成了定价权。 |
| m7 | 还要看这份认同是怎么来的：靠口碑传开的，新用户几乎不用花钱去拉；靠广告和补贴拉来的，每多一个用户，都要再花一次钱。 |
| m8 | 认同如果留不住钱，就只是热闹，不是护城河。 |

## 04 · 中国考题

| 编号 | 旁白 |
|---|---|
| g1 | 带着这三道关和那道乘法，来看三家中国公司：一家老牌，两家新秀。 |
| g2 | 先看茅台。它几乎是中国最经典的身份消费品：摆上宴席，人人认得；拿去送礼，代表的是体面。 |
| g3 | 它也仿不了：一瓶茅台酒，从投料到出厂至少要五年，别人想追，也追不快。 |
| g4 | 可乘法里还有一项，叫社会可见性。2025年5月，新修订的《党政机关厉行节约反对浪费条例》规定，工作餐不得提供高档酒水。 |
| g5 | 宴席上的那份可见性，少了一块。同年12月，飞天茅台的批发价，跌破了1499元的官方指导价；全年营收和利润，出现了上市以来第一次双双下降。 |
| g6 | 但它的定价权并没有消失。去年，茅台酒的毛利率仍然超过93%；今年3月，茅台还把飞天的指导价从1499元提到了1539元；到了9月，批发价在1700元上下。 |
| g7 | 乘法里有一项变小，溢价就会松动；可只要认得出、仿不了还在，定价权就还在。 |
| g8 | 再看老铺黄金。认得出吗？能，商场门口排过长队。 |
| g9 | 仿不了吗？据报道，到2026年4月，它进驻的32家商场里，至少有19家也开了其他古法金品牌。 |
| g10 | 稀释不了吗？据媒体11月的走访，古法金门店大多在促销，老铺的优惠力度最大，一款手镯直接减了将近2万元。 |
| g11 | 不过，它2026年上半年的利润，仍然增长了八成以上。 |
| g12 | 最后看泡泡玛特。补货那天，Labubu的稀缺就打了折；第三季度，收入下降了将近一半。公司的解释是：去年同期基数太高，加上正在优化海外库存。 |
| g13 | 但段永平偏偏在股价下跌时，买入了它5%以上的股份，还说10年内大概率不会卖。 |
| g14 | 他说，看好的是创始人王宁，也没想到它这么能赚钱。 |
| g15 | 一只玩偶的热度会退。一家公司能不能一次又一次，造出让人想拥有的身份，才是真正的考题。答案，交给时间。 |

## 05 · 失守

| 编号 | 旁白 |
|---|---|
| q1 | 身份护城河还有一种失守，比什么都快：品牌背叛了用户的身份。 |
| q2 | 2025年9月，始祖鸟和艺术家蔡国强，在喜马拉雅山的山脊上放了一场烟花。 |
| q3 | 一个讲“敬畏自然”的户外品牌，在雪山上点燃了火药。舆论哗然。两天后，双方先后道歉，当地也成立了调查组。 |
| q4 | 人们会为身份多付钱，也会因为身份，转身离开。 |

## 06 · 答案

| 编号 | 旁白 |
|---|---|
| z1 | 最后，留给你一个问题。 |
| z2 | 如果你用它的时候，没有任何人知道，你还愿意多付同样多的钱吗？ |
| z3 | 如果愿意，你买的是品质；如果不愿意，你买的是别人的目光。两种都没有错。 |
| z4 | 这个问题，也是投资者的试金石：没人看见的时候，愿意多付的钱降得越多，说明身份在这个品牌里的分量越重。 |
| z5 | 但对投资者来说，贵只是一个标价，谁都能标。 |
| z6 | 认得出、仿不了、稀释不了，还能变成利润的身份，才是护城河。 |
| z7 | 当一个品牌成了你的一部分，对手要抢走的就不只是一笔订单，而是你对自己的理解。 |
| z8 | 品牌的最高境界，不是“我拥有它”，而是“它代表我”。 |
