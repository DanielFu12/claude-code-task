**片名：多付的钱，买的是什么｜身份成为护城河的三道关**

## 01 · 第一性原理

| 编号 | 旁白 |
|---|---|
| p1 | 人买东西，其实在回答三个问题。 |
| p2 | 我需要什么？这是功能。 |
| p3 | 我是谁？这是认同。 |
| p4 | 我希望别人怎么看我？这是地位。 |
| p5 | 品牌能多收的钱，很大一部分来自后两个问题。 |
| p6 | 这部分溢价不全是虚荣，归属感和审美同样让人掏钱。这一期，只讲第三个问题：别人怎么看我。 |
| p7 | 人为什么这么在乎别人的眼光？ |
| p8 | 芒格说过：驱动这个世界的，不是贪婪，而是嫉妒。 |
| p9 | 因为在群体里被高看一眼，就意味着更多的机会和资源。在乎地位，是刻在人性里的。 |
| p10 | 可地位是看不见的。收入、能力、品位，都藏在一个人身上。 |
| p11 | 所以，人需要信号，让别人看见。 |
| p12 | 信号要让人相信，就得有代价。谁都能轻松发出的信号，没有人会当真。 |
| p13 | 孔雀的尾巴又长又重，还容易招来天敌。正因为弱小的孔雀负担不起，这条尾巴才让人相信。 |
| p14 | 放到买东西上，多付的钱，往往来自三股力量。 |
| p15 | 第一股，是地位信号：用这个品牌，让别人觉得我更有钱、更有品位，或者属于更好的圈子。 |
| p16 | 第二股，是从众：我向往的那群人都在用，我也更愿意选它。 |
| p17 | 第三股，是门槛：价格高一些，或者要先办一张会员卡，让这个选择显得有分量；可普通的中产家庭，仍然买得起。 |
| p18 | 要分清的是，这不是凡勃伦效应。凡勃伦效应是越贵越想买；这里多付的钱，是为了信号，不是为了贵本身。 |
| p19 | 三股力量叠在一起，就有了一种特别的护城河：大众地位象征型品牌。 |
| p20 | 它的强弱，可以写成一个乘法：社会可见性，乘以身份识别度，乘以心理溢价，乘以广泛可及性。 |
| p21 | 既然是乘法，任何一项接近零，整条护城河就接近零。 |
| p22 | 可这几项天生互相拉扯：地位是相对的，人人都有，就等于谁都没有。 |
| p23 | 买得起的人越多，拥有的人就越多；拥有的人越多，区分就越薄。 |
| p24 | 被认可、买得起、有区分，能长期管好这三件事的品牌，才守得住这条护城河。 |

## 02 · 一把尺子

| 编号 | 旁白 |
|---|---|
| d1 | 那么，身份溢价什么时候，才算得上护城河？ |
| d2 | 巴菲特给过一把尺子：评估一家企业，最重要的是定价权。 |
| d3 | 如果涨价十分之一美分之前，都得先祷告一番，那就是糟糕的生意。 |
| d4 | 身份带来的溢价，要能长期守住，还能往上提，才算护城河。把刚才的乘法拆开来看，它要过三道关。 |

## 03 · 三道关

**第一关 · 认得出**（社会可见性 × 身份识别度）

| 编号 | 旁白 |
|---|---|
| k1 | 第一关：认得出。 |
| k2 | 信号要有人看见，还要被对的人看懂。 |
| k3 | 放在家里的东西再贵，也换不来别人看你一眼。 |
| k4 | “爱马仕橙”走红，有分析认为，原因之一是别人一眼就能看出：这是今年的新款。 |
| k5 | 苹果传递的信号，不是“我很有钱”，而是“我有一定的消费能力，在乎品质，过着体面的生活”。 |
| k6 | 不过，说多数人买苹果是为了面子，并没有证据；苹果还有产品和生态。能确定的只是，身份这份动机确实存在。 |

**第二关 · 仿不了**（心理溢价是否可信）

| 编号 | 旁白 |
|---|---|
| k7 | 第二关：仿不了。 |
| k8 | 信号值钱，是因为别人仿不出来。可“仿不出来”有两种：一种是假的，一种是真的。 |
| k9 | 假的那种，靠的是一时缺货：产能跟不上，黄牛在囤货。 |
| k10 | 2025年6月18日，Labubu全渠道补货。据媒体统计，热门款的二手价当天就跌了一半以上。 |
| k11 | 仿冒也来得很快：那一年，英国边境查获的假冒玩具里，九成是假Labubu。 |
| k12 | 当二手价本身就是信号，价格一跌，信号也跟着贬值。 |
| k13 | 真的那种，来自对手短期内追不上的东西。 |
| k14 | 比如爱马仕：皮具工匠入职，要先培训至少18个月；新工坊的计划，已经排到了2030年。 |
| k15 | 想多做，快不起来；想模仿，也买不来将近两百年的积累。 |

**第三关 · 稀释不了**（广泛可及性 vs 身份区分）

| 编号 | 旁白 |
|---|---|
| k16 | 第三关：稀释不了。这是大众身份品牌最难的一关。 |
| k17 | 用户越多，认得出的人越多，特别感却越少。普及先增强信号，再削弱信号。 |
| k18 | 所以投资者该问：多一个用户，会让下一个人更想买，还是更不想买？ |
| k19 | 奢侈品可以靠少卖守住区分，大众品牌不行，只能在规模里留出层次：苹果有Pro和标准版；山姆有一张会员卡，和一排排挑过的货架。 |
| k20 | 山姆是个特别好的例子。它给会员的感觉，不是“我买得起贵东西”，而是“我属于注重品质、懂得挑选的城市家庭”。 |
| k21 | 2025年7月，山姆下架了20多款口碑商品，换上了好丽友派这类到处都能买到的零食。 |
| k22 | 会员们炸了锅，有人说要退卡。山姆随后下架了争议商品。 |
| k23 | 一块派引起这么大的反应，说明很多会员担心的，是这张卡给自己的那份区分，被稀释了。 |

**最后一道算术 · 心理溢价能不能变成利润**

| 编号 | 旁白 |
|---|---|
| m1 | 三关都过了，还有最后一道算术：身份，能不能变成利润？ |
| m2 | 爱马仕把它变成了很高的价格：2025年，毛利率71%，经营利润率41%。 |
| m3 | 苹果走的是另一条路：2025年第四季度，苹果卖出的手机，大约占全球的四分之一，收入却拿走了将近六成。 |
| m4 | 这多出来的钱，不全是为身份付的，还有产品和生态。但只要每一部都卖得更贵，再乘上一年两亿多部，就是另一种定价权。 |
| m5 | 还要看这份认同是怎么来的：靠口碑传开的，新用户几乎不用花钱去拉；靠广告和补贴拉来的，每多一个用户，都要再花一次钱。 |
| m6 | 认同如果留不住钱，就只是热闹，不是护城河。 |

| 编号 | 旁白 |

| g1 | 带着这三道关，回头看开头的两家中国公司。 |
| g2 | 老铺黄金：认得出，商场门口排过长队。 |
| g3 | 仿不了吗？据报道，到2026年4月，它进驻的32家商场里，至少19家也开了其他古法金品牌。 |
| g4 | 稀释不了吗？据媒体11月走访，古法金门店大多在促销，老铺的力度最大，一款手镯减了将近2万元。 |
| g5 | 不过，它2026年上半年的利润，仍然增长了八成以上。 |
| g6 | 泡泡玛特：补货那天，Labubu的稀缺就打了折；三季度收入下降了将近一半，公司的解释是去年基数太高，加上正在优化海外库存。 |
| g7 | 但段永平偏偏在股价下跌时，买入了它5%以上的股份，还说10年内大概率不会卖。 |
| g8 | 一只玩偶的热度会退。一家公司能不能一次又一次，造出让人想拥有的身份，才是真正的考题。答案，交给时间。 |

| 编号 | 旁白 |
|---|---|
| q1 | 身份护城河还有一种失守，比什么都快：品牌背叛了用户的身份。 |
| q2 | 2025年9月，始祖鸟和艺术家蔡国强，在喜马拉雅山的山脊上放了一场烟花。 |
| q3 | 一个讲“敬畏自然”的户外品牌，在雪山上点燃了火药。舆论哗然，两天后，双方先后道歉。 |
| q4 | 人们会为身份多付钱，也会因为身份，转身离开。 |

## 06 · 答案

| 编号 | 旁白 |
|---|---|
| z1 | 最后，留给你一个问题。 |
| z2 | 如果你用它的时候，没有任何人知道，你还愿意多付同样多的钱吗？ |
| z3 | 如果愿意，你买的是品质；如果不愿意，你买的是别人的目光。两种都没有错。 |
| z4 | 这个问题，也是投资者的试金石：如果没人看见时，愿意多付的钱降得越多，说明身份在这个品牌里的分量越重。 |
| z5 | 但对投资者来说，贵只是一个标价，谁都能标。 |
| z6 | 认得出、仿不了、稀释不了，还能变成利润的身份，才是护城河。 |
| z7 | 当一个品牌成了你的一部分，对手要抢走的就不只是一笔订单，而是你对自己的理解。 |
| z8 | 品牌的最高境界，不是“我拥有它”，而是“它代表我”。 |
