## 一句话主线

**多付的钱，买的是“别人怎么看我”。地位是相对的，所以身份生意永远在认可、可及、区分之间拉扯；贵只是一个标价，谁都能标——认得出、仿不了、稀释不了，还能变成利润的身份，才是护城河；最深的那条，是品牌成了“我”的一部分。**

| 模块 | 说明 |
|---|---|
| `src/script.py` | 旁白脚本（配音文本 / 字幕文本分开写）与句前留白 |
| `src/tts.py` / `src/tts_single.py` / `src/voice_qc_single.py` | Seed-TTS 3.0；整篇一次合成 6 条择优 + 残余漂移小幅修正；一致性验收 |

| `src/music.py` / `src/mix.py` | 配乐时刻表与混音（−14 LUFS，真峰 −1.2 dBTP）|
| `src/video.py` | 竖版分镜（19 个场景函数）+ 片尾品牌动画 + 字幕 + 版面审计模式 |
| `src/video_h.py` / `build_h.sh` | 横版分镜（复用竖版的时间线、字幕切分和片尾粒子）；先跑 `build.sh` 再跑 `build_h.sh` |
