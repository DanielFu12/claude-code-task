## 一句话主线

**多付的钱，买的是“别人怎么看我”。它来自地位信号、从众、门槛三股力量，强弱是一道乘法，任何一项接近零就接近零；地位是相对的，所以身份生意永远在被认可、买得起、有区分之间拉扯；贵只是一个标价，谁都能标——认得出、仿不了、稀释不了，还能变成利润的身份，才是护城河；最深的那条，是品牌成了“我”的一部分。**
