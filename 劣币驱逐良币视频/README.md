## 一句话主线

> 当好的行为得不到奖励，坏的行为不必付出代价，问题就不再只是个人的道德，而是整个系统的激励。

片子按「侦探」结构展开，用一条线贯穿始终：**「你看不见」**。开头是五条近一年的真实热点（甲醛白菜、刹车踏板支架断裂、幽灵外卖、漂白鸡爪、保水虾仁），它们的共同点是质量藏在消费者看不见的地方。接着用一斤保水虾仁算清这笔账，再排查嫌疑人、找线索，揭示真凶（信息不对称）和作案机制（逆向选择的恶性循环），最后给出破局方法（让质量被看见、让诚实更赚钱）和投资启示（真正的护城河）。

## 品牌规范落实

全部按 `CLAUDE.md` 和 `brand/BRAND.md` 执行：

- **右上角角标**：全程由 `brand.Hud(scale=1.0, frame_w=1080).draw(frame, t)` 逐帧绘制，自带光晕、阴影和流光（每 7.5 秒一次，每次 1.4 秒）。角标在色调映射之后合成，保持品牌原色；片尾也一直保留，随整片最后的淡出一起消失。
- **片尾 logo**：只使用 `brand/logo_baman.png`，通过 `brand.load_logo()` 做预乘 alpha 缩放。粒子汇聚只把 logo 的透明通道当遮罩，最终显示的是原始 logo 图像，同样在色调映射之后合成，不会被辉光或调色改变。
- **片尾文字**：字体（`SPEC['title_font']` 和 `SPEC['sub_font']`）、金色渐变（`GOLD_STOPS`）、小字颜色（`SUB_GOLD`）、小字与主标题的间距（`sub_gap_px`），以及「BUFFETT · MUNGER」两端对齐到主标题等宽的规则，都由 `src/video.py` 的 `_brand_text()` 直接读取 `brand.py` 并按比例放大，复用 `brand._font`、`brand._ink`、`brand._ramp`。流光时长取 `SPEC['shimmer_dur']`，logo 光晕颜色取 `SPEC['glow_rgb']`。
- **文字动效**：关键句采用「放大 → 落定、运动模糊 → 清晰、字距收拢」的动态字；【】标记的关键词用金色渐变 + 辉光 + 下划线扫光强调；全片加入横向变形光斑（anamorphic streak）、透视地面网格和体积光。
- **参考文件缺失**：需求里提到的参考文件 `love_video/render.py` 在仓库所有分支和本机都不存在。片尾动画改为参考 `不开心视频/src/video.py` 的片尾实现，并按需求重新设计。

```bash
./build.sh   # 需要 ffmpeg 和 python3，以及 numpy、opencv-python-headless、pillow、soundfile、fonttools
```

四进程并行渲染约需 15 分钟。调试用法：

```bash
cd src

python3 run.py qa /tmp/qa.json 0 6948 10      # 检查文字是否越界、字体是否缺字
```

## 质检结果（基于最终成片）

- **时长与格式**：成片 3:51.6，1080×1920，30fps；AAC 48kHz，综合响度 −12.6 LUFS，真峰值 −0.7 dBFS。成片约 161MB，预览版约 28.6MB。
- **文字**：用 `run.py qa` 全片抽检，没有文字越出 40px 安全边距，也没有字体缺字。
- **音画同步**：9 个关键重拍处，画面跳变与音频起音的偏差在 +8 至 +64 ms 之间（最大 2 帧）。
- **黑屏**：开场 0.17 秒是淡入；`blackdetect` 另外标出 3 处 0.1–0.27 秒的极暗帧（2:23.0、2:31.0、3:36.2），都是新镜头文字逐字浮现的瞬间，画面上有背景和角标；片尾最后 0.3 秒是整片淡出。
- **音频**：没有中断，唯一一段静音是 3:49.8 之后配乐的自然收尾。
