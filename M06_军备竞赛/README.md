# M06《大家都加码，为什么可能谁也没多赚？》· 军备竞赛（竖屏版）

《50个自然法则，看懂商业世界》第 06 期。本期话题：**对手响应 / 投入升级 / 行业收益**。

- 成片：`M06_大家都加码为什么可能谁也没多赚_军备竞赛_竖屏.mp4`（**1080×1920 竖屏** · 30fps · 3:05 · 无人声，字幕叙事）
- 竖屏大字，延续 M03–M05 的手机观看布局：
  - 字幕 56–62 px，大字 72–100 px。
  - 画面主体放在上中部，字幕在中下部（约 y 1250），底部和右侧留给平台按钮与文案。
  - 右上角全程是 `brand.Hud(frame_w=1080)` 画的官方角标，直到整片最终淡出。
- 视觉：
  - 两方固定用霓虹青（A / 防御）和橙（B / 攻击）。
  - 三本账：企业利润用琥珀色，消费者收益用青绿，总需求用紫色；结论用品牌金。
  - 贯穿全片的意象是**两座交替加高的「投入塔」**：开场、第二章和终章都有，片尾粒子也从塔的方块出发。
  - 与前几期相同的炫光层：霓虹地面、极光、光斑、节拍光环、重拍镜头光、镜头推拉和统一调色。
- 配乐与音效全部为原创合成（`src/music.py`），没有外部采样：
  - 配乐：E 小调，和声走 i–VI–III–VII（Em–C–G–D），抽空段改走 iv–VI–III–V。
  - **1 拍 = 14 帧 = 0.4667 s（128.57 BPM）**，是系列里节奏最紧的一期，表现「你加一步、我跟一步」。每个拍点和转场都落在整数帧上。
  - 转场音效只用 sub drop、低频 boom、低沉膨胀和闷击。全部经过 4 阶 180 Hz 低通，实测 **99.996% 的能量在 200 Hz 以下**。不用白噪声、whoosh 或尖锐的上升音。
  - 每个音效都按所在位置的音乐响度自动压低，至少比音乐低 4 dB，起音对准转场那一帧。
  - 混音：整片约 −13.7 LUFS，峰值 −1 dBFS。

## 事实、出处与制作约束

| 内容 | 出处 / 处理方式 |
|---|---|
| 军备竞赛：一方的攻击或防御适应改变另一方的选择压力，后者的反适应可以形成升级；属于对抗性的共同进化 | 素材《01 军备竞赛事实核查》；Mark Ridley, *Evolution* 教材的 Coevolution 教程（核查卡指定来源） |
| 捕食者与猎物、攻防等级台阶图 | 核查卡要求“攻击与防御等级交替变化的模型；不暗示动物有意识制定战略”，所以画面标注“模型示意 · 不代表动物有意识地制定策略”，没有数值 |
| 三本账：企业利润、消费者收益、总需求分开看 | 核查卡“商业映射”：把企业利润、消费者收益与总需求分开 |
| 判断问题：追加投入是在创造新价值，还是主要在转移份额 | 核查卡“应用” |
| 主要限制：升级可以停滞、改变方向或受成本限制；研发不等于浪费；结果未必双输 | 核查卡“主要限制”，即抽空段的三个提醒 |
| 两家手机厂商 | **假设情景**。核查卡写明手机研发与平台补贴都是待核案例，所以没有点名真实公司，也没有任何金额或份额数字 |
| 巴菲特、芒格引语 / 企业财务数字 | 核查卡写明“本卡不使用”，本片遵守 |

与 M01（红皇后效应）的区别：M01 讲“跑得再快也只能留在原地”，以及怎样离开跑步机；M06 专门讲加码的钱**最后落到了谁手里**，用三本账区分企业利润、消费者收益和总需求。结尾按投资研究视角落到研究问题，不给买卖建议。
