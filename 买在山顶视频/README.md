## 事实与数据来源

片中标注的数据都核对过公开报道，走势图标了「示意」的只有被标注的点是真实数据：

- 2026：1 月新开户 492 万户（上交所，财联社）；5.11 科创50 收于 1716.69 点创历史新高；上半年新开户 2016.13 万户，同比 +60%（21 世纪经济报道）；6.23 两融余额 30009.71 亿元首破 3 万亿（财联社 / 证券时报）；截至 7.13 科创50 7 月以来跌约 11.18%，存储、光通信龙头较高点回撤超 30%（中国新闻周刊）；10.8 科创50 收跌 4.82%（21 世纪经济报道）。
- 创业板指：2026.6.25 盘中 4380.41 点创历史新高；7.28 收跌 7.35%，盘中较高点跌去 24.28%；7.30 抹平全年涨幅，较高点回落超 26%（北京商报、金融界、经济观察网）。
- 2015：6.12 上证 5178.19 点；6.18 融资余额约 2.27 万亿元；8 月下旬跌破 3000 点。
- 中国石油 A 股 2007.11.5 上市开盘 48.60 元，2026.8 约 11.23 元；思科 2000.3.27 高点 80.06 美元，2025.12.10 才收复；牛顿南海泡沫（Odlyzko, 2019）。
- 晨星（中国）《中国公募基金投资者回报差研究报告》（2025.5.22 发布，截至 2024.12.31 的五年期年化「投资者回报差」= 投资者年化回报 − 基金年化回报）：固收 −0.62、保守混合 −0.86、积极配置 −2.17、主动非行业股票 −2.65、行业基金 −3.59 个百分点。
  （初版曾引用《公募权益类基金投资者盈利洞察报告》的 16.67% 与 8.85%，但前者是基金业绩指数的 15 年年化、后者是客户累计平均收益率，口径不可比，已替换。）
- Tversky & Kahneman (1992) 损失厌恶系数约 2.25；Greenwood & Shleifer (2014) 投资者预期与此后回报负相关；纳斯达克 2000.3 5048 点 → 2002.10 1114 点（−78%）；《巴伦周刊》1999.12「What's Wrong, Warren?」。

## 重新生成

```bash
./build.sh        # 需要 ffmpeg、python3，以及 numpy、opencv-python-headless、pillow、soundfile、librosa
```

- `src/audio.py`：拼接背景音乐并输出节拍网格、四个重拍的位置、逐帧能量。
- `src/engine.py`：加色光 + 辉光的小型动态图形引擎（双线性亚像素粒子、抗锯齿线条、逐字动画文字）。
- `src/common.py`：音乐同步、情绪色调背景、旁白、章节界面、主角「你」。
- `src/scenes_a.py` / `scenes_b.py` / `scenes_c.py`：三幕分镜，每个 `s_*` 函数对应一段画面，都是时间 `t` 的纯函数。
- `src/film.py`：合成入口。`python3 src/film.py preview 17.5 93.7` 输出单帧，`python3 src/film.py sheet 0 265 2` 输出联系表。
