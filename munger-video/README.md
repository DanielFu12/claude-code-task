# 思维的格栅 —— 查理·芒格的世界模型（约 7 分钟）

与 `buffett-video/` 同一套代码生成的视频：Canvas 逐帧渲染画面、程序化合成配乐，
二者共享一条 90 BPM 的节拍时间轴，转场、文字与数字落点都卡在同一个拍上。

叙事主线（芒格把投资放进的那个更大的框架）：

多学科思维模型 → 避免愚蠢 → 判断企业质量 → 等待少数高胜率机会 → 长期复利 → 用同一套原则处理人生

| 段落 | 内容 |
| --- | --- |
| 开场 | “我只想知道将来我会死在哪里”——逆向思考；格栅（latticework）意象成形 |
| 总览 | 六步链条，价值投资只是其中一段 |
| 01 其人 | 早年经历、人生低谷、1959 年结识巴菲特、惠勒-芒格合伙公司（年化 19.8% vs 道指 5.0%）、1978 年任伯克希尔副董事长 |
| 02 格栅 | 锤子与钉子、多学科模型、鲁拉帕路萨效应、学习机器、可口可乐思想实验 |
| 03 逆向 | 雅可比“反过来想”、保证痛苦的处方、持续避免愚蠢、人类误判心理学、检查清单、铁律 |
| 04 能力圈 | 三个篮子（可以 / 不能 / 太难）、知道自己不知道什么 |
| 05 好生意 | 资本回报率决定长期回报、从烟蒂到优秀企业、喜诗糖果、“建筑师”与“总承包商”、好生意的特征 |
| 06 等待 | 彩池式赌注、等待、下重注、比亚迪与富国银行、坐着不动的投资法 |
| 07 复利 | 不要打断复利、三次腰斩、复利的力量与难度 |
| 08 人生 | 配得上、每天聪明一点、远离嫉妒怨恨报复自怜、职业三原则、辞世 |
| 结尾 | 芒格的世界模型、“我没什么要补充的” |

## 构建

```bash
./build.sh            # 生成 ../芒格投资理念-思维的格栅.mp4
```

预览单帧：`node render.js x --stills 60,200 --outdir /tmp`。右上角 logo 来自 `assets/logo.webp`（`assets/logo.js` 为其 data URL）。

内容仅供学习交流，不构成投资建议。
