# M01《产品越来越强，为什么优势却未必变大？》· 红皇后效应

《50个自然法则，看懂商业世界》第 01 期。本期话题：**绝对进步 / 相对优势 / 维持投入**。

- 成片：`M01_产品越来越强为什么优势却未必变大_红皇后效应.mp4`（1920×1080 · 30fps · 4:04.8 · 无人声，字幕叙事）
- 配乐与音效全部为原创合成（`src/music.py`），没有外部采样：
  - 配乐：100 BPM、D 小调。**1 拍 = 0.6 s = 正好 18 帧**，所以每个拍点、每个转场都落在整数帧上。16 分音符琶音贯穿全片，对应“一直在跑”。
  - 转场音效只用 sub drop、低频 boom、低沉膨胀和闷击。全部经过 4 阶 180 Hz 低通，实测 **99.99% 的能量在 200 Hz 以下**。不用白噪声、whoosh 或尖锐的上升音。
  - 每个音效都按所在位置的音乐响度自动压低，至少比音乐低 4 dB，起音对准转场那一帧。
- 右上角全程是 `brand.Hud` 画的官方角标，片尾 logo 用的是 `brand/logo_baman.png` 原图。品牌金色、字体、边距、流光参数都从 `brand/brand.py` 读取，没有另画。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、python3，以及 numpy scipy opencv-python-headless pillow soundfile
```

- `src/timeline.py`：节拍网格、音乐段落、重拍与转场时间点、全部字幕（全片唯一的时间来源）
- `src/music.py`：配乐和低频音效的合成与混音
- `src/video.py`：全部分镜（每个 `sc_*` 函数对应一段画面）以及片尾的 logo 粒子汇聚
- `src/engine.py`：小型“加色光 + 辉光”动态图形引擎（由 `不开心视频/src/engine.py` 扩展而来）
