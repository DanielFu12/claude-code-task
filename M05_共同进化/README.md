# M05《最好的产品，为什么不是一家公司做出来的？》· 共同进化（竖屏版）

《50个自然法则，看懂商业世界》第 05 期。本期话题：**双向适应 / 平台伙伴 / 生态互动**。

- 成片：`M05_最好的产品为什么不是一家公司做出来的_共同进化_竖屏.mp4`（**1080×1920 竖屏** · 30fps · 3:44 · 约 95 MB · 无人声，字幕叙事）
- 竖屏大字，延续 M03/M04 的手机观看布局：
  - 字幕 56–62 px，大字 66–100 px。
  - 画面主体放在上中部，字幕在中下部（约 y 1250），底部和右侧留给平台按钮与文案。
  - 右上角全程是 `brand.Hud(frame_w=1080)` 画的官方角标，直到整片最终淡出。
- 视觉：
  - 平台用霓虹青，伙伴用粉色；花用品红，传粉昆虫用青绿；「双向」和结论用品牌金。
  - 贯穿全片的意象是**双螺旋**：两条链代表双方，金色横档代表互相作用。它出现在标题、高潮和终章，片尾粒子也从它出发。
  - 与 M03/M04 相同的炫光层：霓虹地面、极光、光斑、节拍光环、重拍镜头光、镜头推拉和统一调色。
- 配乐与音效全部为原创合成（`src/music.py`），没有外部采样：
  - 配乐：A 小调，和声走 i–VI–III–VII（Am–F–C–G），抽空段改走 iv–VI–III–V。**1 拍 = 17 帧 = 0.5667 s（105.88 BPM）**，每个拍点和转场都落在整数帧上。
  - 转场音效只用 sub drop、低频 boom、低沉膨胀和闷击。全部经过 4 阶 180 Hz 低通，实测 **99.996% 的能量在 200 Hz 以下**。不用白噪声、whoosh 或尖锐的上升音。
  - 每个音效都按所在位置的音乐响度自动压低，至少比音乐低 4 dB，起音对准转场那一帧。
  - 混音：整片约 −13.3 LUFS，峰值 −1 dBFS。

## 事实、出处与制作约束

| 内容 | 出处 / 处理方式 |
|---|---|
| 共同进化：相互作用的种群对彼此施加选择压力，产生相互的演化响应 | 素材《01 共同进化事实核查》“本片采用的机制” |
| 相互选择、地理背景、多种共同进化结果 | John N. Thompson, “Four Central Points About Coevolution”, *Evolution: Education and Outreach*（核查卡指定来源） |
| 花与传粉者 | 核查卡写明“双向箭头仅作机制图；具体物种须另找对应研究”，所以画面标注“机制示意 · 不对应具体物种”，台阶图没有数值 |
| 主要限制：互利不是必要条件；共同进化也可以是对抗；生态依赖不自动等于共同进化 | 核查卡“主要限制”，即抽空段的三个提醒 |
| 手表平台与应用伙伴 | **假设情景**。核查卡写明 iOS 与开发者、微信小程序都是待核候选，而且要证明“双方改变对方而非同期增长”，所以没有点名真实公司 |
| 双向时间线检查表 | 核查卡“应用”：建立双方变化的时间线，并寻找反向影响证据；加上 Thompson 的地理背景与多种结果 |
| 巴菲特、芒格引语 / 企业财务数字 | 核查卡写明“本卡不使用”，本片遵守 |

结尾按投资研究视角落到研究问题（伙伴有没有反过来改变它），不给买卖建议。
