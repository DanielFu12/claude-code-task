# 企业盈利能力评估框架 · 10 分钟动态图形讲解视频

- 成片：`企业盈利能力评估框架.mp4`（1920×1080 · 30fps · 10:26 · H.264 两遍编码 + AAC 128k，控制在 GitHub 单文件 100MB 上限以内；仓库的 Git LFS 额度已满，所以按普通文件入库）。`./build.sh` 同时会在 `work/` 下生成 CRF 18 的高清母版（不入库）。
- 内容依据：《企业盈利能力评估框架（终版 · 2026 年 11 月）》——从巴菲特、芒格出发的六层评估框架（L0 生存 → L5 时间与演化），含统一公式、组合规则、八步流程和五个判别测试。
- 旁白：豆包 Seed-TTS 2.0「儒雅逸辰」男声，**整篇 3041 字一次合成、一条录完**（做法见 `claude/relaxed-thompson-azyyd4` 分支的 `docs/旁白一致性与自然衔接.md`）：一条语气提示贯穿全片；pYIN + Praat PSOLA 拉平长录音的音高漂移（每分钟中位数 117–123 Hz）；逐段子序列 DTW 对齐、在停顿正中切开；段内首尾相接，只在章节重拍处留白；本地 Whisper 逐段识别核对，没有漏读。
- 配乐：全部用 Python 现场合成的原创曲（`src/instruments.py` + `src/music.py`），120 BPM、D 小调，没有使用任何采样或现成音乐。
- 右上角全程挂「巴芒价值」品牌角标（`brand/`，带光晕和流光），片尾为大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」。

## 可读性

- 合成顺序：卡片底板和文字阴影在下，文字在上（早期版本底板压在文字之上，卡片里的字只剩约 45% 亮度）。
- 最小字号 28px；中小号文字自动加深色外描边与柔和阴影；3D 画布之上再叠文字，标签不会被价值体遮住。
- 竖版：场景标题不再缩小画进舞台，而是提取出来，以竖屏原生大字号排在舞台上方（主标题）和下方（副标题）。

## 核心意象：价值体

全片只讲一件事：**每股内在价值 ≈ [ 投入资本 + Σ 未来经济利润的现值 ] ÷ 股数**。为了让这条公式"看得见"，片中把它画成一块发光的 3D「价值体」：

| 维度 | 含义 | 对应的层 |
|---|---|---|
| 高度 | ROIC − WACC（超额回报） | 第二层 价值创造与获取 |
| 顶部被削掉的一层 | 维持竞争地位必须的开支 | 第三层 维持成本 |
| 厚度（逐年变化） | 投入资本，能否越做越厚 | 第四层 再投资 |
| 地板 / 放大 | 资本成本、杠杆、股数 | 第五层 资本与治理 |
| 长度 / 衰减 | 超额回报能持续多久 | 第六层 时间与演化 |
| 被一刀截断 | 永久性资本损失 | 第一层 生存（一票否决） |

旁白按「讲故事」的方式写成连贯口语稿：以喜诗糖果（印钞机）和航空公司（碎钞机）开场，到第三层再回扣喜诗；每一章用一个问句收尾、引出下一章（"钱，到底从哪里来？""保住它，要花多少钱？"……），在音乐重拍上给出答案。

## 制作流程

```
script.py ─▶ tts.py ─▶ timeline.py ─▶ music.py ─▶ mix.py ─┐
 旁白与提示点   逐句合成   排到 120BPM 网格   按小节编曲     闪避混音   ├─▶ ffmpeg 合成
                                     └──────────▶ video.py（scenes_a~d）┘
```

| 文件 | 作用 |
|---|---|
| `src/script.py` | 旁白脚本与章节；句中 `[cue]` 标记画面提示点 |
| `src/tts_take.py` | 整篇一次合成、拉平音高漂移、逐段 DTW 对齐切分与校验 |
| `src/check_vo.py` `src/voice_check.py` | 逐段语音识别核对；各章语速 / 音高、留白、人声与配乐响度差自检 |
| `src/tts.py` | 标点 ↔ 停顿的逐字对齐（用于把参考音频的字时刻映射到整篇录音） |
| `src/timeline.py` | 章节对齐小节线；提示点量化到八分音符，画面与卡点音效共用同一时刻；字幕切分 |
| `src/dsp.py` `src/instruments.py` | numba 加速的振荡器 / 滤波器 / 压缩 / 混响，以及二十多种合成乐器和音效 |
| `src/music.py` | 逐小节编曲：和声进行、能量自动化、军鼓滚奏、留白、冲击、卡点音效、侧链 |
| `src/mix.py` | 旁白放进同一个小房间（短混响 + 底噪）；闪避放在母带压缩之后（全频 −14 dB、人声频段再 −5 dB）；−14 LUFS |
| `src/engine.py` `src/common.py` | 加色光 + 辉光的动态图形引擎、图标与卡片部件、动态大字与章节过渡句 |
| `src/three.py` | 3D 相机、带遮挡的多边形画布、发光网格地面，以及核心意象「价值体」 |
| `src/scenes_a.py` ~ `scenes_d.py` | 全部场景（第二版）；`legacy_*.py` 是被复用的第一版图表组件 |
| `src/video.py` | 背景、章节卡、重拍特效、UI、字幕、角标、渲染入口 |
| `src/gemini_ear.py` | 制作中用 Gemini 试听评审音色、配乐和混音的小工具 |

## 重新生成

```bash
./build.sh            # 需要 ffmpeg、python3 及 numpy scipy numba opencv-python-headless pillow soundfile librosa pyloudnorm
```

单帧约 0.25 秒，4 进程并行整片约 25 分钟，最终两遍编码另需约 15 分钟。预览单帧或拼图：

```bash
python3 src/video.py frame 175.5 out.png
python3 src/video.py sheet sheet.png 30 100 175.5 300
```
