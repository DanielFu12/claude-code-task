# 滚雪球的人 —— 巴菲特投资思想进化史（约 5 分钟）

完全由代码生成的视频：画面（Canvas 逐帧渲染）与配乐（程序化合成）共享同一条节拍时间轴，
所以转场、文字出现、数字落定都与音乐卡在同一个拍点上。

| 文件 | 作用 |
| --- | --- |
| `timeline.js` | 唯一的时间轴：96 BPM，12 个场景的起止小节、内部切点、重音点、和弦进行、编曲层次 |
| `audio.js` | 合成配乐（Pad、钢琴、拨弦琶音、弦乐、底鼓/军鼓/太鼓、低频深邃转场声、混响），输出 48k/24bit WAV |
| `engine.js` | 渲染引擎：背景星云、逐字动画文字系统、转场特效、HUD 时间轴、暗角与颗粒 |
| `scenes.js` | 12 个场景的内容与画面（数据来自伯克希尔致股东信（截至 2025 年）等公开资料） |
| `render.js` | 用 Playwright 驱动 Chromium 多进程逐帧渲染并交给 ffmpeg 编码 |
| `build.sh` | 一键构建：字体 → 配乐 → 画面 → 合成 |

## 构建

```bash
./build.sh            # 生成 ../巴菲特投资理念-滚雪球的人.mp4
```

预览单帧：`node render.js x --stills 12.8,75 --outdir /tmp`。
