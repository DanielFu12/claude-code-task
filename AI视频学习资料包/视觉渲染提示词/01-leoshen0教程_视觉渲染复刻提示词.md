# 复刻提示词｜《leoshen0：文章转讲解视频工作流教程》视觉渲染风格

> 分析对象：X @leoshen0《把之前写的文章让 Opus 5.5 转成了视频》(16分10秒，1920×1080)
> 系列归属：Opus 5.5 代码渲染系列中的"教程/方法论"条目。与同系列科普成片（暗黑电影感）不同，
> 本片是**纸面推演风**：暖纸底 + 手绘矢量图解 + 逐笔生长动画，全程无真人、无 3D、无照片。

---

## 一、视觉风格分析（这条视频的渲染语言）

**整体基调：暖纸上的手绘推演。** 全片背景为统一的暖米纸色（约 #F6F1E7），带极淡的纸纹噪点。
所有图解都是 2D 矢量手绘风：1.5~2px 的细灰色描边（#8A8578）、圆角矩形框、虚线框、
手绘感箭头与花括号。没有任何照片、3D 渲染或渐变色块，像一本摊开的高级笔记本。

**色彩体系（严格三色）：**
- 纸底：暖米色 #F6F1E7（全片不变，禁止纯白 #FFFFFF）
- 墨色：深灰黑 #2B2B2B（正文）、中灰 #8A8578（描边、辅助线）
- 强调色：朱砂橙红 #E05A33（关键词高亮、勾选 ✓、流程箭头、章节号）——只用于"正在讲的那个点"

**字体排印系统（三级，中文无衬线，苹方 / Noto Sans SC）：**
1. 章节眉（左上小字）："05 Harness"、"06 上下文管理"——橙灰色小号，字间距宽，全程提示当前章节
2. 中央大标题：深灰黑色大字居中，如「死磕某个具体工具？」「MCP」「Agent Loop」，一屏只讲一个概念
3. 图解内文字：框内小字 + 关键词橙红高亮，如「**准备**上下文」「**废话**和**重点**混在一起」

**图解语言（本片的灵魂，四种固定构件）：**
- 流程图：圆角矩形节点 + 菱形判断框 + 橙色实线箭头（如 Agent Loop：调用模型→有工具请求？→执行工具→收集结果→回复）
- 对话框仿真：iOS 风格聊天气泡（灰底用户 / 白底 AI），用于演示"上下文"概念
- 大括号批注：右侧手绘大括号 + 竖排小字，如「上下文」括住系统提示词/会话记录/用户输入三项
- 虚线便签框：虚线圆角框 + ✓ 清单（如"保存话题记录 / 准备上下文"）

**镜头语言：** 几乎无运镜。转场靠"笔画生长"——线条按讲解顺序逐笔出现（stroke-dashoffset 动画），
框体淡入，关键词最后变橙红。节奏慢、稳，一屏一概念。

## 二、完整复刻提示词（给 Claude / Opus 等代码渲染智能体用，直接粘贴）

```
请用 HTML + SVG + CSS 动画的方式，渲染一条与参考视频完全相同的视觉风格的
教程讲解视频。先读懂下面的风格规范，全片严格遵守，不要自由发挥。


暖纸手绘推演风（warm paper sketch）。每一帧都应像摊开的高级笔记本：
暖米纸底、手绘矢量图解、细灰描边、朱砂橙红点睛。
禁止出现：纯白背景、照片、3D 渲染、渐变色块、霓虹/荧光色、圆角过大的卡片风。


- 全片背景 #F6F1E7，叠加极淡纸纹噪点（SVG feTurbulence，opacity 0.04）。
- 所有图形用 SVG：描边 #8A8578，stroke-width 1.5~2px，
圆角 rx=10px；轻微手绘抖动（可用 rough.js 或滤镜 feTurbulence + feDisplacementMap，scale 2）。
- 文字 #2B2B2B，字体：PingFang SC / Noto Sans SC，无衬线。


- 强调色 #E05A33 只用于：当前讲解的关键词、✓ 清单符号、
流程箭头、章节号。其他元素一律灰黑，绝不多用。


1. 章节眉（左上，x=48, y=44）：橙灰色小字，letter-spacing 4px，
如"06 上下文管理"，全程常驻，随章节切换。
2. 中央大标题：#2B2B2B，96px，加粗，居中，一屏只放一个概念
（如「死磕某个具体工具？」），下方可配一行小字副标题。
3. 图解内文字：框内 40px；关键词用 #E05A33 加粗高亮。
4. 底部解说：42px 深灰，居中，每句一屏，随旁白切换。


A. 概念引入卡：中央大标题 + 一行小字定义，元素逐个淡入。
B. 流程图：节点按讲解顺序逐个出现，连接箭头用 stroke-dashoffset
做"生长"动画（1.2 秒/条），当前节点描边变橙红。
C. 对比演示：左右两块面板 + 右侧手绘大括号批注，
大括号最后出现，把三项圈成"上下文"。
D. 清单便签：虚线圆角框从上方落入，✓ 逐条打出（橙红），
每条间隔 0.4 秒。
E. 收束：回到中央大标题，关键词橙红，结束。


单镜头 8~15 秒，无运镜。元素动画只用三种：淡入（0.5s）、
笔画生长（1.2s）、落入（0.4s ease-out）。转场：0.4 秒纸色淡入淡出。


1920×1080，30fps。每一镜渲染为 PNG 序列（或直接录制 HTML 动画），
最后 FFmpeg 合成并压字幕。
```
