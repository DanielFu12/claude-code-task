## 一、视觉风格分析（这条视频的渲染语言）

**整体基调：黑暗中的奢侈品。** 背景为极深的黑（约 #05070C），全片铺一层极淡的点阵网格
（dot grid，opacity 0.06），像高级纸张的暗纹。画面元素极少，每一镜只讲一个意象：
一个发光的「场」字、一束地球磁感线、一条光谱带。留白即语言。

**色彩体系（黑 + 烫金 + 冰蓝）：**
- 背景：#05070C + 点阵网格（#FFFFFF，opacity 0.05~0.08）
- 烫金 #D4A94E：书法大字（场/贰）、描边方框、章节线——只用于"神圣"的元素
- 冰蓝 #9FD8E8：磁感线、波形线、干涉条纹——代表"场"本身
- 白 #F5F5F5：正文；彩虹色仅出现在光谱可视化一条带中，别处禁用

**字体排印系统（四级，衬线中文 + 宽字距英文）：**
1. 书法大字：烫金、发光、巨大（300px+），如开场的「场」、章节的「贰」，
字体为书法/宋体变体（Noto Serif SC Black），带柔光晕
2. 英文小 caps：字间距极宽（letter-spacing 12px），如 "F I E L D"、
"Strong force / GLUONS · YUQI"，32px，灰白，永远配在中文下方
3. 章节标题：如「场的量子化」，白色 64px 居中，下方一条细金线 + 更小的英文
4. 底部双语字幕：中文 48px 白 + 下方 28px 灰色英文，全大写或小 caps，居中

**视觉母题（每镜一个，绝不堆叠）：**
- 发光细线场：地球磁感线（冰蓝，数百条贝塞尔曲线从两极发散）、波干涉同心圆
- 光谱带：一条横向彩虹渐变带 + 下方七个中文标签（无线电/微波/红外/可见光/紫外/X射线/γ射线）
- 点阵时间线：2012（希格斯发现）一个金点落在横向点阵轴上
- 夸克胶子图：红绿蓝三色发光节点 + 白色键线，极简
- CMB 质感帧：一整屏暖色噪点（宇宙微波背景），唯一的"满幅"镜头

**镜头语言：** 几乎静止。元素淡入后只做极慢的呼吸缩放（scale 1.0→1.03，10 秒）。
转场全靠黑场淡入淡出（1.5 秒），仪式感拉满。

## 二、完整复刻提示词（给 Claude / Opus 等代码渲染智能体用，直接粘贴）

```
请用 HTML Canvas 2D + Three.js（仅用于磁感线等曲线）的方式，
渲染一条与参考视频完全相同的视觉风格的物理学科普视频。
先读懂下面的风格规范，全片严格遵守，不要自由发挥。


极简物理美学（minimalist physics luxury）。每一帧都应像奢侈品广告：
极深黑底、发光细线、烫金书法、大量留白。
禁止出现：浅色背景、实物 3D、卡通、多种高饱和色并存、拥挤排版。


- 背景 #05070C；全片叠加点阵网格（Canvas 绘制圆点，间距 48px，
半径 1px，#FFFFFF opacity 0.06）。
- 发光：Canvas shadowBlur 30 + 三次叠画同路径（opacity 0.9/0.4/0.15），
或 Three.js UnrealBloomPass（strength 0.7, threshold 0.8）。
- 线条：1~2px，冰蓝 #9FD8E8（场线）/ 烫金 #D4A94E（装饰线）。
- 磁感线：300~500 条三次贝塞尔曲线，从球体两极发散，
用 requestAnimationFrame 做缓慢流动（dash offset 动画）。


- 烫金 #D4A94E：书法大字、章节线、描边方框；
- 冰蓝 #9FD8E8：一切"场"的可视化线条；
- 文字白 #F5F5F5，说明灰 #A8A8A8；
- 彩虹色只允许出现在光谱带可视化中。


1. 书法大字：Noto Serif SC Black，320px，#D4A94E，
shadowBlur 60 同色，居中，独占一屏（如「场」）。
2. 英文小 caps：letter-spacing 14px，32px，#C9C9C9，
永远在中文标题下方（如 "F I E L D"）。
3. 章节：书法字（如「贰」）120px + 白色标题 64px「场的量子化」+
下方 60px 宽 2px 金线 + 28px 英文。
4. 底部双语字幕（y=980 居中）：中文 48px #F5F5F5；
下方英文 26px #A8A8A8，letter-spacing 3px。


A. 开场：黑场 → 点阵浮现 → 烫金「场」字从暗到亮（3 秒）→
下方 "F I E L D" 淡入 → 停留 4 秒。
B. 场线：冰蓝磁感线在黑色球体周围缓缓流动，底部字幕讲解。
C. 光谱：一条横向彩虹带从左向右"点亮"（渐显 3 秒），
下方七个标签逐个浮现。
D. 时间点：横向点阵轴 + 2012 金点落下 + 涟漪扩散。
E. 微观：夸克三色节点 + 白色键线，轻微浮动。
F. 收束：回到书法字构图，呼应开场。


镜头：静止或 10 秒内 scale 1.00→1.03 的呼吸。
转场：黑场淡入淡出 1.5 秒。全片禁止推拉摇移。


1920×1080，30fps。Canvas/Three.js 渲染 PNG 序列 + HTML 文字层，
FFmpeg 合成。
```
