## 一、视觉风格分析（这条视频的渲染语言）

**整体基调：暗黑宇宙中的思想星图。** 全片背景为近乎纯黑（约 #05070A），漂浮着极淡的星尘噪点。
画面主体永远是"发光的点与线"：二进制数字带、神经元节点、粒子网络，全部带辉光（bloom），
在黑暗中如星座般亮起。几乎没有实物渲染，抽象、克制、诗意。

**色彩体系（黑 + 双辉光色）：**
- 背景：纯黑 #05070A（全片不变，带细微星尘）
- 暖金 #E8B34B：神经元节点、关键连线、年份数字——代表"被点亮的思想"
- 冰青 #7FD4E8：次级节点、数据点、辅助连线——代表"计算/数据"
- 文字白 #F2F2F2；说明文字灰 #9A9A9A

**字体排印系统（三级）：**
1. 年份（右侧大字）：白色大号数字（如 1943 / 1958 / 1986 / 2012 / 2016）+ 下方中文事件名
（如"人工神经元"/"感知机"/"反向传播"/"深度学习爆发"/"AlphaGo"）+ 更小的灰色英文/说明
2. 中央书法标题：结尾「涌现」二字，白色衬线/书法体，带柔光，大字独占一屏
3. 顶部细线装饰：画面上下有极细的灰色刻度线，营造"时间轴/胶片"感

**视觉母题（全片只用三件套，重复变奏）：**
- 二进制带：0/1 数字组成透视长带，向画面深处延伸（开场）
- 节点网络：发光圆点 + 细连线，缓慢呼吸明灭（代表神经网络/涌现）
- 年份事件卡：右侧大年份 + 左侧对应可视化（如 1958 感知机的二维点阵分类面）

**镜头语言：** 极慢的推镜与横移，几乎静止；转场靠"亮起/熄灭"——旧年份的网络暗下去，
新年份的亮起来。2 分钟讲完 70 年，节奏如潮汐。

**水印：** 左上常驻「一条sgf bilibili」（复刻时去掉）。

## 二、完整复刻提示词（给 Claude / Opus 等代码渲染智能体用，直接粘贴）

```
请用 Three.js + HTML 文字叠加的方式，渲染一条与参考视频完全相同的视觉风格的
AI 史诗短片。先读懂下面的风格规范，全片严格遵守，不要自由发挥。


暗黑思想星图风（dark constellation）。每一帧都应像深夜天文馆：
纯黑宇宙、发光节点与连线、缓慢呼吸、极度克制。
禁止出现：浅色背景、实物 3D、卡通、彩虹色、复杂 UI。


- Three.js，深黑背景 #05070A；开启 UnrealBloomPass
（strength 0.9, radius 0.5, threshold 0.7），只让发光点线溢出。
- 节点：Sprite/Points，暖金 #E8B34B（主）/ 冰青 #7FD4E8（次），
size 0.03~0.08，additive blending；连线用 LineBasicMaterial，
opacity 0.25，颜色跟随端点。
- 全片漂浮 200 个星尘（白色，opacity 0.15，极慢漂移）。
- 节点明灭：正弦呼吸动画，周期 4~6 秒，相位随机。


- 背景 #05070A；文字白 #F2F2F2；说明灰 #9A9A9A；
- 暖金 #E8B34B：主节点、年份数字、关键连线；
- 冰青 #7FD4E8：次节点、数据点。


1. 年份（右侧，x=1450）：白色 120px 数字（如"1943"），
下方 56px 中文事件名（如"人工神经元"），再下方 32px 灰色说明。
年份切换时旧数字淡出、新数字从下方升起。
2. 中央标题（结尾）：「涌现」白色衬线体（Noto Serif SC Black）280px，
text-shadow 0 0 60px rgba(255,255,255,.4)，独占一屏 4 秒。
3. 上下细线：画面顶部 y=40 与底部 y=1040 各一条 1px #2A2A2A 横线，
线上带等距微小刻度，全程常驻。


A. 开场：二进制 0/1 数字带从近处向远处延伸透视，镜头极慢前推，
数字逐个亮起。
B. 年份事件：右侧年份卡 + 左侧对应网络可视化（如感知机=二维点阵+
一条发光分类直线；反向传播=分层节点+反向流动的光点）。
C. 高潮：全屏节点网络同时亮起、连线暴涨（代表"涌现"），
持续 3 秒后缓缓暗下。
D. 收束：黑场中央「涌现」二字亮起，呼吸两次，结束。


镜头：每镜 10~15 秒，速度低于 0.2 米/秒的推镜或完全静止。
转场：交叉淡化 1.2 秒，或"亮起/熄灭"（opacity 动画）。


1920×1080，30fps。Three.js 渲染 PNG 序列 + HTML 文字层，
FFmpeg 合成。去掉任何水印。
```
