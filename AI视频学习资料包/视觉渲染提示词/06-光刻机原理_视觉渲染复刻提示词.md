## 一、视觉风格分析（这条视频的渲染语言）

**整体基调：暗黑电影感科技风。** 全片背景为近乎纯黑的深蓝黑（#06090D），所有物体都是 Three.js PBR 写实渲染：金属拉丝、硅片镜面、玻璃透光，配电影级三点布光（主光+紫色轮廓光+青色补光）、ACES 色调映射、Bloom 辉光后期。画面永远有悬浮尘埃粒子和浅景深，营造"太空实验室"感。

**色彩体系（严格三色+点缀）：**
- 主色：纯白文字 #FFFFFF、深黑背景 #06090D
- 强调色：薰衣草紫 #B388FF（章节号、副标题、下划线、标注引线、光束）
- 辅助色：冰青色 #8FD4DC（标注引线、发光细节）
- 点缀色：琥珀金（光刻胶 #C08A3E）、青蓝（硅片 #3E8FA3）、炽红（激光 #FF5A3C）——只用于物体本身，不用于文字

**字体排印系统（四级，全部用思源黑体 Bold / Noto Sans SC Bold）：**
1. 章节眉（左上常驻）：紫色数字 "01" + 白色标题 + 紫色下划线，如「01 从沙子到晶圆」
2. 大标题卡（居中）：超大白色粗体带微辉光 + 紫色副标题，如「EUV 光刻机 / 人类造过的最精密的机器之一」
3. 底部解说字幕：白色大粗体居中，带轻微阴影，全程跟随旁白
4. 标注标签：黑色半透明圆角矩形 + 白字 + 紫色左侧竖条，引出细引线（末端白色圆点）指向部件；数据 HUD 为右上黑色药丸，如「已曝光 10 / 64 个区域」

**镜头语言：** 缓慢推轨（dolly-in）、环绕运镜、微距特写；转场靠"拆机透视"——外壳变玻璃半透明露出内部光路（X-ray 剖视）；光束永远是加了辉光的白色/紫色发光体。

**信息图风格：** 深色底 + 大号半透明公式（如「分辨率 ≈ k₁ × λ / NA」）+ 横向时间条（g线 436nm→EUV 13.5nm，配 1980s/1990s/2000s/2019起 年代标签）。

## 二、完整复刻提示词（给 Claude / Opus 等代码渲染智能体用，直接粘贴）

```
请用 Three.js + HTML 文字叠加的方式，渲染一条与参考视频完全相同的视觉风格的
科技讲解视频。先读懂下面的风格规范，全片严格遵守，不要自由发挥。


暗黑电影感科技风（dark cinematic tech）。每一帧都应像高端科技发布会 CGI：
深黑背景、写实 PBR 材质、电影三点布光、辉光后期、悬浮尘埃粒子、浅景深。
禁止出现：白色/浅色背景、扁平卡通、渐变彩虹色、照片级人物。


- Three.js，开启 ACESFilmicToneMapping，exposure 1.1；开启 UnrealBloomPass
（strength 0.6, radius 0.4, threshold 0.85），只让发光体和轮廓光溢出。
- 所有物体使用 MeshStandardMaterial / MeshPhysicalMaterial：金属度 0.9、
粗糙度 0.25~0.4；玻璃/外壳用 MeshPhysicalMaterial（transmission 0.9，
thickness 2, roughness 0.05）做 X-ray 透视。
- 地面：深色高反光地板（roughness 0.15），反射出物体底部的霓虹光带。


- 主光：顶部白色聚光灯，强度 3，带柔和阴影。
- 轮廓光：紫色（#B388FF）从后方左右打，强度 2，让物体边缘镶上紫边。
- 补光：青色（#8FD4DC）低强度 0.6 从侧前方补。
- 环境：RoomEnvironment，environmentIntensity 0.25。


- 背景 #06090D；正文文字纯白 #FFFFFF；
- 强调紫 #B388FF：章节号、副标题、下划线、标注引线、光束；
- 冰青 #8FD4DC：次级引线、发光细节线；
- 物体点缀色仅用于 3D 物体本身：光刻胶琥珀金 #C08A3E、硅片青蓝 #3E8FA3、
激光炽红 #FF5A3C。文字绝不使用点缀色。


全片漂浮 150~300 个微尘粒子（PointsMaterial，size 0.02~0.05，白色，
opacity 0.5，additive blending），缓慢布朗运动，营造太空实验室感。


1. 章节眉（左上，x=60, y=60 常驻）：紫色加粗数字（如"01"，96px）+
白色标题（64px，加粗）+ 其下方 6px 高紫色下划线（宽 420px）。
2. 大标题卡（画面中央）：白色 150px 加粗，text-shadow 0 0 30px rgba(255,255,255,.35)；
下方紫色副标题 56px。用于开场提问与每个大设备亮相。
3. 底部解说字幕（y=950 居中）：白色 64px 加粗，
text-shadow 0 2px 12px rgba(0,0,0,.9)，每句单独一屏，随旁白切换。
4. 部件标注：黑色圆角矩形（rgba(0,0,0,.72)，radius 12px，padding 18px 28px），
白字 44px 加粗，左侧 8px 紫色竖条；从标签引出 2px 紫色引线，
末端 10px 白色圆点，精确指向 3D 部件。
5. 数据 HUD（右上药丸）：rgba(0,0,0,.6) 圆角胶囊，白字 40px，
如"已曝光 10 / 64 个区域"，数字滚动更新。


A. 开场提问卡：宏大 3D 物体特写（芯片剖面层）为背景慢速环绕，
中央大标题 + 紫色副标题。
B. 设备亮相：整机 3/4 视角，缓慢 dolly-in，大标题卡叠加，
地面反射出底部霓虹光带。
C. 拆机透视（X-ray）：外壳渐变为玻璃半透明，内部出现加了辉光的
白色/紫色光束，按流程折线传播；每个节点用"标注标签"指出
（光源→掩模版→投影物镜→晶圆）。
D. 微观工艺：等距微距视角展示材料变化（锡滴被红色激光击中爆出
等离子体闪光；晶圆高速旋转甩开金色光刻胶；离子注入用青色
发光柱阵列下落）。
E. 数据图：深色底，大号半透明公式居中，横向时间条
（灰条 + 白字参数 + 右侧年代），下方配芯片阵列 3D。
F. 收束：拉远到第一帧的宏大视角，呼应开场。


全片只用三种：缓慢 dolly-in（每镜 0.5~1.0 米）、15~30 度环绕、
微距 push-in。单镜头时长 6~10 秒，运镜速度均匀无急停。
转场：硬切 + 0.3 秒黑场，或 X-ray 渐变（opacity 动画 0.8 秒）。


1920×1080，30fps，H.264。每一镜分别渲染 PNG 序列，
HTML 文字层单独渲染为透明 PNG 序列，最后 FFmpeg 合成并压字幕。
```
