## 一、视觉风格分析（这条视频的渲染语言）

**整体基调：午夜实验室的霓虹蓝图。** 背景纯黑（约 #030507），一切物体都是"线框"：
双缝实验的青色网格板、光锥的白色经纬线、希格斯势的金色"墨西哥帽"线框。
没有面，只有发光的线——Tron 式的工程美学，但比 Tron 更克制、更学术。

**色彩体系（黑 + 三霓虹色，各司其职）：**
- 背景：纯黑 #030507
- 青 #6FE3F5：实验装置线框（双缝板、波函数曲线）、主视觉线
- 金 #F5C86E：希格斯场/势阱、能量相关、强调曲线
- 品红/紫 #C86FF5：叠加态第二条曲线、量子涨落点
- 白 #FFFFFF：公式、关键中文词；公式用白色手写体感，极具"黑板"味

**字体排印系统（四级）：**
1. 霓虹中文大字：如开场「量子」（白色，带横向光 streaks）、结尾「人」
（冰蓝色霓虹，280px）——每片只出现 2~3 次，用于情绪锚点
2. 公式（右上/中央）：白色数学公式，如 |ψ⟩=α|ψ₁⟩+β|ψ₂⟩、E²=(pc)²+(mc²)²、
S=E(a,b)−E(a,b′)+E(a′,b)+E(a′,b′)、V(φ)=−μ²φ²+λφ⁴，字体偏手写衬线
3. 章节号（左上小字）："Ⅱ 量子纠缠"、"Ⅳ 标准模型"、"Ⅴ 希格斯场"、
"Ⅶ 量子计算"、"Ⅷ 量子计算"——灰白色小字，罗马数字 + 中文
4. 底部双语字幕：中文 50px 白居中 + 下方 28px 灰英文，如
「把电子一个一个，射向两条缝。」/ Fire electrons, one by one.
5. 数据 HUD：右上/中央小字读数，如 "S = 2.828"（青色发光）、"W432"、
"n=4 l=3 m=2"、仪表盘、1972/1982/2015/2022 时间轴——营造"实验进行中"感

**视觉母题：**
- 线框装置：双缝板（青色网格 + 两条缝 + 电子光点逐个射出）
- 光锥：白色经纬线双锥 + 顶部公式 E²=(pc)²+(mc²)² + 底部"一朵云"粒子
- 墨西哥帽：金色线框势阱 + 中央小球滚落动画（希格斯机制）
- 波函数：青/品红两条发光正弦曲线在透明盒中交织（叠加态）
- 概率云：品红/青色光点在网格面上起伏（量子涨落）

**镜头语言：** 线框物体缓慢旋转展示（15~30°），镜头极慢推近；
电子/光点沿路径运动是主要动效。转场：黑场硬切为主，偶尔用光点拖尾过渡。

## 二、完整复刻提示词（给 Claude / Opus 等代码渲染智能体用，直接粘贴）

```
请用 Three.js + HTML 文字叠加的方式，渲染一条与参考视频完全相同的视觉风格的
量子力学讲解视频。先读懂下面的风格规范，全片严格遵守，不要自由发挥。


霓虹蓝图风（neon blueprint）。每一帧都应像午夜实验室的全息蓝图：
纯黑底、发光线框、无实面、公式如粉笔字。
禁止出现：浅色背景、实心 3D 物体、照片、卡通、多余装饰。


- Three.js，纯黑背景 #030507；UnrealBloomPass
（strength 0.85, radius 0.45, threshold 0.75）。
- 一切物体只用线框：WireframeGeometry / LineSegments / EdgesGeometry，
线宽 1~2px，颜色按分工取用三霓虹色。
- 发光材质：LineBasicMaterial + bloom；运动光点用 additive Sprite。
- 网格地面：GridHelper，#1A2A35，opacity 0.35，只在需要空间感时出现。


- 青 #6FE3F5：实验装置、主曲线；
- 金 #F5C86E：希格斯/能量相关；
- 品红 #C86FF5：叠加态第二曲线、涨落点；
- 公式与关键中文：白 #FFFFFF；
- 背景 #030507。一种元素只用一种颜色，绝不混用。


1. 霓虹大字：白色/冰蓝，280px，加粗，强辉光，
全片只用 2~3 次（如开场「量子」、结尾「人」）。
2. 公式：白色，72px，衬线/手写感（如 'STIX Two Math'），
置于右上或中央空白处，逐符号淡入。
3. 章节号（左上，x=48, y=44）：灰白 36px，
罗马数字 + 中文（如"Ⅴ 希格斯场"）。
4. 底部双语字幕（y=960 居中）：中文 50px 白加粗；
下方英文 28px #9A9A9A。
5. 数据 HUD：36px 等宽字体，发光青/金，
如"S = 2.828"，置于画面空白处，随实验进度更新。


A. 装置亮相：线框装置从黑暗中淡入，缓慢旋转 20°，
章节号与公式浮现。
B. 粒子发射：光点沿路径逐个运动（如电子穿过双缝），
拖尾 0.5 秒，代表"一个一个"。
C. 势阱演示：金色墨西哥帽线框 + 小球从帽顶滚落，
底部"一朵云"粒子泛起。
D. 数据时刻：仪表盘/时间轴 HUD 出现，读数滚动到目标值
（如 S = 2.828），停留 3 秒。
E. 收束：全黑 → 冰蓝霓虹「人」字亮起 → 字幕收束。


单镜头 8~12 秒，线框旋转展示 + 光点运动。
转场：黑场硬切，或光点拖尾 0.6 秒过渡。


1920×1080，30fps。Three.js 渲染 PNG 序列 + HTML 文字层，
FFmpeg 合成。
```
