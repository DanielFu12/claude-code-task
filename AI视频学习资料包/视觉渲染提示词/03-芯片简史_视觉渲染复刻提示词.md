# 复刻提示词｜《Opus5.5·芯片简史》视觉渲染风格

> 分析对象：X @AndyL5cc《Opus 5.5 又给我看傻了·芯片简史》(3分29秒，1920×1080，60fps)
> 系列归属：Opus 5.5 代码渲染系列。本片是"暖金工业史诗"风：Three.js 写实 PBR 渲染，
> 从爱迪生灯泡的暖光一路讲到 EUV 光刻的紫光，用发光大数字锚定每个时代的关键参数。

## 一、视觉风格分析（这条视频的渲染语言）

**整体基调：暖金色的工业浪漫主义。** 与同系列光刻机视频的冷黑紫不同，
本片主色调是**暖**的：钨丝灯泡的琥珀辉光、真空管工厂的金色穹顶、灯丝特写的炽白。
后半段进入半导体时代才转入深蓝 + 紫外光的冷调，形成"从火到光"的色彩叙事弧。

**色彩体系（随时代漂移）：**
- 前半（1906~1957）：琥珀金 #E8963C / 炽白 #FFF3D6（灯丝、真空管、工厂灯光）+ 深褐黑背景
- 后半（晶体管→EUV）：深海军蓝 #0A1420 背景 + 紫外紫 #7B5CFF（光刻机）+ 晶圆 iridescent 彩虹衍射色
- 恒定：发光大数字纯白 #FFFFFF（带辉光）、说明文字灰 #B8B8B8

**字体排印系统（四级，中英双语）：**
1. 年份（右上）："1906" / "1957" 白色大号 + 下方小字英文小 caps（如 VACUUM TUBE / SILICON VALLEY）
2. 发光大数字（画面中央偏左/右）：如「17,468个」「30吨」「9×15米」「150千瓦」「×2²⁵」「157nm」
「50,000颗/秒」——白色 130px+ 带强辉光，是每镜的视觉锚点
3. 底部双语字幕：中文白色粗体 54px 居中 + 下方小一号灰色英文，一一对应
4. 部件标注：细引线（1px 白/紫）+ 小字标签指向设备部件（如"镜片的玻璃就把光吸收"）

**3D 渲染语言：**
- 灯泡/真空管：玻璃 MeshPhysicalMaterial（transmission 高）+ 内部钨丝 emissive 炽白，
Bloom 拉满，暗部几乎纯黑——"黑暗中一盏灯"的经典构图
- 工厂：大跨度穹顶 + 暖色顶灯阵列 + 地面反射，微距仰拍
- 晶圆：一整片圆形晶圆，表面做 iridescent 衍射彩虹材质，镜头缓慢旋转
- 光刻机：深蓝空间 + 紫色辉光镜筒 + 悬浮标注

**镜头语言：** 缓慢推轨 + 微距特写 + 旋转展示；转场多用"光晕闪白"（灯丝点亮瞬间切镜）。
60fps 让粒子与光晕流动极顺滑。

## 二、完整复刻提示词（给 Claude / Opus 等代码渲染智能体用，直接粘贴）

```
请用 Three.js + HTML 文字叠加的方式，渲染一条与参考视频完全相同的视觉风格的
芯片历史讲解视频。先读懂下面的风格规范，全片严格遵守，不要自由发挥。


暖金工业史诗风（warm industrial epic）。每一帧都应像 IMAX 工业纪录片：
写实 PBR、戏剧性明暗、强辉光、浅景深。
禁止出现：扁平卡通、浅色背景、霓虹乱色、廉价塑料质感。


- Three.js，ACESFilmicToneMapping，exposure 1.2；
UnrealBloomPass（strength 0.8, radius 0.5, threshold 0.8）。
- 灯丝/钨丝：emissive #FFF3D6，emissiveIntensity 5；
玻璃罩：MeshPhysicalMaterial，transmission 0.95，roughness 0.05，thickness 1.5。
- 金属：metalness 0.9，roughness 0.3；晶圆表面加 iridescence（1.0，iridescenceIOR 1.8）。
- 地面：深色镜面反射（roughness 0.1），映出顶部灯光。


- 主光：暖色点光源（#FFB347，强度 4）置于发光体内部——光从物体里长出来。
- 轮廓光：冷青 #4A7FA3 从后方打，强度 1.2，分离主体与黑背景。
- EUV 段落切换为紫色主光 #7B5CFF。
- 全片悬浮 100~200 金色尘埃粒子，additive blending，缓慢上升
（象征"热/能量"）。


色彩叙事弧（必须遵守）：1906~1957 段全暖（琥珀金主导）→
晶体管段加入深蓝 → 光刻机段转为紫外紫。让观众"看到"从火到光。


1. 年份（右上，x=1700, y=70）：白色 96px + 下方 30px 灰色英文小 caps，
如「1906 / VACUUM TUBE」。
2. 发光大数字：白色 140px 加粗，text-shadow 0 0 40px rgba(255,255,255,.5)，
每镜只放一组（如「17,468个」「×2²⁵」「157nm」），位置居左或居中。
3. 底部双语字幕（y=960 居中）：中文 54px 白色加粗；
下方英文 30px #B8B8B8，一一对应。
4. 部件标注：1px 引线（白/紫）+ 36px 小字标签，末端圆点指向部件。


A. 时代开场：黑暗中一件发光体特写（灯泡/真空管/晶圆），
慢推 8 秒，右上年份浮现。
B. 数据锚点：发光大数字 + 对应 3D 场景（如 17,468个→真空管阵列工厂）。
C. 微观剖视：镜头穿入物体内部（灯丝/芯片层），X-ray 式半透明。
D. 色彩转折：钨丝熄灭 → 一帧黑 → 紫外紫亮起，进入光刻机段落。
E. 收束：回到第一帧的灯泡，但拉远——灯泡放在一小堆沙子上
（"从沙子来"的呼应），字幕收束。


60fps 渲染。单镜头 6~10 秒，匀速推轨/旋转，无急停。
转场：光晕闪白 0.4 秒，或硬切。


1920×1080，60fps，H.264。PNG 序列 + HTML 文字层，FFmpeg 合成。
```

## 四、本片章节结构（复刻时可直接套用节奏）
