# S5 · 霓虹全息光谱（Neon Holographic Spectrum）

> 本文件只描述**渲染风格**，不含任何具体选题。示例文字一律用〔占位符〕，套用时换成新视频自己的内容。

## 1. 一句话定位

纯黑虚空里的高饱和霓虹：粗发光曲线、细线框立方体、渐变网格曲面、会爆散重组的粒子文字，加上重 bloom、色差和横向变形光斑。像一台全息投影仪在黑暗中演示抽象原理，炫、亮、有能量感。

**适合**：抽象原理/数学/机制的可视化、"反直觉"类内容、需要视觉冲击的 3~6 分钟片子。
**不适合**：需要沉稳、写实、温暖感的内容；有大量文字说明的教程。

## 2. 画面基调

- 实测中位背景色 `#000103`（纯黑），但亮部很亮（90% 分位亮度约 99），色彩跨度最大：一屏内常同时有青、品红、金三色。
- 发光物是"霓虹管"：线条粗、饱和度高、核心接近白色、外晕是本色。
- 比 S2 节奏快：约 14 次硬切/闪白切，其余是粒子爆散重组和光线扫过。
- 粒子文字是本风格的签名：关键汉字由闪烁的蓝白粒子组成，可以笔画形变、爆散、再聚成新字。

## 3. 色彩 Token

| 角色 | 色值 | 用法 |
|---|---|---|
| 背景 | `#000103` | 全片 |
| 霓虹青 | `#4FE0FF` / 中 `#71B2D2` / 暗 `#2A577A` | 主线条、线框、冷色光球 |
| 霓虹品红 | `#FF5FD2` / 暗 `#A24492` | 第二条曲线、对照组、冷暖对比 |
| 霓虹金 | `#FFD27A` / 中 `#C3A06A` | 第三条曲线、高亮、关键词光晕 |
| 薰衣草紫 | `#B58DE2` | 章节罗马数字、次要标签 |
| 光谱渐变 | 沿曲线按相位映射色相：青→蓝→品红→红→黄→绿 | "相位/多值"类曲线、色轮 |
| 粒子蓝白 | `#CFE3FF` 核心 + `#6FA8FF` 外晕 | 粒子文字、粒子云 |
| 字幕白 | `#FFFFFF` + 白色柔光 | 字幕 |
| 线框细线 | `#4FE0FF` @ 50~70% | 3D 线框盒、坐标网格 |

规则：一屏最多三种霓虹色；用"青 vs 品红"表达对立的两方，用金色表达"结果/重点"。

## 5. 视觉母题（可复用）

- **霓虹曲线**：粗发光管（tube geometry 或 line2 + bloom），可沿 x 轴生长；颜色可单色，也可按相位做光谱渐变。
- **线框立方体**：细青色线框盒子，把曲线/曲面"装"在里面，镜头绕它缓慢旋转。
- **渐变网格曲面**：线框 mesh 曲面，顶点色从青→品红→金渐变，可起伏、坍缩。
- **光球**：白核 + 本色外晕 + 横向变形光斑，表示"个体"；两颗光球之间用霓虹波连起来表示关联。
- **粒子汉字**：由数千颗闪烁粒子组成的书法/黑体字，可做笔画形变、炸散、重聚。
- **放射爆发**：一点向外喷出大量金色粒子与光芒，用作章节开场。
- **光谱光束束**：一组彩虹色细线从一点扇形发出、向远处展开。
- **星光速度线**：横向拉长的细白线流过画面，表示高速或远距离。
- **仪表与计数**：半圆刻度盘 + 发光指针；大号等宽数字并排对比（逐位滚动，相同位数高亮）。
- **环形节点阵**：彩色发光圆圈排成圆环，圈内放符号，旁边小字标签。
- **点阵晶格 + 激光**：透视平面上规则排列的白色发光球，几道红色激光柱从上方打下。
- **透视平面门框**：两三块细线框竖直平面在透视空间里，表示屏障或关卡。

## 6. 光影与后期

- Bloom 重：strength 1.5~2.0，radius 0.6，threshold 0.3——霓虹必须"糊"出大光晕。
- 色差（chromatic aberration）：画面边缘 2~4px 的 RGB 分离，粒子和光球处尤其明显。
- 变形光斑（anamorphic streak）：亮点处加横向长光条。
- 镜头光晕 / 彩虹漏光：只在片名和高潮使用。
- 背景偶尔铺一层极暗的星点或横向速度线，避免死黑。

## 7. 动效、镜头与节奏

- 镜头比 S2/S4 主动：绕线框盒子旋转 20~40°、快速推近、在星光速度线里前冲。
- 转场：闪白切（2~3 帧白场）、粒子炸散后在下一个形状重聚、一道横向光线扫过换场、直接硬切。
- 霓虹曲线：沿路径生长 0.6~1.0s，ease-out；曲线之间的形变用顶点插值。
- 字幕：整句淡入，关键词在 0.3s 后点亮（颜色+光晕+下划线从左向右划出）。
- 公式：淡入 + 光晕呼吸；读数面板数值实时跳动。
- 每镜 6~10 秒，片头 30 秒内用 3~4 个快镜头拉起能量，正文转稳，结尾用粒子片名收。
- 首尾呼应：片头出现的粒子字在片尾再次出现，然后炸散成片名。

## 8. 品牌角标适配（巴芒价值）

- 原风格把公式和读数面板放在右上角，与角标区（右上约 230×68px，距右 52、距上 30）冲突。
- 处理：公式和读数面板整体下移到 y≥150，或改放到左上章节眉下方。
- 本风格亮度和饱和度都很高，角标的金色字与霓虹金相近，注意右上 300×150px 范围内不要放高亮光球或强光斑。

## 9. 禁忌

- 浅色背景、写实环境、实物材质、柔和低饱和配色。
- 一屏超过三种霓虹色（光谱渐变曲线除外）。
- 无 bloom 的"干"线条；衬线中文字幕（本风格字幕是无衬线 + 光晕）。
