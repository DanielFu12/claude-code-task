# 渲染风格库 · 索引

从「AI 视频学习资料包」的 6 条视频里提炼出的 6 种动画渲染风格。每份文件**只写渲染特征**（配色、字体、版式、构件、光影、动效、镜头、节奏），不写原片讲了什么，示例文字全部用〔占位符〕。做新视频时直接挑一种风格套用，原片的选题内容不会混进来。

分析方法：每条视频按等间隔抽 32~48 帧做拼图、抽全分辨率关键帧看排印细节、0.5 秒间隔抽帧看转场，再用脚本统计背景色、强调色聚类和镜头切换次数。文中色值是从画面采样后取整的，复刻时可以在 ±10% 内微调。

## 怎么选

| 新视频的特点 | 推荐 |
|---|---|
| 讲方法、讲概念关系，时长 10 分钟以上，口播为主 | S1 |
| 按时间或阶段推进，抽象、短、要有诗意 | S2 |
| 有实物可以建模，想要电影感和高级感 | S3 |
| 从日常现象讲到底层原理，想靠"美"打动人，5 分钟级 | S4 |
| 抽象原理/反直觉，需要视觉冲击和能量感 | S5 |
| 工序、结构、"怎么做出来的"，快节奏、手机观看 | S6 |

可以混用的组合：S2 的底部时间尺 + S4 的字幕体系；S6 的标注卡 + S3 的材质光影。不建议混用的：S1 与任何暗色风格（亮暗底来回切会很跳）；S5 的霓虹与 S3/S4 的写实质感。

## 使用规则

1. **只取风格，不取内容。** 套用时只读本目录的风格文件；不要回头参考原片的分镜、文案或旧版"复刻提示词"（`../视觉渲染提示词/`）里的具体例子，那些文件夹带了原片的选题。
2. 风格文件里的〔占位符〕全部替换成新视频自己的内容；风格文件给出的构件是"手法"，用什么具体物体去承载由新选题决定。
3. 一条视频只用一种主风格；如果要混用，在提示词里写清楚以哪种为主、从另一种借哪一个构件。
4. 每份风格文件第 10/11 节都有一段可直接粘贴的提示词和一句英文风格锚：前者给代码渲染（Three.js / HTML / Remotion），后者给文生视频工具。

## 和品牌角标的配合（所有风格通用）

本仓库要求所有视觉产出右上角放「巴芒价值」角标（见 `../../brand/BRAND.md`）。角标在 1080p 下约 230×68px，距右 52px、距上 30px。

- **右上角预留 260×110px 的空区**（x ≥ 1610，y ≤ 110），任何风格的 HUD、公式、计数器都不能进这个区域。
- 原片里放在右上角的元素（S2 段落标签、S3 时间戳、S5 公式与读数、S6 计数胶囊）各风格文件里都写了改放位置，统一移到左侧或角标下方 y ≥ 130 处。
- 亮底风格（S1）里角标金字对比偏弱，靠角标自带的暗色阴影垫层；出片后目测确认，不改角标配色。
- 片尾统一用品牌片尾（大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」），配色和动效按所选风格调整背景即可。
