# S3 · 琥珀微缩电影（Amber Miniature Cinema）

> 本文件只描述**渲染风格**，不含任何具体选题。示例文字一律用〔占位符〕，套用时换成新视频自己的内容。

## 1. 一句话定位

黑色摄影棚里的微缩实物电影：玻璃、金属、自发光细丝在钨丝暖光里被浅景深的镜头缓缓推近；前半片是琥珀暖金，后半片转入深紫冷光，结尾两种光同框。带双语电影字幕和杂志式时间戳 HUD，质感接近高端纪录片片头。

**适合**：有"实物/装置/场景"可以建模的叙事、从小到大或从古到今的演进、需要电影感和高级感的 3~4 分钟片子。
**不适合**：纯抽象概念、大量图表、需要明亮轻快气氛的内容。

## 2. 画面基调

- 60fps（实测 1920×1080@60），运动顺滑，配合运动模糊，是本风格质感的关键之一。
- 黑底摄影棚：主体被一盏主光照亮，背景迅速衰减到黑；地面常是一块圆形深色玻璃台或磨砂台面，带柔和反射。
- 实测中位背景色 `#0A0411`，但亮部很满（90% 分位亮度约 104），说明主体本身很亮、明暗对比很大。
- 全片只有约 3 次硬切，其余都是推镜、溶解或经由黑场的过渡。

## 3. 色彩 Token（两幕色彩叙事）

| 幕 | 角色 | 色值 | 用法 |
|---|---|---|---|
| 第一幕·暖 | 底 | `#050302` → `#140A04` | 黑到深褐的暗部 |
| | 琥珀主光 | `#F2B35A` / 高光 `#FFE2A8` | 自发光细丝、主光、高光 |
| | 铜橙 | `#C8641E` | 发光导线、轨迹线 |
| | 金属金 | `#C5A263` | 金属件、旧木/黄铜质感 |
| 第二幕·冷 | 底 | `#00001B` / `#16133C` | 深靛蓝黑 |
| | 紫外主光 | `#8D6FC2` → 高光 `#E4D6FF` | 光束、光斑、发光平面 |
| | 电紫 | `#6A2BD8` | 大面积体积光、背景散景 |
| | 冷蓝 | `#515A8B` | 金属冷反射、辅助光 |
| 通用 | 字幕白 | `#F4F1EA` | 中文字幕 |
| | HUD 金 | `#D8AD63` / `#D0B16C` | 章节徽章底、等宽英文小字、下划线 |
| | 关键词 | `#E9A34A` | 字幕里的强调词 |

规则：色温变化本身就是叙事——"过去/起点"用暖琥珀，"现在/极限"用冷紫；结尾让暖光物体和冷紫光束同时出现在一个画面里收束。

## 5. 视觉母题（可复用）

- **微缩台面**：主体放在圆形深色玻璃/磨砂台上，周围有一圈细发光边。
- **自发光细丝/导线**：发光管状曲线（emissive tube + bloom），沿路径"点亮"生长；导线是铜橙色发光弧线，在物体之间拱起。
- **玻璃外壳**：透明玻璃罩、菲涅尔边缘光，内部发光；玻璃上有真实折射和高光条。
- **全息线框**：半透明盒体 + 白色自发光棱线，表示"示意结构"，与实体模型混用。
- **大规模复制**：同一物体用 instancing 排满货架/阵列，暖光一排排亮起，表现规模。
- **宏观飞越**：镜头贴地飞过由密集矩形块组成的"城市式"微观表面，强运动模糊。
- **地图视图**：深蓝底地图，发光点群 + 细引线标签。
- **对数图表**：星空背景上的细网格坐标，发光点沿虚线爬升，轴标为等宽小字。
- **数字墙**：三组并排的大号等宽数字 + 单位，下方一句字幕。
- **台阶柱**：一排逐级升高的发光矩形，配上角大号指数式数字。
- **慢放微观**：带彩虹边缘反射的金属小球一串飞过，背后是紫色散景，左上显示慢放倍率。
- **颗粒堆**：大量细小颗粒（沙/粉末）构成的堆体，在暖光下有颗粒级细节。

## 6. 光影、镜头与后期

- 渲染：Three.js（MeshPhysicalMaterial：transmission/clearcoat/emissive）+ HDR 环境贴图，或 Blender Cycles/Eevee。
- 主光：单盏钨丝色温点光（第一幕）/ 紫外色面光（第二幕），背景无补光。
- Bloom：strength 1.2~1.5，threshold 0.5——发光物要"烧"出光晕。
- 浅景深：前后景明显虚化，焦点在主体发光部位；镜头推近时有跟焦感。
- 运动模糊：快速推镜时强运动模糊（shutter 180°）。
- 镜头光学：画面边缘轻微色差、偶发变形光斑、细腻胶片颗粒（3~4%）、暗角。
- 镜头运动：缓慢推近（dolly-in）、低角度环绕、从宏观表面高速飞入再急停；手持感微抖动（极轻）。
- 每镜 5~8 秒，60fps。

## 7. 动效与转场

- **字幕逐字显现**：中文按字从左到右淡入，正在出现的 2~3 个字呈渐隐的"羽化前沿"；英文翻译整句淡入、更暗。
- **点亮生长**：发光丝/导线沿路径从一端亮到另一端，0.8~1.5s。
- **形状匹配溶解**：上一镜的发光轮廓与下一镜相似的形状重叠溶解（圆对圆、弧对弧）。
- **经黑溶解**：画面压暗到黑约 0.3s，再从黑中亮出下一个发光体。
- **速度切入**：高速推镜 + 运动模糊冲进下一场景。
- **色温转场**：从暖幕到冷幕时，用一束冷紫光从画面一侧扫入、逐渐占满。
- 数字：等宽数字滚动增长；大数字出现时轻微放大 1.05→1。
- 收尾：回到片头出现过的主体，暖光与冷光同框，字幕说出收束语后黑场。

## 8. 品牌角标适配（巴芒价值）

- 原风格右上角放大号时间戳，与角标区（右上约 230×68px，距右 52、距上 30）冲突。
- 处理：时间戳整体移到左侧（章节徽章下方，左对齐 x=80, y≥120），或放到角标正下方 y≥130 右对齐，字号降到 64~72px。
- 本风格的 HUD 金 `#D8AD63` 与角标金色字同色系，整体很协调；注意不要让右上出现大面积高亮物体抢角标。

## 9. 禁忌

- 扁平矢量、卡通、明亮白底。
- 一个画面内同时出现暖幕和冷幕的大面积色彩（只有结尾允许）。
- 无景深、无运动模糊的"游戏截图感"画面；30fps 低帧率。
- 字幕用无衬线、去掉英文行（会丢掉电影感）。

风格规范：
- 黑色摄影棚：主体放在圆形深色玻璃台上，只有一盏主光，背景衰减到黑。
