# S1 · 暖纸手绘图解（Paper Explainer）

> 本文件只描述**渲染风格**，不含任何具体选题。示例文字一律用〔占位符〕，套用时换成新视频自己的内容。

## 1. 一句话定位

暖米色纸面上的扁平矢量图解：一屏只讲一个点，元素在原地生长、替换、淡出，像一本被逐页翻开的高级笔记本。全程无 3D、无照片、无硬切。

**适合**：概念拆解、方法论/教程、流程与系统关系讲解、长时长（10 分钟以上）口播配图。
**不适合**：需要震撼感、史诗感、实物质感的内容。

## 2. 画面基调

- 亮底、低饱和、高留白。实测全片中位背景色 `#EDE8DD`，亮度极稳定（10%~90% 分位亮度 224~236），整片没有一次硬切。
- 纸面带极淡的纸纹噪点和非常轻的暖色暗角，禁止纯白。
- 画面元素少而精：一屏通常 1 个标题 + 1 组图解 + 底部字幕。

## 3. 色彩 Token

| 角色 | 色值 | 用法 |
|---|---|---|
| 纸底 | `#EDE7DD`（可在 `#EDE7DD`~`#F3EEE6` 之间做极轻的径向渐变） | 全片唯一背景 |
| 卡片/胶囊底 | `#FBF7F1` | 卡片、胶囊标签、对话框底色，比纸底略亮 |
| 字幕衬底 | `#F1EBE2` | 底部字幕下的极淡色带 |
| 墨色 | `#2B2621` 左右 | 标题、正文 |
| 辅助灰 | `#8A8578` / `#B8B2A6` | 描边、序号、次要说明、未激活项 |
| 朱砂橙（唯一强调色） | `#BF5934`（深）/ `#B76143`（章节号） | 当前重点、关键词、✗、手绘圈、箭头 |
| 强调浅底 | `#F5E2D4` | 被选中的胶囊/卡片填充 |
| 辅助绿（少量） | `#5E8C6A` 左右 | ✓、"正确/通过"类状态、进度条 |
| 辅助紫（极少） | `#69508D` 左右 | 偶尔用于区分第三类对象 |

规则：一屏里朱砂橙只标"正在讲的那一个点"；绿只表示肯定状态；其余全是墨色和灰。

## 4. 字体排印

| 层级 | 字体 | 字号（1080p） | 位置/样式 |
|---|---|---|---|
| 章节眉 | 衬线：编号用橙色数字 + 灰色章节名（Noto Serif SC / Source Han Serif） | 26~30px | 左上 (120, 95)，全程常驻，提示当前章节，例如 `0N 〔章节名〕` |
| 屏内大标题 | 衬线宋体，墨色 | 40~56px | 居中或左上对齐，一屏一句 |
| 图解文字 | 无衬线（Noto Sans SC / 苹方），Medium | 28~36px | 卡片、胶囊内 |
| 数字/代码 | 等宽（JetBrains Mono / SF Mono） | 视情况 | 计数器、序号 `01 02 03`、代码片段 |
| 字幕 | 无衬线 Bold，墨色 | 36~40px | 底部居中 y≈1005，下垫一条极淡的 `#F1EBE2` 圆角色带；关键词改为朱砂橙 |

字幕里的英文、数字和中文同一行混排，不另起英文翻译行。

## 5. 图解构件库（可复用）

- **卡片**：`#FBF7F1` 圆角矩形（r≈6px），1px 浅灰描边 + 很柔的投影（y 2px，blur 12px，α 0.06）；上方小灰字标签，中间大号等宽数字，下方橙色单位。
- **胶囊标签**：全圆角，1px 灰描边；激活态改为 `#F5E2D4` 填充 + 橙色描边；未激活态降到 40% 不透明度。
- **编号清单**：左侧灰色等宽序号 `01…0N` + 细竖线串联 + 右侧胶囊，逐条出现；出错项右侧弹出橙色 ✗，通过项弹出绿色 ✓。
- **流程/循环图**：节点用胶囊或小卡片，连线是 1.5px 灰色细弧线 + 小箭头；闭环用橙色手绘椭圆圈住。
- **虚线框**：橙色或灰色 1.5px 虚线圆角框，表示"范围/边界/环境"，左上角带一行小标签。
- **聊天/窗口仿真**：浅色窗口（左上三个小灰点）、左右气泡；深色气泡（`#2B2621` 底白字）表示一方，浅色描边气泡表示另一方。
- **数据密排**：大量小号灰色等宽数字铺成矩阵，个别数字染成橙色，作为"海量数据"的视觉隐喻。
- **词云散落**：等宽英文术语以不同字号、不同灰度散布，中央压一句大号衬线标题。
- **进度条/占比条**：细长圆角条，已占部分用绿或橙，旁边大号百分比。
- **线性图标**：锁、地球、文件夹等 1.5px 线性图标，灰色，配小字说明。
- **片尾插画**（可选）：一张水彩风暖色插画占半屏右侧，左侧留白放衬线收尾语。

## 6. 动效与转场

- **原地生长**：元素入场 = 不透明度 0→1 + 上移 8~12px，300~450ms，ease-out；成组元素依次错开 80~120ms。
- **打字/逐字出现**：标题和强调语逐字出现，每字 40~60ms。
- **数字滚动**：计数器从 0 或上一个值滚动到目标值，约 0.8~1.2s。
- **重点切换**：激活色在胶囊之间移动；被替代的元素降到 30~40% 不透明度，不直接删除。
- **手绘描边**：圈、下划线、箭头用 stroke-dashoffset 动画"画出来"，约 0.6s。
- **场景切换**：整屏元素一起淡出（约 300ms）→ 空纸停顿 0.3~0.5s → 下一屏元素生长。不做推拉摇移，不做硬切，不做花哨转场。
- 章节眉在切章时淡出再淡入，新编号出现。

## 7. 镜头与节奏

- 摄像机完全静止，所有运动都在元素层面完成。
- 每个"屏"停留 8~30 秒，跟随口播逐步加元素；长片也保持这种慢节奏。
- 信息揭示是累加式：同一屏上一句一句叠加，讲完才整体清场。

## 8. 实现建议

- 最合适：HTML/CSS + SVG（或 Remotion），无头浏览器逐帧截图后用 FFmpeg 合成；也可用 Python + Pillow/cairo 逐帧绘制。
- 1920×1080，30fps。
- 纸纹：叠一层 2~3% 不透明度的灰度噪点 + 很轻的暖色暗角。

## 9. 禁忌

- 纯白底、深色底、渐变大色块、霓虹发光、3D、照片素材。
- 一屏超过 1 种强调色、超过 3 组图解。
- 推拉镜头、旋转、弹跳等夸张缓动。

## 10. 品牌角标适配（巴芒价值）

- 角标固定在右上角（距右 52px、距上 30px，约 230×68px），本风格右上角本来就空，直接放。
- 本风格是亮底，角标的金色字在米色纸上对比偏弱：保留 `brand/` 自带的暗色阴影垫层，出片后务必目测确认可读；不要为此改角标配色。
- 片尾可沿用本风格的留白，把大号 logo +「巴芒价值」+「BUFFETT · MUNGER」居中放在纸面上。

## 11. 可粘贴的风格提示词（无选题）

```
请按"暖纸手绘图解"风格渲染一条讲解视频（1920×1080，30fps），用 HTML/SVG 逐帧渲染后 FFmpeg 合成。
风格规范：
- 全片唯一背景为暖米纸色 #EDE7DD，带极淡纸纹噪点，禁止纯白、深色底、3D、照片、霓虹。
- 墨色 #2B2621 写标题和正文，灰 #8A8578 做描边和辅助字；唯一强调色朱砂橙 #BF5934，只标当前重点；绿色 #5E8C6A 只表示"通过/正确"。
- 左上角常驻章节眉：橙色衬线编号 + 灰色衬线章节名（〔章节编号〕〔章节名〕）。
- 屏内标题用衬线宋体，图解文字用无衬线，数字和序号用等宽字体。
- 图解构件只用：浅色圆角卡片（柔投影）、全圆角胶囊标签、编号清单、细弧线流程图、虚线范围框、聊天窗口仿真、线性图标、进度条。
- 底部居中字幕：无衬线粗体墨色，下垫极淡色带，关键词改橙色。
- 动效：元素原地淡入并上移 10px，成组错开 100ms；关键词逐字打出；数字滚动；手绘圈和下划线用描边动画画出；被替代的元素降到 35% 不透明度。
- 场景之间整屏淡出→空纸停顿→下一屏生长；摄像机全程静止，不用硬切。
- 一屏只讲一个点，内容为：〔逐屏写出本片自己的要点〕。
- 右上角为品牌角标预留 260×110px 的空区，不放任何元素。
```
