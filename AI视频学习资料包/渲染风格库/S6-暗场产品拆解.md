# S6 · 暗场产品拆解（Dark Studio Breakdown）

> 本文件只描述**渲染风格**，不含任何具体选题。示例文字一律用〔占位符〕，套用时换成新视频自己的内容。

## 1. 一句话定位

深灰摄影棚里的 3D 产品级拆解动画：哑光 PBR 模型、紫色轮廓光和灯带、漂浮的散景尘粒，配大号粗体中文字幕、带引线的标注卡和章节编号。像一支发布会产品片 + 工业原理讲解，信息清楚、节奏快。

**适合**：流程/工序/结构拆解（"它是怎么做出来/怎么工作的"）、分步骤讲解、2 分钟左右的快节奏短片、移动端观看。
**不适合**：抽象概念、诗意叙事、需要大量公式的内容。

## 2. 画面基调

- 实测中位背景色 `#141920`（深炭灰，带一点蓝），暗部有 `#06080D`；比 S2/S5 的纯黑更"像摄影棚"。
- 画面常驻一层**大颗粒白色散景尘粒**（直径 6~20px 的柔边白点，随机漂浮），是本风格的辨识点。
- 每个章节由多个 3~5 秒的短镜头组成，章节之间直接硬切（约 25 次切换，平均每镜 4 秒左右）。
- 字幕大而粗，适合手机屏幕。

## 3. 色彩 Token

| 角色 | 色值 | 用法 |
|---|---|---|
| 背景 | `#141920`（中）/ `#06080D`（暗角） | 摄影棚底，带轻微径向渐变 |
| 模型浅色外壳 | `#D8DAE0` → `#9EA3AD` | 大型设备外壳、面板 |
| 模型深色件 | `#2A2D35` / `#3A3E48` | 哑光黑金属、台面、底座 |
| 薰衣草紫（主强调） | `#B892F9`（亮）/ `#AB93DC`（文字）/ `#7E6BC4`（光束） | 章节号、标注副文字、灯带、光束、选中区域 |
| 冰青（辅强调） | `#8FD4DC` / `#488D9F` | 灯带边缘光、底层材料、对照组 |
| 暖橙金（材料色） | `#D89A4A` / `#7D5835` | 暖色材料层、加热/高能状态 |
| 深青蓝（材料色） | `#1F5D79` | 基底材料层 |
| 激光红（点缀） | `#FF5A4A` | 极少量高能光束 |
| 文字白 | `#FFFFFF` | 字幕、标题、标注主文字 |
| 进度胶囊底 | `#000000` @ 45% | 右上/角落的计数胶囊 |

规则：紫色是"这个视频的颜色"，所有 UI 强调都用紫；青只用在灯带和第二类材料；暖橙只用于材料本身，不用于 UI。

## 4. 字体排印

全片只用一套粗体无衬线（思源黑体 / Noto Sans SC Bold~Heavy；数字可用 Inter Bold）。

| 层级 | 字号（1080p） | 位置/样式 |
|---|---|---|
| 章节编号 | 60~64px Heavy，薰衣草紫 `#B892F9` | 左上 (60, 60) |
| 章节标题 | 48~52px Bold，白 | 编号右侧同一行；下方一条 4px 紫色下划线，与编号+标题等宽 |
| 开场大标题 | 72~80px Heavy，白，带投影 | 画面左中，下一行 32px 紫色副标题 |
| 场景大字 | 72~90px Heavy，白 | 叠在模型上的名称，下一行 30px 白色副标 |
| 标注卡·主 | 40~44px Bold，白 | 左侧 4px 紫色竖条 + 主文字 |
| 标注卡·副 | 32~36px Regular，`#AB93DC` | 主文字下方，一句说明 |
| 标注引线 | 2px 白/紫折线，物体端一个带白描边的小圆点 | 从标注卡竖条中点折到物体 |
| 计数胶囊 | 44~48px Bold，白，胶囊底 `#000`@45%，圆角 8px | 原片右上；**本仓库须移位**（见第 8 节），格式 `〔动作〕 N / M 〔单位〕` |
| 字幕 | 60~64px Bold，白，2px 黑描边 + 柔投影 | 底部居中 y≈975，单行为主，不加英文 |
| 数据条形图 | 标签 24px Bold + 数值 20px | 左对齐横向条，灰蓝条 + 最后一条紫色高亮 |

## 5. 视觉母题（可复用）

- **爆炸视图**：设备外壳沿轴向拆开、悬浮，内部部件依次亮起；拆开后镜头穿过外壳缝隙进入内部。
- **剖面特写**：把结构切开，用不同颜色的厚块表示层（青蓝基底 + 暖橙层 + 浅色层），层与层之间留细缝。
- **逐步工序**：同一个微观剖面在连续镜头里被一步步改变（加一层 → 局部高亮 → 去除部分 → 填入新材料）。
- **光路光束**：紫色半透明体积光束在镜面/部件之间折转，表示能量或信息的路径。
- **阵列填充**：圆形/方形区域被一格一格地点亮，配合计数胶囊 `N / M` 递增。
- **粒子雨**：竖向发光短线（青色）从上方落下，表示被注入/轰击。
- **颗粒原料**：大量不规则小块漂浮或堆积，表示原料状态。
- **转台展示**：主体放在带发光边的深色台座上缓慢转动。
- **数据条形图**：横向条形对比，最后一项紫色高亮，旁边小字年代/类别。

## 6. 光影、镜头与后期

- PBR：哑光金属 roughness 0.4~0.6；浅色外壳带细微面板缝和散热格栅细节。
- 布光：顶部柔光箱 + 紫色/青色轮廓光（rim light）；设备上嵌紫色和青色细灯带（emissive strip）。
- 轻 Bloom：strength 0.5~0.7，只让灯带、光束、发光材料溢光。
- 地面：深色光滑地面，带模型和灯带的模糊反射。
- 散景尘粒层：前景放 30~60 颗大小不一的柔边白点，轻微景深模糊，缓慢漂浮。
- 镜头：环绕（orbit）+ 推近为主，每镜都有运动；从远景"全貌"推到特写"细节"。

## 7. 动效与转场

- 章节切换：硬切，新章节第一镜左上编号+标题从左滑入（0.3s）。
- 标注卡：竖条先出现 → 引线从物体端画到卡片 → 文字淡入，共约 0.5s；离场时整体淡出。
- 计数胶囊：数字跳变，不做滚动。
- 部件运动：拆开/合拢用 ease-in-out，0.8~1.2s；层的覆盖、去除用"从一侧推进"的擦除动画。
- 字幕：整句直接出现/替换，不做逐字。
- 每镜 3~5 秒，8 个章节约 2 分钟。

## 8. 品牌角标适配（巴芒价值）

- 原风格右上角放计数胶囊，与角标区（右上约 230×68px，距右 52、距上 30）冲突。
- 处理：计数胶囊移到右上角标正下方（右对齐，y≥130），或移到左上章节标题下方。
- 本风格背景是带蓝调的深灰，角标蓝色 logo 和金字都能看清；薰衣草紫与金色互补，不需要调色。

## 9. 禁忌

- 纯黑底（要的是深灰摄影棚）、浅色底。
- 衬线字体、细字重字幕、双语字幕。
- 霓虹多色、彩虹渐变；紫色以外的 UI 强调色。
- 长镜头慢节奏（每镜超过 8 秒会拖）。

- 深炭灰摄影棚背景 #141920（四角压到 #06080D），前景漂浮 30~60 颗大小不一的柔边白色散景尘粒。
