# S2 · 暗夜星图编年（Dark Constellation Chronicle）

> 本文件只描述**渲染风格**，不含任何具体选题。示例文字一律用〔占位符〕，套用时换成新视频自己的内容。

## 1. 一句话定位

近乎纯黑的宇宙里，只有发光的点和细线：节点、点云、网格平面在黑暗中逐个亮起又熄灭，配一条贯穿全片的底部时间刻度尺，像深夜天文馆里放一部编年史。极度克制、安静、诗意。

**适合**：按时间/阶段推进的叙事（编年、演进、里程碑）、抽象结构（网络、数据、规模增长）、2 分钟左右的短片。
**不适合**：需要实物质感、人物、明亮场景或大量说明文字的内容。

## 2. 画面基调

- 实测中位背景色 `#010204`，90% 的像素亮度低于 5/255，是"黑场上的光点"。
- 画面四周有明显暗角，中心略亮；全屏漂浮极稀疏、极暗的星尘。
- 发光元素只占画面很小面积，亮度靠 bloom 溢出，不靠大色块。
- 全片**不烧录字幕**，信息只靠少量排印卡片。
- 全片**没有一次硬切**（场景检测阈值 0.25 下 0 次切换），全部是暗下去→亮起来。

## 3. 色彩 Token

| 角色 | 色值 | 用法 |
|---|---|---|
| 背景 | `#010204` | 全片不变 |
| 星尘 | `#FFFFFF` @ 8~15% | 极小点，极慢漂移 |
| 暖金（主光） | 核心 `#FFD9A0` → 外晕 `#E0A060` | 主节点、被激活的结构、核心符号 |
| 琥珀（次暖） | `#D97F5B` | A 类数据点、暖色区域 |
| 冰青 | `#6FC3DF` | B 类数据点、冷色区域、网络节点 |
| 雾蓝紫 | `#636D9A` | 大型网络的连线、远景结构 |
| 年份/大数字 | `#C9C9CE`（约 75% 亮度的灰白） | 大号衬线数字，本身不发光 |
| 说明文字 | `#8C8C92` | 中文说明、英文斜体名、公式 |
| 刻度/细线 | `#2A2A2E` | 底部时间尺、网格线 |

双色语义：暖金/琥珀 = "被点亮、被选中的"；冰青/雾蓝 = "数据、背景结构"。分类场景直接用暖/冷两色区分两类点。

| 节点卡·中文名 | 衬线宋体，字距 0.1em | 36~40px | 短横线下 |
| 节点卡·英文名 | 衬线斜体 | 16~18px | 中文名下，灰色 |

## 5. 版式与常驻 HUD

- **底部时间刻度尺**（本风格最有辨识度的元素）：y≈1050，从 x=140 到 x=1780 一条 1px 暗灰细线；每个节点一个小圆点 + 上方 11~12px 衬线小字标签；已走过的段落线变亮、标签变白；当前节点是一颗带光晕的白点，沿线滑动到下一个节点。首尾标签可用"序 / 终"一类单字。
- 节点卡与主图解呈对角布局（卡在左下 → 图在中右；卡在左上 → 图在中下）。
- 中心构图为主，主图解占画面中部 50~60%。

## 6. 视觉母题（可复用，不限题材）

- **发光节点 + 细连线**：Sprite/Points 节点，additive 混合；连线 1px，透明度 0.25~0.4，颜色跟随端点；节点做 4~6 秒周期的正弦呼吸。
- **扇入结构**：多个输入点用贝塞尔曲线汇聚到一个带圆环的中心符号，中心外再套一个大细圆。
- **倾斜网格平面 + 点云**：透视倾斜的 3D 网格平面，上面散布暖/冷两类点；一条发光分界线在平面上转动、逐步摆到正确位置。
- **分层网络**：多列节点全连接，脉冲光点沿连线流动。
- **透视纸带**：一串数字方块排成向远处延伸的透视长带，带一个高亮括号光标逐格移动。
- **格点落子**：透视网格上的黑白圆点逐个落下。
- **关联弧线**：一排小方框上方拉出半透明弧线互相连接。
- **点云体积增长**：点组成的半球/球体，点数和体积随计数器一起增长，最后散成星云。
- **大面板框**：偶尔用一个很淡的细边框把一组图解框成"展柜"。

## 7. 光影与后期

- UnrealBloomPass：strength 0.8~1.0，radius 0.5，threshold 0.6~0.7——只让点和线溢光。
- 暗角：边缘压暗 40~50%。
- 极轻胶片颗粒（2%）。
- 无景深、无运动模糊。

## 8. 动效、镜头与节奏

- 镜头：极慢推进或横移（< 0.2 单位/秒），或干脆静止；平面类图解可缓慢绕 Y 轴转 5~10°。
- 场景切换：当前场景整体 0.8~1.0s 暗到全黑 → 约 0.5s 纯黑停顿 → 新场景先出图解，0.5s 后节点卡淡入，再 0.5s 后公式/读数淡入（三段错开）。
- 节点卡文字：淡入 + 上移 6px；旧卡淡出，不位移。
- 时间尺上的当前点在切场时滑到下一个节点，约 0.8s，ease-in-out。
- 高潮：全屏节点同时亮起、连线暴涨 2~3 秒后缓缓暗下。
- 收尾：黑场 → 片名居中亮起并呼吸两次 → 一行两句的收束文字逐字淡入 → 结束卡。
- 每个节点停留 4~8 秒，2 分钟内走 15~20 个节点，节奏像潮汐。

## 9. 品牌角标适配（巴芒价值）

- 原风格的段落标签放在右上角 (1600~1780, 100)，与角标区（右上约 230×68px，距右 52、距上 30）冲突。
- 处理：段落标签移到左上 (140, 70)，或放到角标正下方 y≥130 处右对齐。右上的公式/计数器统一下移到 y≥150。
- 本风格是纯黑底，角标的蓝色光晕和金字会很醒目，注意其他元素不要比角标更亮地挤在右上。

## 10. 禁忌

- 浅色背景、大面积色块、实物 3D 材质、照片、人物、卡通。
- 彩虹色和高饱和霓虹（只允许暖金 + 冰青两套光色）。
- 硬切、快速运镜、烧录字幕条。

```
风格规范：
- 背景近乎纯黑 #010204，四周暗角，漂浮极稀疏的暗星尘。画面主体只有发光的点和细线。
- 光色只用两套：暖金（核心 #FFD9A0、外晕 #E0A060，表示被点亮/被选中）和冰青 #6FC3DF（表示数据/背景结构）；远景连线用雾蓝 #636D9A。
- UnrealBloom（strength 0.9, radius 0.5, threshold 0.65），只让点线溢光；节点 4~6 秒正弦呼吸。
- 底部常驻时间刻度尺：y=1050 一条暗灰细线，每个节点一个小点 + 上方衬线小字；已走过的部分变亮；当前点是带光晕的白点，切场时滑到下一个节点。节点为：〔列出本片自己的节点标签〕。
- 每个节点一张排印卡，与主图解对角放置：衬线大号数字/序号（灰白，不发光）→ 短横线 → 中文衬线名 → 英文斜体名 → 1~2 行灰色说明。

```
