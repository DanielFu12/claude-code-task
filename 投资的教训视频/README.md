## 一条主线：第一性原理

**股价 = 每股盈利 × 市盈率**，账户回报 = Σ 仓位 × 个股回报。
所以所有亏损都来自三个变量：**盈利**（周期决定分母）、**估值**（情绪决定倍数）、**仓位**（决定能不能活下来）。四条教训分别对应这几个变量会出问题的地方。
