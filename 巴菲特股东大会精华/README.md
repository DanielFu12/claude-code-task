# 巴菲特与芒格 · 股东大会精华（约 10 分钟）

从 1998—2025 年的 10 届伯克希尔股东大会里，挑出巴菲特和芒格的 12 段精彩发言，再加 4 个冷开场镜头，剪成约 10 分钟的横版精华。每一段都能单独切成短视频，流水线也能直接生成每段一条的竖版短视频。

- 选了哪些片段、原话、中文翻译、短视频标题、出处：见 **[素材清单.md](素材清单.md)**
- 片段配置（可改）：`clips.json`；素材来源：`sources.json`

## 当前状态

剪辑流水线已经写好，并用合成的测试画面跑通了全流程（`src/selftest.py`）。**真实素材还没有下载**：生成这份代码的云端环境，网络策略拦截了所有视频站点（youtube.com、googlevideo.com、cnbc.com、archive.org、bilibili.com 等）。所以 `巴菲特股东大会精华.mp4` 要等能下载素材之后再生成。有两种办法：

1. 在本地电脑上运行 `./build.sh`（装好 ffmpeg、python3、yt-dlp 即可）。
2. 在云端环境的网络设置里放行 `youtube.com`、`www.youtube.com`、`*.googlevideo.com`、`*.ytimg.com`，再让 Claude 继续跑。

如果已经有股东大会的录像文件（比如从 CNBC Buffett Archive 下载的），把路径填进 `sources.json` 对应年份的 `local` 列表，再在同目录放一份同名的 `.en.vtt` / `.srt` 字幕，就能完全离线运行。

| 壹 · 能力圈 | 1998 巴菲特：对手占优的游戏我不玩 ／ 2000 芒格：葡萄干和粪便 |
| 贰 · 普通人的答案 | 2018 1942 年的一万美元 ／ 2017 全场起立致敬博格 ／ 2021 1989 年市值前二十一家不剩 |
| 叁 · 坦然认错 | 2019 错过谷歌 ／ 2020 清仓航空股 |
| 肆 · 看穿泡沫 | 2022 巴菲特：25 美元也不买比特币 ／ 2022 芒格：愚蠢、邪恶、让人难堪 |
| 伍 · 人生的复利 | 2022 投资自己 ／ 2023 芒格最后一次股东大会的人生清单 |
| 终 · 传承 | 2025 巴菲特宣布年底交棒阿贝尔 |
| 片尾 | 大号 logo + 金色「巴芒价值」+ BUFFETT · MUNGER + 致敬芒格 |

画面：
- 源视频铺满 1920×1080。1990 年代的 4:3 标清录像会锐化，两侧补上模糊放大的同一画面，不留黑边。
- 中英双语字幕：中文大字在上，英文原话在下。金句之外的话（比如股东的提问）只显示英文转写。
- 每段开头 6 秒在左上角显示届次、人物和主题，之后缩成一个小标签（章节 · 年份 · 人物），切成短视频后也看得出出处。
- 右上角全程挂「巴芒价值」品牌角标（`brand.Hud`：logo + 金色宋体 + 流光），规范见 `../brand/BRAND.md`。
- 章节卡和片名卡用深色背景、金色微光粒子，背景音乐取自仓库里的 `opus5.5涌现.mp4`。片段本身只用现场原声，并统一响度到 −16 LUFS。

## 运行

```bash
./build.sh            # 横版成片 -> 巴菲特股东大会精华.mp4 + 章节时间码.md
./build.sh --shorts   # 另外生成每段一条 1080×1920 竖版短视频 -> shorts/
```

分步运行：

| 步骤 | 命令 | 说明 |
|---|---|---|
| 1 | `python3 src/fetch.py subs` | 每届股东大会只下载英文字幕（YouTube 自动字幕带逐词时间），几十 KB |
| 1′ | `python3 src/fetch.py whisper 1998` | 某个来源没有字幕时，下载音频并用 faster-whisper 逐词转写（需要 `pip install faster-whisper`） |
| 2 | `python3 src/locate.py` | 用 `clips.json` 里的英文原句在转写稿中模糊匹配，得到每段的起止时间码。匹配不上的会列出来 |
| 3 | `python3 src/fetch.py media` | 只下载每段前后各多留 4 秒的片段，不下载整场 5 小时的录像 |
| 4 | `python3 src/render.py` | 4 进程并行渲染，再无损拼接 |
| 5 | `python3 src/render.py shorts c08 c11` | 竖版短视频。不写编号就全部生成 |

离线自检（不用联网，只用测试彩条画面）：`BRK_WORK=/tmp/brk python3 src/selftest.py --render --shorts`

## 调整

- **时间码不准或匹配失败**：在 `clips.json` 对应片段里加 `"start": "1:23:45", "end": "1:24:30"`（源视频时间）手动覆盖。也可以改 `lines` 里的英文，让它更接近现场的原话。
- **总长**：`auto_fit` 打开时，`locate.py` 会在总长不足 `target_seconds`（600 秒）时，把差额平均分给各段（往前多留 60%，通常正好是股东的提问；往后 40%），切点吸附到说话停顿，每段最多 +25 秒。也可以关掉它，自己调每段的 `pre` / `post`。`render.py` 会打印总时长。
- **完整中文字幕**：`locate.py` 会把每段的完整英文转写写到 `work/subs/<编号>.en.srt`。翻译成双语 SRT（每条第一行中文、第二行英文）后放到 `subs/<编号>.srt`，渲染时会优先使用它。
- **换片段**：在 `clips.json` 里增删即可。`素材清单.md` 末尾列了几个备选。
- **竖版短视频**：顶部是 `short_title`（钩子标题），中间是画面，下面是字幕，底部留给平台的按钮和文案区，结尾 2.5 秒是品牌片尾。

## 文件

```
clips.json        片段配置：章节、每段的英文原句和中文字幕、短视频标题、pre/post
sources.json      每届股东大会的来源（本地文件 / 链接 / YouTube 搜索词）
素材清单.md       选材说明、原话、翻译、出处链接、备选
build.sh          一键生成
src/common.py     路径、字体、转写稿解析（YouTube json3 / VTT / SRT / Whisper）
src/fetch.py      下载字幕、按段下载视频、Whisper 转写
src/locate.py     金句定位（difflib 模糊匹配 + 停顿吸附）
src/render.py     合成：字幕、届次条、章节卡、片名、片尾、品牌角标、竖版短视频
src/selftest.py   离线自检
```
