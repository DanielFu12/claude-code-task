# M02《一家很强的公司，为什么也会失去时代？》· 自然选择

《50个自然法则，看懂商业世界》第 02 期。本期话题：**环境变化 / 能力匹配 / 企业转型**。

- 成片：`M02_一家很强的公司为什么也会失去时代_自然选择.mp4`（1920×1080 · 30fps · 4:24 · 无人声，字幕叙事）
- 配乐与音效全部为原创合成（`src/music.py`），没有外部采样：
  - 配乐：90 BPM、C 小调，比 M01 更慢、更深。**1 拍 = 2/3 s = 正好 20 帧**，每个拍点和转场都落在整数帧上。滚动的琶音对应“一代又一代”。
  - 转场音效只用 sub drop、低频 boom、低沉膨胀和闷击。全部经过 4 阶 180 Hz 低通，实测 **99.99% 的能量在 200 Hz 以下**。不用白噪声、whoosh 或尖锐的上升音。
  - 每个音效都按所在位置的音乐响度自动压低，至少比音乐低 4 dB，起音对准转场那一帧。
- 右上角全程是 `brand.Hud` 画的官方角标，直到整片最终淡出才消失。片尾 logo 用的是 `brand/logo_baman.png` 原图。品牌金色、字体、流光参数都从 `brand/brand.py` 读取。

## 事实、出处与制作约束

| 内容 | 出处 / 处理方式 |
|---|---|
| 自然选择的机制：可遗传差异 + 特定环境中的繁殖成功差异 → 跨世代改变性状频率 | 素材《01 自然选择事实核查》；OpenStax Biology 2e §19.3 |
| 1858 年达尔文与华莱士各自提出自然选择（同年在林奈学会联合宣读） | 达尔文、华莱士论文，Linnean Society, 1858 |
| 「不是强者必胜」；漂变、迁移与偶然事件同样影响演化；不做企业失败的单因归因 | 素材核查卡“主要限制”与核查依据 |
| 适应度地形（fitness landscape） | Sewall Wright, 1932 |
| 昆虫捕食动画 | 标注“简化模拟 · 非实测数据” |
| 纸质地图公司 | **假设情景**。核查卡写明 Nokia 仍是待核案例，公司故事必须先补原始公告、口径、时间线和因果证据，不足时改用标注“假设”的教学情景，所以本片没有点名真实公司 |
| 巴菲特、芒格引语 / 企业财务数字 | 核查卡写明“本卡不使用企业财务数字或巴菲特、芒格引语”，本片遵守，没有使用 |

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、python3，以及 numpy scipy opencv-python-headless pillow soundfile
```

- `src/timeline.py`：节拍网格、音乐段落、重拍与转场时间点、全部字幕（全片唯一的时间来源）
- `src/music.py`：配乐与低频音效的合成和混音
- `src/video.py`：全部分镜（每个 `sc_*` 函数对应一段画面）、选择模拟、适应度地形、生命之树和片尾 logo 粒子汇聚
- `src/engine.py`：“加色光 + 辉光”动态图形引擎（与 M01 同源，新增批量剪影 `darkpolys` / `top_fills`）
- 片尾做法参考了 `love_video/render.py`（在 `claude/youthful-franklin-j206py` 分支）的粒子重组 logo；不同的是，本片右上角角标保持到整片淡出，没有提前隐藏
