# 护城河系列 · 分期规划

> 依据：仓库分支 `claude/tender-turing-itc3zu` 上的《企业护城河标签库 v6》（9 大类 57 个标签 + 误判自查清单）与《企业名单-护城河标签》（1473 家公司）。
> 制作方法：见同目录 `护城河系列视频制作规则.md`。
> 最后更新：2026-11-28

## 规划原则

1. **一期讲一种护城河**，标题用「反常识判断｜成立条件」，如“便宜≠护城河｜低成本成为护城河的三个条件”。
2. **反常识判断直接取自标签库的「误判自查清单」**：低成本≠结构性优势、知名度≠品牌壁垒、规模大≠网络效应、数据多≠飞轮、牌照≠永久……清单本身就是选题冲突。
3. **排序看与关注公司的相关度**：1473 家公司里贴标最多的是客户认证导入（469）、规模经济（330）、赢家拿大头（255）、渠道网络（168）、学习曲线（158）、品牌优势（138）、稀缺资源（128）、成本优势（125）、牌照准入（113）；网络效应、生态等全名单只有个位数，往后放。
4. **全系列同一个总定义**：护城河 = 能持续获得超额回报 / 定价权的结构性原因。每期最后都回到这个定义。

## 每期共用骨架

引子（当下经济现象 → 一正一反两个结局相反的公司）→ 结论式片名 → 第一性原理 → 大师对撞与调和（找不到可核实的对立原话，就用正反案例代替）→ 成立条件（2–3 条，每条一正一反）→ 中国公司体检（✓ / ? / ×，不下结论）→ 失效方式 → 一句话回到标题 → 品牌片尾动画。

## 提醒

- 表中案例取自贴标名单的“符合”项。标签库误判清单写明“示例用于理解机制，不是当前企业评级”，每期都要按规则文档第三节重新找来源。
- 大师对撞是选题难点：成本（巴菲特 vs 段永平）已用过；品牌、网络效应有较多可核实的原话可用；其他期需提前检索，找不到就换成正反案例。
