# 大师之道 · MastersTao / 复利之道 v4

依据用户提供的四张图片重新设计：第二张用于理解复利曲线的粗细变化，第一张用于层次与蓝紫配色，第四张用于路径意象，第三张用于应用图标与中英品牌层级。参考图不作为最终品牌素材直接使用。

图形采用一条持续上升、逐渐加宽的主曲面，加一条细分流形成留白与层次，表达时间积累、知识成长与投资之道。没有字母 M、下跌折线或回撤谷底。曲线是理念象征，不是实际收益图。

A / 蓝紫复利（blue）：推荐配色。蓝色 #279DFF 到紫色 #9560F3；浅色背景微调为 #168BEA 到 #8551E8。
B / 暖金复利（gold）：深色背景 #FFC529，浅色背景 #BD830C。
C / 单色复利（purple）：深色背景 #A78BFA，浅色背景 #7C55CB。
字标：深色背景 #F5F5F7；浅色背景 #211B30。

品牌名：大师之道；英文标识：MastersTao；域名文字：masterstao.com。

## 素材

三个配色目录均包含中英组合（logo-dark/light）、英文横版（logo-en-dark/light）、单色版（logo-black/white）、独立图形（mark）、favicon，以及 16/32/180/512 px 图标。SVG 字标均为路径，无外部字体依赖。Logo PNG 宽度 2400 px；mark.png 为 1024 × 1024；PNG 保留透明背景。每个配色均有独立 logo-kit.zip。

index.html 支持配色切换与深浅背景切换，下载链接跟随当前配色更新。comparison.png / .svg 为三配色对比图，presentation.png / .svg 为推荐方案展示。

concept-imagegen.png 为使用内置 imagegen 工具、以四张附件作为参考生成的概念稿；imagegen-prompt.txt 是完整提示词。最终生产素材为根据概念制作的干净原生 SVG 及其 PNG 导出，没有对参考图或 AI 位图进行程序化编辑，未使用 CLI/API 回退。素材包不包含字体文件。

已检查 SVG 与渐变引用、字标转路径、PNG alpha、像素尺寸及 ZIP 内容。所有早期版本均保留；未修改线上网站或配置域名。
