## 口径

- 出现：中央汇金资管出现在该公司**前十大股东或前十大流通股东**（同一公司只计 1 次），A 股，剔除 B 股。
- 退出：上季在名单、本季不在。**退出名单 ≠ 清仓**，可能只是持股降到前十之外。
- 排序：按**上一季末**（即最后一次披露时）的持股市值（东方财富 HOLDER_MARKET_CAP，两张表取较大者）。退出当季已看不到持股，所以没有当季市值。
- 特殊情况：中国重工 2025Q3「退出」是因为被中国船舶换股吸收合并、2025-09-05 终止上市，画面中单独标注。
- 数据截至 2026-11-03 下载；2026Q3 已披露 99.9%（见 EP01 数据说明）。
