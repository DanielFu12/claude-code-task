## 一句话

2022Q1，**中央汇金资管**与**中国证金**出现在 **259** 家 A 股公司的十大股东名单里；四年里两条线只是缓慢下滑——**今年以来**，汇金资管 140 → 17（−88%），中国证金 111 → 23（−79%），两家合计只剩 **32** 家，而这 32 家正是 19 个季度从未离开过的那 32 家。名单变短，不等于国家队离场：**名单 ≠ 持仓，出名单 ≠ 清仓**。
