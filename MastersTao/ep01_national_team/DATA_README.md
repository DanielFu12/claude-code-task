# 数据说明：汇金系 / 证金系在 A 股十大股东名单中的出现（2022Q1—2026Q3）

> 一句话：**我们统计的是「名字出现在名单里的公司数」，不是「持仓」，更不是「买卖」。**

## 1. 统计对象与口径

| 规则 | 说明 |
|---|---|
| 名单范围 | 上市公司定期报告披露的 **前十大股东** 与 **前十大流通股东**（一季报、半年报、三季报、年报） |
| 统计单位 | 公司（A 股，沪 / 深 / 北交所；剔除 B 股 900xxx、200xxx） |
| 去重 | 同一公司同时出现在两张表 → 只计 1 次；同一公司出现多个同系主体 → 只计 1 次 |
| 合并去重 | 汇金系 ∪ 证金系，同一公司两系都在也只计 1 次（另单列「交集」） |
| 报告期 | 季末日：03-31 / 06-30 / 09-30 / 12-31，共 19 期 |
| 主体识别 | 以东方财富「股东代码」(HOLDER_CODE) 为准，名称仅作复核：同一主体在不同报告中会出现全称、简称或截断名 |

### 名单 ≠ 持仓

- 只有进入前十名才会被披露；**未出现在名单里，不代表没有持股，更不代表清仓**。
- 名单是季末一天的快照，季度之间的买卖完全看不到；披露滞后 1—4 个月（年报最晚次年 4 月底）。
- 汇金 2023 年以来增持的 **ETF** 不会出现在个股的十大股东名单里（ETF 是基金，个股名单里出现的是基金本身），所以本统计**看不到汇金通过 ETF 持有的部分**。
- 排名变化可能来自其他股东增减持、股本变动、限售解禁等，**不能直接等同于国家队主动买卖**。

## 3. 数据来源

| 数据 | 来源 | 备注 |
|---|---|---|
| 十大股东 / 十大流通股东 | 东方财富数据中心 `datacenter-web.eastmoney.com`，表 `RPT_F10_EH_HOLDERS`、`RPT_F10_EH_FREEHOLDERS` | 整理自上市公司定期报告；原始全量名单按季度存于 `data/raw/*.csv.gz` |
| 上证指数、沪深 300 | 新浪财经日线接口 | 只作市场背景，取季度最后一个交易日收盘 |
| 背景事件 | 新华社、中国证券报、财联社、21 财经等公开报道 | 见下方事件表 |

**统计截止**：2026-10-30 下载。2026Q3 三季报法定披露截止为 10 月 31 日；下载时 2026Q2 有名单的 A 股公司中已有 **99.6%** 取得三季报名单，尚缺 22 家（名单见 `VERIFICATION.md`），这 22 家在 2026Q2 都不含汇金 / 证金，因此**不影响 2026Q3 的数字**。2026Q3 的数字可能在少数后续披露后变化，重新运行 `./build.sh --refetch` 即可。

Q1 / Q3 季报期的公司覆盖数略低于年报 / 半年报期（约少 50—150 家，主要是新股与个别未披露季报名单的公司）。为避免样本变化制造虚假环比，`quarterly_counts.csv` 同时给出 **同口径环比**（只比较两期都有名单的公司：`*_like_for_like_prev/now`），以及「上期在名单、本期公司未披露」的数量（`union_prev_missing_now`，全程最多 1 家）。

## 6. 复现

```bash
cd MastersTao/ep01_national_team
python3 scripts/fetch_holders.py      # 下载 19 季 × 2 表原始名单（已缓存则跳过；--force 重下）
python3 scripts/fetch_index.py        # 指数季末收盘
python3 scripts/build_dataset.py      # 生成全部统计表
python3 scripts/verify.py             # 独立重算 + 画面数字核对 → data/VERIFICATION.md
```

|---|---|
| `data/quarterly_counts.csv` | 每季：汇金 / 证金 / 合并 / 交集 / 扩展口径、环比、同口径环比、分主体、两张表各自口径、覆盖率 |
