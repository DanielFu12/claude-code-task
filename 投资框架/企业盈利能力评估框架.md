# 企业盈利能力评估框架

> 从巴菲特、芒格出发：企业如何创造价值、留住价值、维持价值，并把它复利下去
>
> 终版 · 2026 年 11 月

---

## 0. 一页纸摘要

**核心命题**

一家企业对股东的长期价值取决于五件事：
1. 能否让投入资本回报率（ROIC）持续高于资本成本（WACC）；
2. 维持这个回报要付出多少代价；
3. 多出来的钱能以多高的回报、多大的规模再投出去，以及能不能选择不投；
4. 这一切能持续多久；
5. 企业会不会中途死掉。

**统一公式**

```
经济利润(t)   = (ROIC(t) − WACC) × 投入资本(t)
每股内在价值 ≈ [ 当前投入资本 + 未来各期经济利润的现值之和 ] ÷ 稀释后股数
```

**六层结构（L4 分为 a、b 两部分）**

| 层 | 在公式里负责什么 | 核心问题 |
|---|---|---|
| L0 生存 | 求和会不会被提前截断 | 会不会发生永久性资本损失？（一票否决） |
| L1 价值创造与获取 | ROIC 高出 WACC 的结构性部分 | 凭什么赚到超额回报，而且不被别人拿走？ |
| L2 维持成本 | 扣除维持代价后的真实回报 | 保住现在的利润，要持续花多少？ |
| L3 再投资 | 投入资本的增长路径 | 新增资本能投多少、回报多高、能不能不投？ |
| L4a 资本结构 | WACC、ROE 与 ROIC 的差、股数 | 钱从哪来，代价和风险多大？ |
| L4b 所有权与治理 | 资本流向、激励方向 | 谁在配置资本，激励把他推向哪里？ |
| L5 时间与演化 | 超额回报的衰减路径 | 优势能持续多久，正往哪里迁移，我有多大把握？ |

**五条最重要的规则**

1. 企业长期能留住的利润，不会超过它的**附加值**，也就是"假如它消失，整个交易体系会损失多少价值"。
2. 区分**结构性**超额回报和**周期性**超额回报，只有前者值得按长期去资本化。
3. 不能只看回报率，还要看**维持它的代价**，以及**再投资是不是被迫的**。
4. 资本结构只放大经营结果，不创造经营结果。治理改革带来的经营改善，要回到 L1、L2 检验能否持续。
5. 生存一票否决。**高强制性投入或强周期，再叠加高杠杆**，是最常见的死法。

**框架不做的事**：它评价生意，不评价股票。买不买，还要把每股内在价值和价格比较，并按判断的把握程度要求安全边际。

## 1. 为什么要分层

常见的"盈利模型"之所以总是互相交叉、包含，是因为它们回答的根本不是同一个问题：

| 常见说法 | 实际回答的问题 | 在本框架中的位置 |
|---|---|---|
| 冲浪模型（芒格） | 利润从哪来：技术领先的时间窗口 | L1 机制；维持代价在 L2；强制投入在 L3 |
| 品牌、护城河、伟大生意 | 利润从哪来、能否持续 | L1 + L5 |
| 周期景气模型 | 当期利润中有多少来自供需错配 | L1 的 ROIC 拆分 + L5 周期位置 |
| 现金牛（波士顿矩阵） | 成熟期的竞争位置与现金状态 | 横跨 L2、L3、L5 的复合状态 |
| 并购整合（如啤酒业） | 增长手段 | L3 增长手段 + L4b 资本配置 |
| 3G 资本 | 经营改造 + 杠杆 | L4b（经营改善回写 L1/L2）+ L4a |
| 卡尔·伊坎 | 纠正资本错配 | L4b |
| 保险浮存金 | 融资来源 | L4a |
| 烟蒂股、困境反转 | 投资者的买入时机 | L5 + 估值，不是企业的经营模型 |

因此，描述一家公司不应该只贴一个标签，而应写成：

> **主要价值获取机制 + 辅助机制 + 维持与再投资特征 + 资本与治理安排 + 所处的时间位置**

## 2. 统一公式与口径

### 2.1 价值公式

```
每股内在价值 ≈ [ 投入资本 + Σ 未来经济利润的现值 ] ÷ 稀释后股数
```

在假设一致的前提下，它与自由现金流折现在数学上等价。好处是把价值拆成了可以分别分析的部分：

- 超额回报的幅度：L1、L2
- 投入资本的增长：L3
- 资本成本与股数：L4
- 持续时间：L5
- 是否被提前截断：L0

### 2.2 ROE 与 ROIC 之间的桥

```
ROE ≈ ROIC + (ROIC − 税后债务成本) × 净负债 ÷ 股东权益
```

（忽略非经营性资产、少数股东权益等项目。）

- ROE 高出 ROIC 的部分来自杠杆，属于 L4a，不代表经营能力。
- 巴菲特在 1979 年股东信中说，衡量管理层经营表现的首要标准，是在**不过度使用杠杆、不玩会计花招**的前提下取得较高的股东权益回报率，而不是每股收益的持续增长。
- 大量回购可能让股东权益变成负数（如麦当劳、AutoZone），这时 ROE 失去意义，只能看 ROIC。

### 2.3 口径调整（不调整，公式就会误导）

| 问题 | 处理方式 |
|---|---|
| 研发、品牌广告已费用化，投入资本被低估 | 跨公司比较时，统一把研发（必要时包括品牌投入）资本化后再摊销。但要意识到，See's 这类公司"投入资本极小"本身就是经济事实，不是噪音 |
| 商誉 | 计算两个 ROIC：不含商誉的，评价生意本身；含商誉的，评价管理层的并购有没有赚到资本成本 |
| 经营性负债（应付账款、预收款、递延收入） | 从投入资本中扣除。它们降低投入资本、提高 ROIC，属于经营层 |
| 金融企业（银行、保险） | ROIC 不适用，改用"ROE 对比股权成本"，并按资本充足率、准备金、承保质量做风险调整 |
| 股权激励 | 是真实的经营成本，也是员工分走价值的方式。不要使用剔除股权激励的"经调整利润" |
| 周期性 | 用至少一个完整周期的平均值，不要用单年数据 |

## 3. L0 生存：一票否决

ROE 是第二个问题，第一个问题是活下来。芒格有一句广为流传的话："我只想知道我会死在哪里，这样我就永远不去那儿。"

**主要死法**

| 死法 | 机制 | 典型情形 |
|---|---|---|
| 周期 × 杠杆 | 景气顶部借钱扩产，到了底部现金流断裂 | 航运、化工、地产链 |
| 强制性投入 × 杠杆 | 投入停不下来，利息也停不下来 | 资本密集的技术制造 |
| 依赖外部融资才能运转 | 经营现金流长期为负，靠融资续命，ROE 是借来的 | 高周转地产、部分烧钱扩张的平台 |
| 技术绕道 | 引擎所依赖的那座"桥"被绕了过去 | 互联网对地方报纸 |
| 掉下浪头 | 研发跟不上，或押错了技术路线 | 技术领先型企业 |
| 透支引擎 | 为了短期利润削减维持成本 | 砍品牌投入、降服务质量 |
| 增长毁灭价值 | 规模越大，亏得越多 | 巴菲特 2007 年："最糟糕的生意是增长迅速、需要大量资本才能增长，却几乎不赚钱的生意。想想航空公司。" |
| 集中度风险 | 依赖单一客户、单一供应商或单一政策 | 依附于大客户的供应商 |
| 治理失败 | 管理层失德、财务造假 | — |

**检查项**

- 周期底部的净负债与 EBITDA 之比；
- 利息加必需投入，占周期底部经营现金流的比例；
- 债务的到期结构；
- 经营现金流能否长期覆盖维持性投入；
- 前五大客户的收入占比；
- 对监管的敏感程度。

## 4. L1 价值创造与获取

### 4.1 价值杆与附加值

（Brandenburger & Stuart, 1996；Oberholzer-Gee, 2021）

```
客户最高愿付价（WTP）
    │  客户剩余   = WTP − 价格
价格
    │  企业利润   = 价格 − 成本
成本
    │  供应商与员工剩余 = 成本 − 最低接受价
供应商与员工的最低接受价（WTS）
```

- **价值创造** = WTP − WTS
- 企业能长期拿走的利润，以它的**附加值**为上限：

```
附加值 = 有这家企业时体系创造的价值 − 没有它时体系创造的价值
```

所以，"创新"和"行业增长"本身并不保证利润，关键在于企业是否**不可替代**。

**四个例子**

- **芒格的织布机**（1994 年南加州大学演讲）：更高效的织布机提高了整个行业创造的价值，但每家纺织厂都能买到同样的机器，单个工厂的附加值接近零，好处最终以降价的形式流向了客户。芒格由此说，微观经济学的重要一课，是分辨技术什么时候帮你、什么时候害你。
- **光伏制造**：技术进步大幅降低了发电成本，创造了巨大的价值。但制造商之间高度可替代，价值大多让给了下游和终端用户。2021—2022 年短缺期间，硅料是瓶颈，附加值一度极大；新产能投放后，这部分超额利润很快消失。
- **英伟达**：在 AI 训练领域，GPU、CUDA 软件生态和高速互联组成的整体，在一段时间内难以替代，附加值大，所以拿到了产业链中很大一部分利润。
- **苹果与代工厂**：代工能力可以替换，苹果的品牌与生态不可替换，利润主要留在了苹果。

### 4.2 价值会被谁拿走

| 分走价值的一方 | 什么时候发生 | 例 |
|---|---|---|
| 客户 | 产品可替代，竞争靠价格 | 商品型行业 |
| 竞争者 | 壁垒低，超额回报吸引新进入者 | 多数热门新赛道的后期 |
| 供应商 | 关键投入被垄断 | PC 整机厂商面对 Wintel |
| 员工 | 人才的附加值大于公司平台的附加值 | 投资银行、部分资产管理机构 |
| 政府 | 暴利税、价格管制、集中采购、回报率管制 | 资源、医药、公用事业 |
| 资本提供者 | 高杠杆下，利润主要用来付利息 | 杠杆收购后的企业 |

### 4.3 价值获取机制（护城河）

巴菲特在 1991 年股东信中给"经济特许权"下的定义是：产品或服务（1）被需要或渴望；（2）客户认为没有相近的替代品；（3）不受价格管制。这三个条件是否同时具备，体现在企业能否经常大胆定价，从而获得高资本回报。

与之对照，普通的"生意"只有在**自己是低成本经营者，或者供给偏紧**时，才能赚到非凡的利润，而供给偏紧通常持续不了太久。这一区分正是 4.5 节"结构性回报与周期性回报"的源头。

每种机制都要说清楚两件事（Helmer《7 Powers》）：**利益**，即它作用在价值杆的哪一端；**壁垒**，即竞争者为什么无法复制。

| 机制 | 利益（作用在哪里） | 壁垒 | 例 |
|---|---|---|---|
| 品牌心智 | 抬高 WTP | 心智需要长时间积累，无法用钱快速买到 | See's、可口可乐、茅台 |
| 转换成本 | 客户对在位者的 WTP 高于对新进入者 | 数据、流程、认证、培训的迁移成本 | 企业软件、医疗器械装机量、吉列刀片 |
| 网络效应 | WTP 随用户规模上升 | 后来者在小规模下给不出同等的价值 | Visa、万事达、交易所、微信 |
| 有效规模 / 收费桥 | 限制竞争者数量，从而有定价空间 | 市场只容得下少数几家，新进入者会让所有人都不赚钱 | 评级机构、铁路、机场、区域水泥骨料 |
| 规模成本 / 规模经济分享 | 降低单位成本，并可让利给客户 | 竞争者达不到同等规模 | Costco、沃尔玛、GEICO |
| 买方力量 | 压低 WTS | 采购规模与渠道地位 | 大型零售商、苹果对其供应链 |
| 反定位 | 新模式提供更高价值或更低成本 | 在位者一模仿，就会伤到自己的现有业务 | GEICO 直销对代理人体系、先锋指数基金 |
| 流程能力 / 文化 | 降低成本或提高质量 | 外人难以看清，需要长期积累 | 丰田生产方式、丹纳赫业务系统、纽柯钢铁 |
| 稀缺资源 / 牌照 | 降低成本或限制供给 | 产权或法律 | 低成本矿藏和油田、优质水电、特许牌照 |
| 技术领先（冲浪） | 抬高 WTP 或降低成本 | 时间差、专利、技术积累，但终会到期 | 光刻机、领先 GPU、创新药 |
| 轻资产 / 负营运资本 | 减少所需的投入资本 | 合作方愿意出钱的理由（品牌、流量、规模） | 酒店特许经营、会员制零售 |

最后一项不提高利润率，而是减少投入资本，从而提高 ROIC。它属于经营层，不属于融资层。

### 4.4 每种机制的三个独立属性

不预先把机制分成"结构性"和"能力性"两类，而是对三个属性分别评估：

| 属性 | 含义 | 怎么判断 |
|---|---|---|
| 持久性 | 超额回报回落到资本成本的速度 | 历史 ROIC 的稳定性、对手追赶的速度、替代技术的进展 |
| 执行依赖度 | 是否需要管理层持续做出正确决策 | 巴菲特常被引用的说法："买那些好到傻瓜都能经营的生意，因为迟早会有傻瓜来经营它。"可以问：换一个平庸的 CEO，五年后这家公司还在吗？ |
| 维持强度 | 保住优势需要多少持续投入 | 交给 L2 测算 |

依赖管理层不等于不持久，丹纳赫的流程能力可以积累几十年；拥有结构性优势也不等于可以停止投入，网络平台仍然要持续维护体验与安全。

### 4.5 结构性回报与周期性回报

```
ROIC(t) = 结构性 ROIC + 周期偏离(t)
```

- **结构性 ROIC**：至少一个完整周期（通常 7—10 年）的平均值，并且要和同行同期比较。
- **周期偏离**：由供需错配、库存变化、价格波动带来的暂时性部分。

| 类型 | 结构性部分 | 周期偏离 | 例 |
|---|---|---|---|
| 有优势、弱周期 | 高 | 小 | 消费品牌、软件 |
| 有优势、强周期 | 高（处于成本曲线左端） | 大 | 低成本矿企、低成本化工龙头 |
| 无优势、强周期 | 接近零甚至为负 | 大 | 成本居中的商品生产者 |

第三类公司在景气高点时 ROE 再高，也不应该按长期去资本化。

### 4.6 周期的四种来源

| 类型 | 驱动因素 | 观察重点 |
|---|---|---|
| 需求 / 宏观周期 | 信用、收入、投资 | 信用周期、库存 |
| 供给 / 产能周期 | 资本开支的滞后 | 行业资本开支、产能利用率、出清迹象 |
| 创新驱动周期 | 新技术带来的需求爆发 | 需求增速和产能增速之差；**瓶颈环节在谁手里**（利润流向瓶颈，而瓶颈会随产能投放而移动） |
| 政策周期 | 补贴、准入、集采 | 政策意图及其持续性 |

创新周期不存在统一的"渗透率最赚钱区间"。利润分布取决于供给响应的速度和瓶颈的归属。新技术带来的需求增长，等供给追上之后，往往就变成了普通的产能周期。

巴菲特 1999 年谈汽车和航空时说：投资的关键不在于判断一个行业对社会影响有多大、能增长多少，而在于判断某家公司的竞争优势，尤其是这种优势能维持多久。

## 5. L2 维持成本

### 5.1 定义

为了保住当前的 ROIC 和竞争地位，必须持续消耗的经济资源，包括：

- 已计入利润表的必要费用：维持性研发、品牌维护、服务与质量投入；
- 维持性资本开支；
- 维持经营规模所需追加的营运资本。

巴菲特 1986 年股东信对**所有者盈余**的定义是：报告利润，加上折旧、损耗、摊销和某些其他非现金费用，减去维持长期竞争地位和产量所需的平均年度资本开支；如果还需要追加营运资本，也要一并减去。

### 5.2 两个常见错误

1. **重复扣除**：研发和广告已经在利润表里扣过了，计算所有者盈余时不能再扣一次。
2. **把全部研发都当成维护费**：研发中只有一部分用于维持现有地位，其余是开拓性的。这种拆分只能估算。

### 5.3 三个实用指标

| 指标 | 含义 | 怎么解读 |
|---|---|---|
| 零增长可分配现金流 | 停止一切增长性投入后，每年能分配出来的现金 | 明显高于报表利润，说明维持成本低、企业有选择权（如 See's）；接近甚至低于报表利润，说明维持成本高 |
| 重置成本缺口 | 维持代际位置所需的资本开支 − 会计折旧 | 为正且不断扩大时（如先进制程制造），报表利润会高估所有者盈余 |
| 会计口径差异 | 开发支出资本化、剔除股权激励的"经调整利润" | 会让利润看起来比经济现实更好 |

### 5.4 各机制的维持方式（定性参考）

| 机制 | 维持方式 | 强度 |
|---|---|---|
| 品牌 | 广告、渠道、品质 | 通常较低。See's 1972 年以 2500 万美元买入，到 2007 年只追加了约 3200 万美元资本，累计税前利润约 13.5 亿美元（巴菲特 2007 年股东信） |
| 网络效应 | 产品体验、基础设施、安全 | 中低 |
| 转换成本 | 产品迭代、客户服务 | 中 |
| 有效规模 / 收费桥 | 资产维修与更新 | 中高，但可预测 |
| 规模成本 | 价格让利、物流与门店 | 中 |
| 技术领先 | 研发、先进产能 | 高，而且很难中断 |
| 周期型 | 维持产能与成本位置 | 中高，时点难以把握 |
| 连续并购 | 持续收购以维持增长 | 有机增长弱时，并购本身就成了维持成本 |

## 6. L3 再投资：回报 × 容量 × 强制性

巴菲特 1992 年股东信：撇开价格不谈，最值得拥有的生意，是能在很长时间里把大量增量资本以很高回报率投出去的生意；最差的生意正好相反，持续以很低的回报投入越来越多的资本。

### 6.1 三个变量

| 变量 | 问题 | 怎么衡量 |
|---|---|---|
| 回报 | 投出去能赚多少？ | 增量 ROIC = 新增经营利润 ÷ 新增投入资本（用多年滚动数据）。再投资很少时，改看存量 ROIC |
| 容量 | 能投出去多少？ | 市场空间、可复制的单元（门店、产能、地区）、可收购的标的 |
| 强制性 | 能不能选择不投？ | **停投测试**：停止投入后，市场份额和 ROIC 衰减得有多快 |

强制性有四个来源：

- **技术**：不跟进下一代技术就会出局；
- **竞争**：你不扩产，对手扩产，份额就被抢走；
- **监管**：例如公用事业的供电义务；
- **合同**：合同约定的投入义务。

### 6.2 六种典型组合

| 回报 | 容量 | 强制性 | 类型 | 例 |
|---|---|---|---|---|
| 高 | 大 | 低 | 复利机器：最理想，而且保有"可以不投"的选择权 | 扩张期的 Costco、早期沃尔玛 |
| 高 | 大 | 高 | 高回报跑步机：是好生意，但必须一直跑，L0 要求低杠杆 | 先进制程晶圆代工 |
| 存量高 | 小 | 低 | 优质现金牛 / 巴菲特式的伟大生意，关键在于现金交给谁 | See's |
| 略高于资本成本 | 大 | 高（监管） | 巴菲特所说的"优秀生意" | 受监管的公用事业、铁路 |
| 低 | 大 | 高 | 毁灭价值的跑步机，即巴菲特所说的"糟糕生意" | 航空 |
| 低 | 小 | 低 | 收割或清算 | 伯克希尔早年的纺织业务 |

巴菲特 2007 年股东信把生意分为伟大、优秀、糟糕三类，分别对应上表的第三、四、五行。他还调侃说，如果莱特兄弟首飞那天，基蒂霍克有一位有远见的资本家，他应该把奥维尔·莱特打下来，这对后来的投资者是一大贡献。

### 6.3 与"现金牛"相关的四个概念

| 概念 | 判定标准 | 出处 |
|---|---|---|
| 波士顿矩阵的现金牛 | 市场增长低、相对市场份额高，预期产生的现金超过维持份额所需 | Henderson, *The Product Portfolio*, BCG, 1970 |
| 优质现金牛 | 持久的竞争优势 + 低维持成本 + 多年持续产生盈余现金 | 本框架 |
| 巴菲特式的伟大生意 | 持久护城河、很高的有形资本回报，增长不需要大量新增资本 | 2007 年股东信 |
| 复利机器 | 能持续把大量新增资本投到高回报的机会上 | 1992 年股东信 |

波士顿矩阵按**位置**定义（假设份额高就意味着成本低），巴菲特按**结果**定义（看回报率）。份额很高但没有护城河的公司，可能符合波士顿矩阵的定义，却产生不了盈余现金。现金牛同时涉及 L2（维持成本低）、L3（容量小）和 L5（处于成熟期），所以不单独成为一层。

现金牛的核心问题是**钱去哪**：

- 交给优秀的配置者，就是伯克希尔的结构；
- 投进低回报的多元化，就是巴菲特 1989 年所说的"机构惯性"；
- 被外部人发现，就会成为激进股东和收购方的目标。

### 6.4 增长手段

| 手段 | 说明 | 关键判断 |
|---|---|---|
| 内生扩张 | 复制门店、产能、地区 | 单元经济能否复制 |
| 提价 | 品牌和收费桥的主要增长来源 | 提价后销量和份额能否保持 |
| 第二曲线 | 用现有能力开辟新业务 | 例：亚马逊从零售长出云业务；英特尔 1985 年退出存储芯片、专注微处理器 |
| 行业整合型并购 | 把分散的行业整合成寡头 | 终点是寡头，有反垄断天花板；最后一笔大并购往往最贵（百威英博 2016 年收购 SAB 米勒，2018 年将股息减半以降杠杆） |
| 平台复制型并购 | 用一套方法论连续收购小企业 | 例：丹纳赫、Constellation Software。看收购纪律、去中心化文化，以及标的会不会耗尽 |
| 财务驱动型并购 | 收购后大幅提价、削减研发、依赖会计调整 | 例：Valeant。有机增长为负，靠下一笔收购撑住报表 |

判断并购质量看三点：有机增长和并购增长的比例；含商誉的 ROIC 是否长期高于资本成本；"经调整利润"和法定利润相差多少。

## 7. L4a 资本结构

### 7.1 先区分两类"别人的钱"

| 类别 | 例 | 影响 | 所属层 |
|---|---|---|---|
| 经营性资金 | 应付账款、预收款、递延的会员费、负营运资本、特许经营中由加盟方承担的资本 | 减少投入资本，提高 ROIC | L1 / L2（经营层） |
| 金融性资金 | 债务、保险浮存金、银行存款 | 改变 ROE 与 ROIC 的差，也改变风险 | L4a |

### 7.2 各类金融性资金的真实成本

| 资金 | 成本 | 风险 |
|---|---|---|
| 债务 | 利息 | 再融资风险、周期底部的偿付压力 |
| 保险浮存金 | 承保结果：承保盈利时成本为负，承保亏损时成本可能高于债务 | 准备金不足、巨灾 |
| 银行存款 | 利息 + 网点与运营成本 + 存款保险 + 资本金要求 | 挤兑、资产质量 |
| 股权融资 | 股权稀释 | 低价发行会毁灭每股价值 |

### 7.3 回购与稀释

- 低于内在价值回购，会增加每股价值；高于内在价值回购，是把价值转给了卖出股票的股东。
- 股权激励带来的稀释，是员工分走的价值，应当计入成本。
- 用 2.2 节的桥接公式，判断 ROE 中有多少来自经营、多少来自杠杆。

## 8. L4b 所有权、治理与资本配置

### 8.1 资本配置者

如果生意本身是现金牛，资本配置能力就决定了长期回报。代表是伯克希尔（子公司把盈余现金交给总部，总部再投到回报最高的地方），以及亨利·辛格尔顿领导的 Teledyne。风险在于管理层本身就是护城河，交接是最大的变量。

### 8.2 激励

芒格有一句广为流传的话："给我看激励，我就告诉你结果。"如果按规模或每股收益增长来考核管理层，就会系统性地鼓励低回报并购；按 ROIC 或每股内在价值来考核，管理层才和股东站在一起。这是比"谁在配置资本"更底层的问题。

### 8.3 外部所有者的干预

| 类型 | 做什么 | 可能创造的价值 | 风险 |
|---|---|---|---|
| 3G 模式 | 零基预算、组织精简、用杠杆收购成熟品牌 | 去掉冗余成本，提高结构性利润率 | 一旦削减到维持成本，就是拿未来换现在。卡夫亨氏 2019 年计提约 154 亿美元减值，巴菲特承认"我们为卡夫付了太高的价格" |
| 激进股东（伊坎等） | 推动回购、分拆、出售、更换管理层 | 纠正资本错配；更换管理层也可能改善经营 | 只做财务动作、不改善经营时，不创造新价值 |
| 私募 / 杠杆收购 | 杠杆 + 运营改善 + 估值倍数差 | 运营改善的部分是真实价值 | 依赖利率环境和退出窗口 |

例：伊坎 2013 年推动苹果扩大回购；2014 年推动 eBay 分拆 PayPal，分拆于 2015 年完成。

**回写规则**：外部干预带来的经营改善（成本、效率、定价），必须回到 L1、L2 检验两件事：能否持续，是否以削减维持成本为代价。只有资本结构本身的变化留在 L4。

### 8.4 巴菲特与芒格自身的演变

巴菲特在合伙基金时期做过"控制型"投资，试图修理平庸的生意，例如 1961 年取得控制权的登普斯特农机。在芒格的影响下，他转向"以合理的价格买入一家很棒的公司，远胜过以很棒的价格买入一家普通的公司"（1989 年股东信）。

他在 1980 年股东信中写道：当一个以能干著称的管理层，去接手一个以基本面糟糕著称的生意时，最后保持不变的，往往是生意的名声。

## 9. L5 时间与演化

### 9.1 衰减率

超额 ROIC 向资本成本回落的速度，决定了公式中求和的长度。Mauboussin 把这段时间称为"竞争优势期"。估计依据包括：历史 ROIC 的持续性、行业结构的变化、替代技术、对手追赶的速度。

### 9.2 周期位置

即当期 ROIC 中周期偏离所占的比例（见 4.5 节）。在高点，它会让平庸的生意看起来很伟大；在低点，它会让好生意看起来很平庸。

### 9.3 模型迁移

| 迁移路径 | 例 |
|---|---|
| 技术领先 → 形成标准或生态 → 转换成本、网络效应（冲浪的最好结局） | 英特尔 x86 与 Wintel；英伟达 CUDA |
| 技术领先 → 被追上 → 商品周期 | 英特尔的存储芯片业务；多数光伏、锂电制造 |
| 分散行业 → 并购整合 → 寡头 → 现金牛 | 全球啤酒业 |
| 收费桥 → 被技术绕过 → 收割 | 地方报纸 |
| 技术领先 → 品牌 + 生态锁定 | 伯克希尔 2016 年开始买入苹果时，看重的是消费品牌与生态，而不是技术冲浪 |

### 9.4 困境反转

巴菲特在 1979 年股东信中说："反转"很少真正反转。例外只出现在引擎完好、问题只是一次性的时候：1963 年色拉油丑闻之后的美国运通（巴菲特 1964 年买入），以及 1976 年濒临破产的 GEICO。这两家公司的特许权都没有受到损害。

### 9.5 可预测性与能力圈

能持续和看得懂是两回事。芒格在 1994 年那次演讲里谈到"冲浪"时表示，伯克希尔一般不做这类高科技投资，因为他们在这方面没有判断优势（大意）。

每一层判断都应标注把握程度（高、中、低）。把握越低，要求的安全边际越大，或者干脆把它归入"太难"的那一堆。

## 10. 组合规则

| 组合 | 结果 |
|---|---|
| 技术领先 + 生态锁定 | 有机会转化为结构性优势 |
| 技术领先 + 没有锁定 | 长期处在高强制性投入的跑步机上 |
| 现金牛 + 优秀的配置者 | 伯克希尔模式 |
| 现金牛 + 糟糕的配置者 | 价值黑洞，也是激进股东的目标 |
| 强周期 + 处于成本曲线左端 + 低杠杆 | 能穿越周期，在底部扩张并收割对手 |
| 强周期 + 高杠杆 | 迟早出局 |
| 高强制性投入 + 高杠杆 | 一个下行周期就可能致命 |
| 规模分享 + 克制 | 飞轮持续转动 |
| 规模优势 + 收割利润率 | 自毁护城河 |
| 并购整合 + 维持品牌投入 | 成为寡头 |
| 并购整合 + 削减维持成本 | 短期利润上升，长期走向衰退 |
| 浮存金 + 承保纪律 | 低成本甚至负成本的杠杆 |
| 浮存金 + 承保亏损 | 昂贵的负债 |
| 创新周期 + 掌握瓶颈 | 阶段性超额利润，能否持续取决于瓶颈能否守住 |
| 创新周期 + 不在瓶颈环节 | 替客户和瓶颈方打工 |

## 11. 评估流程

| 步骤 | 做什么 | 核心问题 | 主要数据 |
|---|---|---|---|
| 1. 生存排雷（L0） | 查杠杆、融资依赖、强制性投入、集中度 | 最坏情况下能活下来吗？不过关就停在这一步 | 周期底部的现金流、债务结构 |
| 2. 价值杆（L1） | 画出价值的创造与分配 | 谁创造价值，谁拿走价值，企业的附加值有多大？ | 产业链利润分布、价格与成本结构 |
| 3. 拆分 ROIC（L1） | 区分结构性与周期性；分别计算含商誉和不含商誉的 ROIC | 剔除周期因素后，还剩多少超额回报？ | 10 年以上的 ROIC 和同行对比 |
| 4. 维持成本（L2） | 测算零增长可分配现金流、重置成本缺口 | 保住现在要花多少？ | 资本开支结构、研发结构 |
| 5. 再投资（L3） | 评估回报、容量、强制性 | 新的钱投到哪里，回报多高，能不能不投？ | 增量 ROIC、有机增长、停投测试 |
| 6. 资本与治理（L4） | ROE 桥接、资金成本、回购、并购、激励、稀释 | 管理层怎样融资和配置，激励指向哪里？ | 回购均价、并购后回报、薪酬方案 |
| 7. 时间（L5） | 衰减率、周期位置、迁移方向、把握程度 | 能持续多久？我有多大把握？ | 行业结构、技术路线 |
| 8. 估值 | 每股内在价值与价格对比 | 价格给了多大的安全边际？ | 情景假设 |

**常用判别测试**

- **提价测试**：巴菲特 2010 年接受美国金融危机调查委员会（FCIC）访谈时说，评估一家企业最重要的是定价权；如果提价之前还得先开个祈祷会，那就是糟糕的生意。（提价幅度在不同转述版本中说法不一，见附录 B。）
- **资本测试**：给一个强大的竞争者大量资本，它能否夺走这家企业的地位？巴菲特曾以可口可乐为例说明，再多的钱也做不到（大意）。
- **织布机测试**：效率提升的好处，最终归股东还是归客户？
- **傻瓜测试**：换一个平庸的管理层，五年后这家公司还在吗？
- **停投测试**：停止投入后，市场份额和 ROIC 衰减得有多快？

## 12. 可证伪的指标：每种机制三项

下表的每一项都是待检验的假设，不是判定标准，单一指标从来不足以下结论。

| 机制 | 利润来源指标 | 维持成本指标 | 失效信号 |
|---|---|---|---|
| 品牌 | 提价后的销量与份额；相对同类产品的价格溢价 | 营销费用效率 | 提价后份额连续下滑；渠道库存和折扣上升；年轻客群渗透率下降 |
| 转换成本 | 客户留存率、净收入留存率 | 服务与迭代投入 | 新客户转向替代方案；出现技术换代窗口 |
| 网络效应 | 留存率和变现率随规模改善 | 获客成本、补贴 | 用户同时使用多个平台的比例上升；监管要求互联互通 |
| 有效规模 / 收费桥 | 定价与回报是否稳定 | 维修与更新资本开支 | 出现替代路径；监管下调回报率 |
| 规模分享 | 单位成本随规模下降，并通过降价让利 | 扩张投入的回收期 | 毛利率上升，而客流或会员续费率下降 |
| 技术领先 | 新产品份额；相对同行的毛利溢价 | 研发强度、每一代的资本开支 | 对手追平所需时间缩短；客户开始导入第二供应商 |
| 稀缺资源 | 在行业成本曲线上的位置 | 储量补充成本 | 储量或品位下降；出现替代资源 |
| 流程能力 | 相对同行的成本、质量、周转 | 培训与体系建设投入 | 关键人员流失；并购后体系推行失败 |
| 周期型 | 穿越周期的平均 ROIC、成本曲线位置 | 景气期资本开支的占比 | 行业产能增速持续高于需求增速 |
| 连续并购 | 有机增长；收购后的经济利润 | 每年需要的收购金额 | 含商誉的 ROIC 长期低于资本成本；收购倍数上升 |

## 13. 案例拆解（方法示范）

## 15. 局限与使用边界

1. 客户愿付价、附加值、衰减率都难以精确计量。框架提供的是推理结构，不是计算器。
2. 金融企业需要单独的资本与风险口径。
3. 会计口径（研发费用化、商誉、股权激励）会扭曲 ROIC，使用前需要先做调整。
4. 历史 ROIC 只能证明过去。框架的价值在于追问"为什么"，并为每个判断找到能证伪它的信号。
5. 框架评价生意，不评价价格。

> **伟大的企业，能以合理的代价守住一块别人拿不走的价值，并在机会出现时，把资本转化为更高的每股价值；而且这一切，是你能够理解和判断的。**

## 附录 A：术语

| 术语 | 定义 |
|---|---|
| ROIC（投入资本回报率） | 税后经营利润 ÷ 投入资本。投入资本 = 经营性营运资本 + 经营性长期资产 − 经营性负债；视用途决定是否包含商誉 |
| WACC（加权平均资本成本） | 债务成本与股权成本按资本结构加权 |
| 经济利润 | (ROIC − WACC) × 投入资本 |
| 所有者盈余 | 巴菲特 1986 年定义：报告利润 + 折旧摊销等非现金费用 − 维持性资本开支（及必要的追加营运资本） |
| 附加值 | 有这家企业时体系创造的价值 − 没有它时体系创造的价值 |
| 增量 ROIC | 新增经营利润 ÷ 新增投入资本 |
| 零增长可分配现金流 | 停止一切增长性投入后，每年可分配的现金 |
| 重置成本缺口 | 维持代际位置所需的资本开支 − 会计折旧 |
| 停投测试 | 停止投入后，份额和 ROIC 的衰减速度，用来衡量投入的强制性 |
