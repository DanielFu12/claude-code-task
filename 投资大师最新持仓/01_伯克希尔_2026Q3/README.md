## 配乐与卡点

120 BPM，A 小调 Am–F–C–G，1 小节 = 2 秒。所有镜头切换都在小节线上，所有数字弹出都在拍点上。

| 时间 | 音乐 | 镜头 |
|---|---|---|
| 0–8 s | 前奏：滤波琶音渐开、闷鼓、计数「滴答」 | 总市值从 0 滚到 3,042 亿，第 10 拍落定 |
| 8–12 s | 鼓组进入 | 30 只持仓「星群」 |
| 12–16 s | 停顿式重音（每半小节一击：底鼓 + tom + 和弦） | 新进 1 / 增持 4 / 减持 6 / 清仓 0，每击弹出一格 |
| 16–18 s | 军鼓滚奏 + 上行蓄力 + 半拍静默 | 四格坍缩成光点 |
| **18 s** | **DROP 1**（低频冲击 + 镲） | 闪白冲击波，片名 |
| 18–50 s | 满编主段：四拍底鼓、拍手、十六分踩镲、侧链贝斯、超锯齿和弦 | 前十大环形图（每 2 拍聚焦一只）→ 68.50% → 30 只动作分组逐拍点亮 → 谷歌柱子逐拍升起 → 新进 → 增持逐拍入场 |
| 50–60 s | 半速段、暗色和声 | 减持逐拍入场 → 美国银行趋势线 |
| 60–64 s | 抽空：心跳 + 蓄力 | 巨大的「0」，清仓 16 → 1 → 0 |
| **64 s** | **DROP 2**（加入主旋律） | 「最值得关注的 3 个信号」 |
| 66–84 s | 满编 | 01 苹果 · 02 住房 + 出行 · 03 银行股 |
| 84–88 s | 尾段 | 一句话总结（每 2 拍一行） |
| 88 s– | 终止重击 + 低频余韵 | 片尾 |

每个转场点：前一拍军鼓过门 + 反向镲涌起 + 低沉 whoosh，转场拍上是低音 tom 和柔和镲片；画面同步做光扫和轻推镜。音色压住高频（踩镲、镲片都经过低通），母带响度约 −12 LUFS。
