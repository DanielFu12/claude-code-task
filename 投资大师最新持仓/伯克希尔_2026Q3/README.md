单位约定：每只持仓的主数字一律是**持仓市值（亿美元）**，占比作为辅助；凡是股数都写「股」（如 1.06亿股），凡是金额都写「亿美元」，百分比注明是「市值占比」还是「持股数变化」；每张图的纵轴写明「持股数（股）」。

相邻镜头之间不交叠：上一镜头在转场拍之前完全退场，下一镜头从转场拍开始入场。`python3 check_overlap.py` 会每 0.1 秒采样全片，检查有没有两段同时可见的文字互相遮挡，并检查每段文字用的字体里有没有缺字（当前：无遮挡、无缺字）。

每个转场点：前一拍军鼓过门 + 反向镲涌起 + 低沉 whoosh，转场拍上是低音 tom 和柔和镲片；画面同步做光扫和轻推镜。音色压住高频（踩镲、镲片都经过低通），母带响度约 −12 LUFS。

- `src/data.py`：全部数据与口径说明；`fetch_page.js`：用无头浏览器抓取参考网页
