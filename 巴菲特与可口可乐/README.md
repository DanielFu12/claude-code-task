# 38年，一股未卖 —— 巴菲特与可口可乐

> 一笔始于 1988 年、跨越 38 年的投资：从 13 亿美元到 376 亿美元，每年股息 8.48 亿美元。
> 但这不是一部歌颂“永远不卖”的片子——它要讲清楚：**长期持有本身并不创造价值，真正创造财富的是企业持续增长的内在价值。**

## 切入点（已核实）

可口可乐 **2026-10-16 收盘 93.90 美元，创历史最高收盘价**；10-15 盘中最高 94.10 美元（Nasdaq / Yahoo 日线一致）。
按此价格：伯克希尔持有的 4 亿股（13F，2026-06-30 仍为 4 亿股）市值约 376 亿美元，成本 12.99 亿美元；
2026 年股息 0.53×4×4 亿 = 8.48 亿美元（全年预计，约为成本的 65%）。

## 制作方式

- **旁白（整段录制，去 AI 感）**：Gemini TTS `gemini-3.8-flash-tts`，音色 **Charon**（与“巴芒价值”系列统一）。
  不再逐句生成：按叙事段落（开场 / 各章，共 9 段）一次读完，句与句之间的语气、换气、停顿由模型自然衔接；**不变速、不压停顿**。
  每段 1–3 个候选：Gemini 转写逐字校对（读错/多读的淘汰，如多出一个“啊”的录音被弃用），再随机顺序多轮盲听选最自然的一条；
  “卖/买”等易错声调另做定向核查（`src/tts_passage.py`、`src/select_takes.py`）。
  选定录音用 torchaudio MMS_FA 强制对齐到文本（中文转拼音），在句间停顿正中切开，44 句逐句转写复核切点；
  每个字的发声时刻用于字幕与画面对位（`src/align.py`、`src/voice_build.py`）。各段统一响度，叠一层很轻的房间混响。
- **呼吸感**：段内保留原录音的自然停顿（0.35–1.0 秒）；章节卡前后、“为什么？”之后（1.4 秒）、“但这条路，并不平坦”之前都留出空气。
- **配乐（按叙事节点逐帧对位）**：Lyria `lyria-3-pro-preview` 为各章分别生成原创管弦乐（大鼓、铜管、弦乐、无词合唱），
  由 Gemini 听审 + 起音/能量分析挑出每段的真实重拍。`src/score.py` 把每段的高潮钉在叙事节点上（标题、“1988 年夏天”、
  “多因素合奏效应”、“376 亿”、“因为生意没有变坏”、主题句、“时间”、logo）：节点之间按整小节（不得已时半小节）剪辑，
  再做 ±2.5% 以内、保持音高的 rubberband 微变速，**11 个重拍与节点误差均在 ±25ms 内（不到一帧）**。
- **点燃与收放**：最重的重拍前 3 秒音乐慢慢退后 6dB、最后 0.3 秒“收气”，重拍处闪避让路、随后托起 2.5dB；
  重拍前 1.2–1.5 秒做低通扫频，顺带去掉原曲里的上升音 / 镲片 / 白噪扫频；章节交接留 2.5 秒低沉混响拖尾，避免“切歌”感；
  “因为生意没有变坏”叠加一记同一套素材里的真实管弦重击。低频冲击（<220Hz，合成）叠在每个重拍上。
- **混音**：说话时配乐 -8dB，人声频段（700Hz–3.2kHz）再让 4.5dB；配乐只做轻微高频控制；主输出 -14 LUFS（成片编码 -1.2dB 留峰值余量）。
- **画面**：`src/engine.py`（无头 OpenGL/llvmpipe 光线步进 + numpy 合成）；三维玻璃弧形瓶（折射、液体吸收、气泡、轮廓光）、
  糖浆滴落、点阵地球（Natural Earth）、拆股立方体与全部数据图表均为代码原创；历史照片为美国国会图书馆 FSA 公有领域作品。
- **英文引言卡**：卡片下方的光斑、景深与光晕全部压暗（`clear_glow`），文字带阴影，逐张检查可读性。
- **真实影像**：股东大会和访谈视频由 CNBC 等持有版权，未获授权，因此未剪入；大师的“声音”以可核实的致股东信 / 演讲原文
  （英文原句 + 中文翻译 + 出处）呈现，未用 AI 模仿巴菲特或芒格的声音。详见 `docs/SOURCES.md` 第 7 节。

## 重新生成

```bash
./build.sh          # 需要 ffmpeg、python3（numpy opencv-python-headless pillow soundfile librosa scipy pyloudnorm moderngl）、
                    # Mesa EGL（apt install libegl1 libegl-mesa0）；生成旁白/配乐需要 Gemini API
python3 src/film.py work frame 150s out_#.jpg    # 单帧预览
python3 src/make_docs.py work                     # 重新生成 docs/SOURCES.md
```

目录：`src/` 全部源码 · `data/` 行情数据与收益计算 · `assets/archive/` 历史图片（附 `credits.json`）· `assets/geo/` 陆地轮廓 ·
`assets/generated/` 已选定的整段旁白（`tts_p/` 9 段 + 选择记录）、旧版逐句旁白（`tts/`，仅作缺段时的后备）与选用的 8 段 Lyria 配乐素材（`music2/`）· `docs/` 资料来源与发布文案。
`work/` 为中间文件（候选配乐、混音、分段视频），不入库。
