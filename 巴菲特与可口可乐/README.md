# 38年，一股未卖 —— 巴菲特与可口可乐

> 一笔始于 1988 年、跨越 38 年的投资：从 13 亿美元到 376 亿美元，每年股息 8.48 亿美元。
> 但这不是一部歌颂“永远不卖”的片子——它要讲清楚：**长期持有本身并不创造价值，真正创造财富的是企业持续增长的内在价值。**

## 切入点（已核实）

可口可乐 **2026-10-16 收盘 93.90 美元，创历史最高收盘价**；10-15 盘中最高 94.10 美元（Nasdaq / Yahoo 日线一致）。
按此价格：伯克希尔持有的 4 亿股（13F，2026-06-30 仍为 4 亿股）市值约 376 亿美元，成本 12.99 亿美元；
2026 年股息 0.53×4×4 亿 = 8.48 亿美元（全年预计，约为成本的 65%）。

## 制作方式

- **旁白**：Gemini TTS `gemini-3.8-flash-tts`（已核实模型标识可用），音色 **Charon**（与“巴芒价值”系列旁白统一）；
  导演提示要求“像真人纪录片讲述者娓娓道来、在逗号/破折号处换气”。每句生成后用 Gemini 转写回听，与字幕逐字比对。
  统一 1.16 倍速（ffmpeg atempo，不变调）；句内停顿上限 0.45 秒。
- **呼吸感**：章节卡前后、钩子“为什么？”之后（1.4 秒）、第四章“但这条路，并不平坦”之前（章节卡后再留 0.9 秒）、
  核心句前后（0.6–1.0 秒）都留出整段无旁白的空气；配乐在这些地方抬起。
- **配乐**：Lyria `lyria-3-pro-preview` 按本片章节时间点生成两段原创器乐（各 3 个候选，用包络图 + 听审挑选），
  剪成 A / C / B 三段；章节切换、标题、拆股、市值揭晓、片尾 logo 都卡在配乐的重拍上：旁白比音乐长时，在平稳段按整小节（拍点对齐）重复，短时按整小节剪掉（`src/music_plan.py`）。
- **声音设计**：转场全部是合成的 sub drop / 低频冲击 / 心跳，低通到 220Hz 以下；配乐整体柔化高频，并对原曲里的上扬、镲片
  过渡段做自动 + 手动低通；有旁白时配乐 -10dB 且人声频段再让 3dB，无旁白时音乐抬起；主输出 -14 LUFS。
- **画面**：`src/engine.py`（无头 OpenGL/llvmpipe 光线步进 + numpy 合成）；三维玻璃弧形瓶（折射、液体吸收、气泡、轮廓光）、
  糖浆滴落、点阵地球（Natural Earth）、拆股立方体与全部数据图表均为代码原创；历史照片为美国国会图书馆 FSA 公有领域作品。
- **英文引言卡**：卡片下方的光斑、景深与光晕全部压暗（`clear_glow`），文字带阴影，逐张检查可读性。
- **真实影像**：股东大会和访谈视频由 CNBC 等持有版权，未获授权，因此未剪入；大师的“声音”以可核实的致股东信 / 演讲原文
  （英文原句 + 中文翻译 + 出处）呈现，未用 AI 模仿巴菲特或芒格的声音。详见 `docs/SOURCES.md` 第 7 节。

## 重新生成

```bash
./build.sh          # 需要 ffmpeg、python3（numpy opencv-python-headless pillow soundfile librosa scipy pyloudnorm moderngl）、
                    # Mesa EGL（apt install libegl1 libegl-mesa0）；生成旁白/配乐需要 Gemini API
python3 src/film.py work frame 150s out_#.jpg    # 单帧预览
python3 src/make_docs.py work                     # 重新生成 docs/SOURCES.md
```

目录：`src/` 全部源码 · `data/` 行情数据与收益计算 · `assets/archive/` 历史图片（附 `credits.json`）· `assets/geo/` 陆地轮廓 ·
`assets/generated/` 已生成并选定的旁白（44 句 wav）与 3 段 Lyria 配乐（重建时直接复用）· `docs/` 资料来源与发布文案。
`work/` 为中间文件（候选配乐、混音、分段视频），不入库。
