# AI 越快，越要慢 —— 李录、巴菲特、芒格谈复利

竖屏投资思想短片，1080×1920，30fps，6 分 35 秒。**第三版。**
- **热点开场**：李录 2026 年 10 月在哥大格雷厄姆与多德年度活动的**官方高清录像原声**。
- **大师原声**：巴菲特 1999 年股东大会、芒格 BBC 专访与 USC 演讲。
- **解说**：用 Gemini TTS 串联，讲清楚「复利的秘密不是更快，而是不失去」。
- **动画**：约 1 分 35 秒，讲复利的第一性原理和人生的复利。
- **片尾**：按系列准则制作的品牌片尾。

## 声音

- **解说**：只用 Gemini TTS `gemini-3.8-flash-tts`（声音 charon）。
  - 每个段落一次合成，保证语气连贯；关键句前加呼吸或停顿标签。
  - 合成后用 faster-whisper 逐字对齐，在句间能量最低处切句；稿子覆盖率不到 0.88 就重新合成。
  - 用 rubberband 轻微提速，保留音高与共振峰。
- **配乐**：用 Lyria 3 Pro 按分镜生成三段原创配乐，在 `assets/music3/music3.json` 里按实测重拍卡点：
  - **开场**：持续推进，47.95 秒的大鼓落在片名上；
  - **铺底**：克制，铺在原声与解说下面；
  - **高潮**：85.43 秒的高潮重拍落在总结句上，其后的强拍落在片尾「巴芒价值」字标上。
- **混音**：
  - 原声期间配乐压低约 15dB，解说期间约 10dB，并挖开 1.2–4.5kHz 的语音频段；
  - 片名、动画重拍、总结、片尾把配乐推起来；
  - 低频音效全部在 200Hz 以下；
  - 母线约 −14 LUFS。
