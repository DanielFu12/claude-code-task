## 声音设计

- **配乐**：用 Google Lyria 3 Pro 按分镜生成的两段原创配乐（主题段 2:38、高潮段 1:20），提示词里写明了每个段落的起止时间。我从 6 个候选里挑出了结构最贴合、高频最干净的两段，然后实测它们的重拍时间（0:32.0、2:57.2、3:21.6、3:43.4、3:45.8），把画面锚定在这些点上（`src/timeline.py`）。
- **低频音效**（`src/audio.py` 本地合成）：Sub Drop、低通轰鸣、低频脉冲和涨落，最后统一做 200Hz 低通，没有白噪声、刺耳的 whoosh 或尖锐的上升音。配乐的高频也做了约 −4.5dB 的柔化。
- **动态混音**：旁白出现时，侧链自动把音乐压低约 8dB；没有旁白时音乐抬高约 2dB。片头重拍前 1 秒先把音乐"吸"下去，让重拍更有冲击力。母线响度约 −14 LUFS，峰值低于 −1 dBFS。
- **旁白**：只用 Gemini TTS `gemini-3.8-flash-tts`（音色 Orus）。每条旁白生成后都用 Gemini 做语音转写，和原文逐字比对，读错、漏读或把提示词读出来都会重新生成。

## 重新生成

```bash
./build.sh                  # 需要 ffmpeg、python3：numpy numba opencv-python-headless pillow soundfile librosa scipy pyloudnorm fonttools
python3 src/render.py still 33 177.5 226    # 只渲染几帧静帧检查
```

`src/script.py` 是全部文字和数字的唯一来源；`src/scenes.py` 是分镜；`src/engine.py` 是一个用 numba 写的小型渲染器，包括解析光线追踪的玻璃方块（菲涅尔反射、边缘高光、厚度吸收、折射）、3D 粒子景深和多尺度辉光。
