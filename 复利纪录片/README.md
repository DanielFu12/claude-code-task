## 原始影像的处理

- **8 段原声，约 2 分 04 秒**；李录合计 53.5 秒（< 1 分钟）。片段定义（出入点、裁切、中英字幕）都在 `src/clips.py`。
- **出入点和字幕时间**来自本地 Whisper 的词级时间戳，Gemini 独立转写交叉核对。
- **画面**：B 站转载版本带有转载者的硬字幕和水印。`src/prep_clips.py` 会按人物位置逐帧追踪裁切（李录的头部位置由 Gemini 每秒标注一次，见 `assets/track/`，再做平滑），用 `src/desub.py`（顶帽检测白字黑边笔画 → inpaint）去掉压在画面上的旧字幕，并裁掉所有水印。画面里的所有字幕都是本片重新制作的。
- **合成**：影像窗口在色调映射之后、以显示空间合成，原始画面的颜色不会被改动；背景用同一帧的模糊放大版铺底。
- **声音**：每段原声单独做响度归一（约 −20 LUFS）和 85Hz 高通；原声出现时，侧链把音乐压低约 10dB。

## 声音设计

- **配乐**：Google Lyria 3 Pro 按分镜生成的两段原创配乐，画面锚定在实测重拍点上（`src/timeline.py`）。
- **低频音效**（`src/audio.py` 本地合成）：Sub Drop、低通轰鸣、低频脉冲，统一 200Hz 低通；每段原始影像入场有一个轻微的低频落点。
- **母线**：约 −14 LUFS，峰值低于 −1 dBFS。
- **配音**：本版没有 AI 配音（按要求先不使用 TTS），所有讲话都是原声。

## 重新生成

```bash
tools/fetch_footage.sh      # 下载原始影像到 footage/src/
./build.sh                  # 处理片段 → 混音 → 并行渲染 → 合成
python3 src/render.py still 20 60 120 200   # 只渲染几帧静帧检查
```
