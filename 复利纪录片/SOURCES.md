## 四、数学计算依据

全部数字都在 `src/script.py` 的 `MATH` 里统一计算，画面直接引用这些值：

| 画面 | 计算 | 结果 |
|---|---|---|
| 每年 +10%，30 年 | 1.1³⁰ | **17.449** 倍（画面显示 17.45 / 17.4） |
| 每年 −10%，30 年 | 0.9³⁰ | **0.0424** 倍（"只剩 4%"） |
| 两者差距 | (1.1/0.9)³⁰ | **411.6**（"相差约 412 倍"） |
| −50% 后回到原点 | 0.5 × (1+x) = 1 → x = +100% | 需要 **+100%** |
| 按每年 +10% 恢复要多久 | ln 2 / ln 1.1 | **7.27 年**（"7 年多""7.3 年"） |
| 永久性 −50% 对终值的影响 | 乘法满足交换律：终值 = 本金 × Π(1+rᵢ)；多乘一个 0.5，不论在哪一年，终值都 ×0.5 | 30 年 +10% 的路径上叠加一次永久 −50% → 8.72 倍；恢复 7.27 年后到 17.45 倍时，没有中断的路径已是 17.45 × 1.1^7.27 = **34.9** 倍 |
| 可口可乐分红隐含年均增速 | (704/75)^(1/28) − 1 | **8.33%**（画面里只有两端是真实数据，中间曲线明确标注为示意） |

**假设与边界（画面上也有标注）：**
- 这是数学示意：假设固定年化收益率，不计税费、通胀和分红再投资的差异，不代表任何资产的预期收益。
- **暂时回撤 ≠ 永久损失。** 企业内在价值还在、投资者没有被迫卖出时，价格的暂时下跌可以等回来。伯克希尔 2008–09 年下跌 50.7%，但 1965–2017 年仍有 20.9% 的年复合回报。永久损失是指企业价值真的受损（看错企业），或者因为杠杆被迫在低位卖出。影片没有说"永远不能亏损"。
- 知识、信任、技能、健康部分明确标注为「类比，不是等式：这些领域没有固定的'收益率'」。
