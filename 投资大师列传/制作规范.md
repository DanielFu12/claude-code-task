# 投资大师列传 · 视频制作规范

本规范来自第 04 集《沃伦·巴菲特：股神的复利人生》的制作过程和用户的多轮反馈。后续每一集都按本规范制作，以第 04 集的代码为模板（`04-沃伦·巴菲特/`）。

> 标注 **【硬性】** 的条目是用户明确提出过的要求，不得违反。

---

## 一、分支与目录

- **【硬性】** 本系列只在分支 `claude/beautiful-archimedes-o816wj` 上开发，长期独立维护，**不得合并到 `main`**，也不要对 `main` 开 PR。需要 `main` 的新内容时只能 `main → 本分支`。
- 每集一个目录：`投资大师列传/NN-大师名/`，集数和标题以 `选题规划.md` 为准。
- 目录结构（照搬第 04 集）：

```
NN-大师名/
├── README.md            # 本集说明：素材来源、配乐、卡点、生成方法
├── 脚本.md               # 分镜脚本（由 src/shots.py 生成，不要手改）
├── build_r.sh           # 竖屏成片一键生成（主交付）
├── build.sh / build_v.sh  # 横屏版 / 竖屏 Lyria 配乐版（备选）
├── assets/              # 画面素材 *.jpg、配乐 music/
├── src/
│   ├── shots.py         # 分镜数据（唯一事实源）
│   ├── assets.py        # 画面素材提示词与生成
│   ├── music_r.py       # 配乐编排 + 时间线（主）
│   ├── render_v.py      # 竖屏逐帧渲染（主）
│   └── music.py / music_v.py / render.py   # 横屏和 Lyria 版
└── NN-大师名：标题（竖屏）.mp4
```

- `work/`、`fonts/`、`__pycache__/` 不入库（`.gitignore`）。
- 成片 `*.mp4` 走 Git LFS（仓库 `.gitattributes` 已配置），提交前确认文件已写完。

## 二、交付形态

## 三、内容与脚本

### 3.1 形式
- 参照编年体人物短片：**没有旁白**，靠音乐和字幕推进，按年份从家世讲到「今天」，最后用一句话总结一生。
- 标题统一为「大师名：一句话主题」，与 `选题规划.md` 一致。

### 3.2 章节结构（参考第 04 集，可按人物调整章名）
1. 序章：标题 + 家世 + 出生地地图
2. 少年 / 起步
3. 师承 / 思想来源
4. 成名之路（事业第一阶段）
5. 代表性投资（**经典投资案例要充分**：每个案例给出年份、金额、结果）
6. 坚守与逆行（逆势判断、危机中的出手）
7. **错误清单**（**经典失败案例**，单独成章，每条标类型：卖早、坏行业、买贵、能力圈外、买在高点、错过……）。章尾落在「他犯过错，但从没犯过让自己出局的错」一类的主题上
8. 落幕（晚年、交棒、现状）
9. 尾声（关键数据对比 + 总结卡 + 一句话总结）
10. 片尾 logo 动画

### 3.3 分镜数据 `src/shots.py`
- 每个镜头一条 `dict`，字段：`ch`（章节首镜才写）、`kind`（title / map / photo / film / card / quote / data / end）、`year`、`age`、`lines`（最多 2 句）、`bg`（素材 id）、`fx`（动画）、`tag`（错误清单小标）、`visual`（画面说明）、`dur`（脚本时长，仅作比例参考）。
- `脚本.md` 由 `python3 src/shots.py > 脚本.md` 生成，**不要手改**。
- 字幕：`【】` 包住的词显示为红色，用于关键词（金额、公司名、「首富」等）。每句尽量 ≤ 20 字，长句在逗号处断开。
- 年龄：**按生日精确计算**（事件发生在生日前要减一岁），关键节点才标年龄。
- 年份接连出现时用「同年」。
- 引语用「」，一定是本人公开说过的话的忠实意译。

### 3.4 事实核对
- 金额、年份、比例、原话都要可查证。`脚本.md` 第四节列出「待核实事项」，**发布前逐条核对**。
- 对现状（「今天」）的描述要以制作时的最新公开信息为准。

## 四、画面素材

### 4.1 AI 示意图（`src/assets.py`）
- 用 Gemini 图像模型（`gemini-3.1-flash-image`）生成 16:9 复古纪实风格示意图。
- 风格按年代：1930–60 年代黑白泛黄胶片；70–90 年代褪色彩色胶片；2000 年后现代纪实电影感。
- **不画真人正脸**（背影、远景、剪影、虚焦），**不出现可读文字和真实商标**。
- 提示词末尾统一加构图要求：左下三分之一留出安静区域给字幕。
- 额度不足生成失败时，在 `render_v.py` 的 `FALLBACK` 里指定风格相近的已有素材顶替，并在 README 里注明，额度恢复后补图。
- 素材入库前压缩为 JPEG q88（每张约 300KB）。

### 4.2 程序化画面
- **地图**：`global-land-mask` 点阵世界地图，镜头从大范围俯冲到目标，红色定位针落下 + 脉冲圈 + 黄色地名。终点停在**能看到海岸线的大陆尺度**，不要放大到满屏都是陆地。跨大洋时中途拉远。
- **数据动画**：折线、柱状、数字滚动、财富曲线等写在 `render_v.py` 的 `fx_draw`，数字跟随节奏滚动。
- **纸卡 / 引语卡**：浅灰纸纹底 + 米白卡片 + 黄色描边（错误清单用红色描边），可配带白边的小照片。

## 五、竖屏版式（1080×1920）

| 区域 | 规范 |
|---|---|
| **顶部** | **【硬性】** 不要贴顶。品牌角标 `HUD.y0 = 112`，右边距 48；左侧系列名「投资大师列传 · 大师名」30px 金色（y≈102），下面黄色竖条 + 「第N章  章名」42px 白色（y≈150），与角标上下对齐 |
| 关注语胶囊 | 角标下方右对齐，y≈206，右边距 36 |
| 错误清单小标 | 左侧 y≈290，红底白字 40px |
| 中部画面带 | y 540–1148（1080×608），16:9 清晰画面 + Ken Burns；背景为同图放大、模糊、压暗（×0.42）铺满；画面带上下各一条淡白细线 |
| 下部字幕 | 年份大字 y≈1200，`sans_black` 128px 黄色 `#FFD400`（年龄 92px）；字幕 54px 白色，左侧 10px 黄色竖条（错误清单用红色），最大行宽 870px |
| 纸卡 | 照片 900×506 在 y≈390；卡片宽 960 在 y≈990 |
| 数据图表区 | x 110–970，y 430–1060 |
| 底部 | **【硬性】** 不放「画面为 AI 生成示意」等说明文字 |

- **换行**：长句优先在「，、：；」处断开；没有标点可断的长句在 `BREAKS` 里手工指定断点；避免末行只剩一两个字，避免标点落在行首。
- 字体（Google Fonts，`build_*.sh` 自动下载）：思源黑体 Noto Sans SC（900/700/400）、思源宋体 Noto Serif SC（900/600）、Cormorant Garamond（BUFFETT · MUNGER）、Oswald（数字）。
- 颜色：黄 `#FFD400`，红 `#FF3B30`，金色渐变 `#FFF3C8 → #FFD478 → #E2A03C → #FFD682`（与 `brand/` 一致）。
- 全片统一加暗角和轻微胶片颗粒。

## 六、品牌

- **【硬性】** 右上角全程挂「巴芒价值」角标，统一用 `brand/`（`from brand import Hud`），不自己画 logo。竖屏下 `Hud(scale=1.0, frame_w=1080)`，并把 `y0` 下移（见上表）。片尾 logo 动画期间隐藏角标。
- logo 光晕必须在**加了边距的画布**上做模糊，否则会裁出方框（第 04 集踩过的坑）。

## 七、片头

- **【硬性】** 只出现「大师名」（思源宋体 150px 金色渐变）和「标题主题」（76px），**不要横线，不要「投资大师列传 · NN」系列名**。
- 动画：飘雪背景，金色粒子旋转汇聚成大师名，副标题随后擦出。时长约 5 秒，放在配乐前奏里。

## 八、配乐、卡点与情绪递进

### 8.1 配乐来源
- **默认使用参照片配乐**（`assets/music/ref_bgm.m4a`，用户已获使用授权）。其他第三方音乐在没有确认授权前不得使用。
- 有更高音质的原曲时直接替换 `ref_bgm.m4a`，卡点逻辑不变。
- 备选：Lyria 原创配乐（`music_v.py` / `build_v.sh`）。

### 8.2 分析原曲（换曲时要重做）
- 逐拍追踪拍点（`librosa.beat.beat_track`，不要用匀速网格，原曲有轻微漂移）。
- 找重拍：短时响度相对 1 秒滑动平均的突起（prominence ≥ 6 dB，间隔 ≥ 4 秒）。参照片的曲子约每 4–7 秒一个重拍，比周围高约 9 dB，结果写入 `HITS_SRC`。

### 8.3 延长
- 用 `SEGS` 拼接原曲片段，**每个接缝两边都必须是重拍**，在重拍前 20ms 交叉淡化，接缝被重拍掩盖。保留原曲尾奏做结尾。

### 8.4 阅读节奏
- **【硬性】** 画面不能切得太快，要让人看得完。每个镜头的阅读时长 = 1.0 + 字幕字数 / 8（秒），至少 3.5 秒；地图、数据动画另加 0.8 秒，纸卡和引语卡另加 0.5 秒，片头 5 秒。
- 全片时长 = 各镜头阅读时长之和（按重拍调整）。第 04 集平均每镜约 4.75 秒。

### 8.5 卡点
- **章节开头必须落在重拍上**：用动态规划在所有重拍中整体挑选各章起点，使每章实际时长尽量贴近阅读需要（短于需要的惩罚加倍）。
- 章内镜头按阅读需要比例分配；章内其余重拍吸附到最近的切镜点（±1.3 秒内），吸附后任何镜头不得短于阅读需要的 88%（且 ≥ 3 秒）；其余切点对齐拍点。
- 片尾：粒子汇聚从倒数第二个大重拍开始，**logo 在最后一个大重拍浮现**，4 拍后出金色文字。

### 8.6 情绪递进（时变低通 + 增益）
| 段落 | 处理 |
|---|---|
| 序章 | 低通约 900Hz，音乐发闷，像回忆；上升音效进入第一章 |
| 少年 / 起步 | 低通约 3200Hz，偏暖，像老收音机 |
| 师承 | 从 5500Hz 逐渐打开 |
| 成名之路起 | 完全打开 + 大冲击 |
| 错误清单 | 低通约 1500Hz、整体压低约 3 dB，压抑感 |
| 落幕 | 从 1800Hz 慢慢打开 |
| 尾声 | 全开，配大冲击 |

- 大落点（`DROPS`：少年、成名之路、代表性投资、尾声）前：上升音效 4 拍 + **半拍空白**（音乐压到 15%）+ 冲击。检查标准：冲击后 1 秒的响度比冲击前高约 5 dB 以上。

### 8.7 合成音效（`music_v.py` 里的函数，代码合成，不用外部素材）
| 时机 | 音效 | 增益 |
|---|---|---|
| 章节开头 | `impact`（大落点 1.0 / 其他 0.6）+ 前置 `riser` | 0.75 / 0.45 |
| 踩重拍的切镜 | `impact(0.45)` | 0.3 |
| 普通切镜（能量 ≥ 0.6 的章节） | `whoosh`，左右交替 | 0.12 |
| 错误清单切镜 | `glitch` | 0.3 |
| 错误清单印章 | `stamp` + 轻 `impact` | 0.9 |
| 片尾 | `riser` → `reverse_swell` → logo `impact` → 文字 `impact` + `shimmer` | 见代码 |

- 混音后 `tanh` 软限幅，峰值归一到 0.93；成片平均响度约 −16 dB，峰值约 −0.5 dB。

## 九、转场与画面卡点（`render_v.py`）

| 类型 | 用在哪 | 做法 |
|---|---|---|
| 章节冲击 `impact` | 章节首镜 | 闪白 0.8 衰减 0.35s + 放大 1.12 回弹 + 抖动 0.5s；画面中央弹出「第N章 + 章名」（纯数据镜头放到图表上方） |
| 重拍转场 `hit` | 踩重拍的切镜 | 闪白 0.45 衰减 0.2s + 放大 1.07 回弹 + 轻微抖动 0.32s |
| 纵向推移 `push` | 普通切镜 | 0.24s 上下推移 + 纵向运动模糊 |
| 故障 `glitch` | 错误清单 | RGB 错位 + 横向切片错移 0.16s |
| 淡化 `fade` | 序章、落幕、片尾 | 0.35s 交叉淡化 |

- 年份大字随切镜弹出（1.35 → 1 回弹），字幕晚半拍从左擦出。
- 能量高的章节在重拍上画面带轻微脉冲；尾声加暖色漏光；落幕首镜渐变黑白。
- 错误清单：画面降饱和偏冷，章首红色印章「错误清单」随闷响盖下，章尾印章淡出、金色重新亮起。

## 十、关注语

### 10.1 正片中途关注语胶囊（参照分支 `claude/festive-brown-49d0no`）
- 深色半透明圆角胶囊（`#080910`，不透明度 0.62），左侧官方 logo 60px（`brand/logo_baman.png`），右侧白字 38px「**关注 @巴芒价值**」。
- 收尾那一次多一行金色小字 26px「**更多投资大师 · 主页合集**」。
- 每次 4.5 秒：0.4 秒淡入加 14px 上滑，0.4 秒淡出；不闪烁、不扫光。
- 时刻：正片开始约 50 秒后第一次，之后每隔约 150 秒一次（距收尾 ≥ 90 秒），收尾一次在片尾前约 25 秒；都在镜头开始 0.8 秒后出现，避开切镜瞬间。

### 10.2 片尾关注语
- **【硬性】** 片尾底部不写「投资大师列传 · NN …」，改为关注语：「**关注「巴芒价值」，传承大师智慧，领悟投资真谛**」（金色渐变 40px），由一条展开的细金线引出。

## 十一、片尾 logo 动画（约 17 秒）

1. 全片画面拼成的马赛克闪现（回忆感）
2. 马赛克碎裂成约 1.8 万颗粒子（颜色取自画面，带运动拖尾），螺旋旋入，汇聚成官方 logo 的形状（在 logo 浮现前约 0.6 秒成形）
3. **在最后一个大重拍上**：清晰的官方 logo 居中浮现（闪白 0.4、冲击波圆环、背后旋转光芒、淡蓝光晕）
4. 4 拍后：金色「巴芒价值」（思源宋体 150px）回弹砸下，「BUFFETT · MUNGER」随后出现，流光扫过两次
5. 细金线展开 → 金色关注语
6. 最后 2.4 秒整体淡出，随尾奏结束

## 十二、制作流程与检查清单

### 12.1 新一集的起步
1. 复制 `04-沃伦·巴菲特/` 为 `NN-大师名/`（不复制 `work/`、`fonts/`、成片）。
2. 改 `src/shots.py`：重写分镜数据。
3. 改 `src/assets.py`：重写素材提示词，`python3 src/assets.py` 生成素材，拼一张缩略图总览检查风格统一、无正脸、无文字商标。
4. 改代码里写死的本集内容：

| 文件 | 位置 | 内容 |
|---|---|---|
| `render_v.py` | 文件头 docstring | 片名 |
| `render_v.py` | `header()` | 「投资大师列传 · 大师名」 |
| `render_v.py` | `title_frame()` | 片头大师名、主题 |
| `render_v.py` | `ERR = [c == "…错误清单" …]`、`trans_type()` | 错误清单章名 |
| `render_v.py` | `MAPS`、`fx_draw()`、`BREAKS`、`FALLBACK` | 本集地图、数据动画、手工断行、替补素材 |
| `music_r.py` | `CH_NAMES`、`DROPS`、`ENERGY` | 本集章名、大落点、能量 |
| `music_r.py` | 错误清单 / 落幕章名引用（`E0, E1`、印章、故障声） | 章名 |
| `music_r.py` | `SEGS`、`HITS_SRC`、`FINALE`、`LOGO_HIT` | 换曲或时长变化时重做 |

5. `python3 src/music_r.py`：看输出的章节起点、镜头时长范围和「明显短于阅读需要的镜头」，必要时调整字幕或 `SEGS`。
6. 关键画面出单帧检查：`TL=r python3 src/render_v.py still <镜头号> <秒> out.png`（或 `at <全片秒数>`）。
7. `./build_r.sh` 生成成片（约 40 分钟；后台跑，超时上限设 2 小时）。

### 12.2 交付前检查
- [ ] 抽帧网格（每 10 秒一帧）通看：版面不重叠、字幕不越界、无孤字成行
- [ ] 片头没有横线和系列名；底部没有说明文字；顶部不贴边
- [ ] 转场过程帧：章节冲击、重拍转场、推移、故障各抽 2–3 帧
- [ ] 关注语胶囊在预定时刻出现，最后一次带小字
- [ ] 片尾：粒子 → logo 在重拍浮现 → 金字 → 关注语 → 淡出；logo 背后没有方框
- [ ] 音频：`volumedetect` 平均约 −16 dB、峰值 ≤ −0.5 dB；各大落点前后响度跳升
- [ ] 事实核对清单逐条确认
- [ ] 成片走 LFS 提交并推送到本分支；README 记录素材来源、替补图、配乐和卡点参数

### 12.3 已知限制
- Gemini 按预付额度计费，额度用完会返回 402，素材和 Lyria 都无法生成，需要用户充值。
- 参照片配乐是单声道 48kbps，音质有限。
- 渲染时只能用响度数据和抽帧检查，节奏和音效的实际观感要请用户试听确认。
