## 音乐与卡点（`src/music_r.py`）

- 拼接 `SEGS = [(0, 143.37), (59.26, 171.93), (107.0, 213.2)]`。比第 04 集多一个乐句（第三段从 107.0s 的重拍开始，而不是 111.27s），给 11 章留足阅读时间。接缝两边都是重拍
- 各章起点由动态规划在重拍里整体挑选（短于阅读需要的惩罚 ×8）：序章 0 · 苦难少年 16.5 · 华尔街学徒 33.0 · 价值的发现 64.3 · 绝境重生 100.6 · 思想的巅峰 143.4 · 投资法则 179.8 · 格雷厄姆的错误清单 223.2 · 师徒传灯 250.3 · 落幕 292.4 · 尾声 321.0 · 片尾 341.3（logo 347.8，文字 350.6）
- 镜头 3.5–7.1 秒，平均约 4.7 秒；没有短于阅读需要 85% 的镜头
- 大落点 `DROPS`：价值的发现、思想的巅峰、师徒传灯、尾声
- 情绪递进：序章 900Hz → 苦难少年 3200Hz → 华尔街学徒从 5500Hz 打开 → 价值的发现全开 → 绝境重生从 2200Hz 先沉后扬 → 思想的巅峰、投资法则全开 → 错误清单 1500Hz、压低约 3 dB → 师徒传灯全开（大落点）→ 落幕从 1800Hz 慢慢打开 → 尾声全开
- 关注语：约 51.5s、203.3s，收尾 316.1s（带「更多投资大师 · 主页合集」）
- 音效函数从第 04 集的 `music_v.py` 抽到 `src/sfx.py`。本集不做 Lyria 版和横屏版

## 和脚本相比的调整

- 「今天 · 他的方法仍在课堂上讲授」从落幕移到尾声，放在数据对比之后，让两章的时长都贴近阅读需要

## 重新生成

```bash
./build_r.sh
```

依赖：ffmpeg、python3，以及 numpy、opencv-python-headless、pillow、soundfile、librosa、global-land-mask。字体由 `build_r.sh` 自动下载。

出单帧：

```bash
TL=r python3 src/render_v.py still <镜头号> <镜头内秒数> out.png
```

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/shots.py` | 分镜数据（唯一事实源），生成 `脚本.md` |
| `src/assets.py` | 画面素材提示词与 Gemini 生成 |
| `src/sfx.py` | 合成音效与时变低通 |
| `src/music_r.py` | 配乐延长、重拍卡点、情绪递进，输出 `work/bgm_r.wav`、`work/timeline_r.json` |
| `src/render_v.py` | 竖屏逐帧渲染：版式、地图、数据动画、转场、品牌角标、关注语、品牌片尾 |
