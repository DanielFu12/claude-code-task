# 04 · 沃伦·巴菲特：股神的复利人生

- 竖屏成片：`沃伦·巴菲特：股神的复利人生（竖屏）.mp4`（1080×1920 · 30fps · 约 4:54），配乐用参照片的曲子（用户已获使用授权），`./build_r.sh` 生成
- 竖屏 Lyria 原创配乐版：`./build_v.sh` 生成（输出文件名相同，会覆盖）
- 横屏成片：`沃伦·巴菲特：股神的复利人生.mp4`（1920×1080 · 30fps · 约 4:55），`./build.sh` 生成
- 脚本：`脚本.md`（由 `src/shots.py` 生成）
- 形式：参照编年体人物短片，没有旁白，靠音乐和字幕推进。字幕左下角是黄色大字年份（关键节点加年龄），下面是白色字幕，左边一根黄色竖条，关键词标红。
- 右上角全程挂「巴芒价值」品牌角标（`brand/`），片尾用大号 logo + 金色「巴芒价值」+「BUFFETT · MUNGER」。

## 素材

| 内容 | 来源 |
|---|---|
| 画面 `assets/*.jpg` | Gemini 生成的复古纪实风格示意图。不画真人正脸，不出现商标和可读文字。成片左下角标注「画面为 AI 生成示意 · 数据以公开资料为准」 |
| 地图 | 用 `global-land-mask` 的陆地数据实时画点阵地图，镜头俯冲后落下红色定位针 |
| 配乐 `assets/music/` | Lyria 生成的原创电子乐（117.45 BPM）。A 段是主曲；B 段是「暗色间奏 → 起势 → 高潮 → 收尾」，专门给「错误清单」和尾声用 |
| 数据动画 | 在 `src/render.py` 的 `fx_draw` 里逐帧绘制 |

Gemini 额度不足时，`ketchup`、`warehouse`、`house`、`crowd`、`podium` 这 5 张图暂时用已有素材顶替（见 `render.py` 的 `FALLBACK`）。额度恢复后运行 `python3 src/assets.py` 补齐，再重新 build。

## 音乐与剪辑

- A 段在第 244 拍跳回第 180 拍（正好 64 拍），从 2:58 延长到约 3:30。
- B 段 62.95 秒的高潮对准「尾声」第一个镜头（1965–2024 数据对比），所以 B 段在约 3:17 进入，正好赶在「错误清单」开始前，同时 A 段淡出。
- 每个镜头的起止时间都对齐到最近的节拍（`work/timeline.json`）。
- 章节重拍处（开场、1956、1972、2008、错误清单印章、尾声数据）硬切加闪白，其余镜头之间做 0.18 秒交叉淡化。

## 竖屏版

| 内容 | 做法 |
|---|---|
| 版式 | 顶部：系列名和当前章节名（右上角品牌角标）；中部：16:9 清晰画面带，背景为同一张图放大、模糊、压暗后铺满；下部：黄色大字年份和白色字幕。地图、数据图、纸卡按竖屏重新排版 |
| 配乐编排 `src/music_v.py` | 每章开头钉在小节第一拍。章内镜头按比例伸缩，切点对齐到节拍。大落点（少年生意经、合伙基金时代、从烟蒂到伟大企业、尾声）前先上升音效、留一拍空白，再砸下冲击。序章和少年时代用低通滤波让音乐发闷，拜师后逐渐打开，1956 年完全打开。错误清单切到 B 段的暗色间奏，配印章闷响和故障声 |
| 卡点 | 章节开头闪白、放大回弹、抖动，中央显示章节名；普通切镜纵向推移加运动模糊，配呼啸声；错误清单用故障转场；序章、落幕柔和淡化。年份大字随切镜弹出，字幕晚半拍出现；能量高的章节在强拍上画面轻微脉冲；尾声加暖色漏光 |
| 片尾 logo 动画 | 全片画面拼成马赛克闪现 → 碎裂成粒子旋入、汇聚成官方 logo → logo 在重拍上清晰浮现（冲击波、光芒、冲击音）→ 下一个重拍砸出金色「巴芒价值」和「BUFFETT · MUNGER」，流光扫过两次 → 整体淡出 |

参照片配乐（约 85 BPM，每 4 小节一次能量爆发）只用作节奏参考，没有使用它的音频。所有音效都在 `music_v.py` 里用代码合成。

## 竖屏版 · 参照片配乐（当前成片）

`src/music_r.py`：
- 原曲 `assets/music/ref_bgm.m4a` 取自参照片音轨（单声道 AAC 48kbps，3:33，约 84.7 BPM），用户已获使用授权。
- 延长：在 143.37s 的重拍处接回 59.26s 的重拍，全曲约 4:54。
- 卡点：九个章节的开头都钉在曲子的重拍上；章内其余重拍就近吸附到切镜点（31 个），这些切镜用「重拍转场」（快速闪白、放大回弹、轻微抖动，配轻冲击音）；其余切点对齐到逐拍追踪的拍点。
- 情绪递进：序章发闷 → 少年时代偏暖 → 拜师逐渐打开 → 1956 年完全打开；错误清单压暗收窄、整体低 3 dB → 落幕慢慢打开 → 尾声全开。大落点前上升音效 + 半拍空白。
- 片尾：粒子汇聚从 276.41s 的重拍开始，logo 在最后一个大重拍（282.87s）浮现，4 拍后金色文字随冲击和闪光音效出现，随尾奏淡出。

## 重新生成

```bash
./build.sh
```

依赖：ffmpeg、python3，以及 numpy、opencv-python-headless、pillow、soundfile、librosa、global-land-mask。

调画面时可以先出单帧：

```bash
python3 src/render.py still <镜头号> <镜头内秒数> out.png
```

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/shots.py` | 分镜数据（年份、字幕、画面类型、素材、动画），也负责生成 `脚本.md` |
| `src/assets.py` | 画面素材的提示词和生成脚本 |
| `src/music.py` | 拼接配乐，把镜头对齐到节拍 |
| `src/render.py` | 横屏逐帧渲染：字幕、纸卡、点阵地图、数据动画、印章、片头片尾、品牌角标 |
| `src/music_v.py` | 竖屏版配乐编排：章节对齐小节、合成音效、滤波递进、drop gap |
| `src/music_r.py` | 竖屏版配乐（参照片曲子）：延长、重拍卡点、情绪递进 |
| `src/render_v.py` | 竖屏逐帧渲染：竖屏版式、卡点转场、章节标题、片尾 logo 粒子动画；`TL=r` 时读参照片配乐的时间线 |
