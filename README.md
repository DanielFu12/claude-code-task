# 进化心理学：你大脑的“出厂设置”

一部约 12 分钟的中文科普视频，用通俗的语言和动画介绍进化心理学。

## 内容结构

1. **开场钩子**：为什么你怕蛇、怕蜘蛛，却不怕汽车和插座？为什么忍不住奶茶炸鸡、爱听八卦、消息没人回就焦虑？
   答案：你的大脑是一台“石器时代出厂”的机器。
2. **什么是进化心理学**：达尔文的自然选择与他的预言；核心观点——大脑也是被自然选择塑造的器官。
3. **四把钥匙**：时间错配（30 万年压缩成一天）、烟雾报警器原理、近因与终极原因、“如果……那么……”的规则（老茧的例子）。
4. **生活里的进化痕迹**：儿童找蛇实验与猴子恐惧学习、沃森选择任务互动小测试与“骗子侦测器”、八卦与邓巴数、社交排斥与“心痛”、亲缘选择与霍尔丹的玩笑、互惠利他、择偶研究（37 种文化）。
5. **三个误区**：自然主义谬误、基因决定论、“原来如此的故事”与可重复性争议。
6. **四个能用上的建议**：识别焦虑误报、改环境而非拼意志、对社交媒体保持清醒、给大脑“熟悉”的生活方式。
7. **总结与参考资料**。

## 如何重新生成

视频完全由代码生成：旁白用离线神经网络语音合成（sherpa-onnx + Kokoro 中文模型），画面用 Pillow 逐帧绘制，最后用 ffmpeg 合成。

```bash
pip install sherpa-onnx soundfile numpy pillow cairosvg
bash src/fetch_assets.sh        # 下载字体与语音模型到 assets/（约 400MB）
cd src
python3 build_audio.py          # 合成旁白、背景音乐，生成时间轴与字幕
python3 render.py --preview 5,60,120   # （可选）导出几帧预览图到 build/preview/
python3 render.py               # 渲染并合成成片
python3 make_script.py          # 生成带时间码的文案
```

- 修改文案或画面：编辑 `src/content.py`（每个场景的旁白与画面元素都在这里）。
- 换声音：修改 `src/build_audio.py` 中的 `VOICE_ID`（Kokoro v1.1 中文女声约 3–57，男声约 58–102）和 `SPEED`。
