# M04《产品越来越像，竞争会走向哪里？》· 竞争排斥原理（竖屏版）

《50个自然法则，看懂商业世界》第 04 期。本期话题：**资源重叠 / 同质化 / 竞争条件**。

- 成片：`M04_产品越来越像竞争会走向哪里_竞争排斥原理_竖屏.mp4`（**1080×1920 竖屏** · 30fps · 3:18 · 约 91 MB · 无人声，字幕叙事）
- 竖屏大字，延续 M03 的手机观看布局：
  - 字幕 56–62 px，大字 72–100 px。
  - 画面主体放在上中部（约 y 230–1120），字幕在中下部（约 y 1250）。底部约 25% 和右侧留空，避开视频号和抖音的按钮、文案区。
  - 章节标签在左上角，进度线在它下方。右上角是 `brand.Hud(frame_w=1080)` 画的官方角标（BRAND.md 边距 52/30）。
- 视觉：
  - 两个对手全片统一用霓虹青（A）和品红（B），分化与结论用品牌金。
  - 与 M03 相同的炫光层：霓虹透视地面每拍滚动一格，加上极光丝带、顶部光束和景深光斑。每小节重拍荡开一圈金色光环，重拍时有横向镜头光，镜头会缓慢推拉，最后统一调色。
- 配乐与音效全部为原创合成（`src/music.py`），没有外部采样：
  - 配乐：120 BPM、G 小调。和声走 i–VI–III–VII（Gm–Eb–Bb–F），抽空段改走 iv–VI–III–V。**1 拍 = 0.5 s = 正好 15 帧**，每个拍点和转场都落在整数帧上。
  - 转场音效只用 sub drop、低频 boom、低沉膨胀和闷击。全部经过 4 阶 180 Hz 低通，实测 **99.996% 的能量在 200 Hz 以下**。不用白噪声、whoosh 或尖锐的上升音。
  - 每个音效都按所在位置的音乐响度自动压低，实测比音乐低 6–8 dB，起音对准转场那一帧。
  - 混音：整片约 −13.7 LUFS，峰值 −1 dBFS。

## 事实、出处与制作约束

| 内容 | 出处 / 处理方式 |
|---|---|
| 竞争排斥原理：对同一限制资源的完全竞争，在稳定条件下难以持续共存；资源分化可改变结局 | 素材《01 竞争排斥原理事实核查》“本片采用的机制” |
| 高斯（G. F. Gause）草履虫实验：两种草履虫单独培养都能生长，混合培养时一种被排除；改变环境条件可让两者共存 | 素材核查卡（OpenStax Biology 2e §45.6 教学案例）；G. F. Gause, *The Struggle for Existence*, 1934 |
| 草履虫种群曲线 | 核查卡要求“注明教材示意而非新实验”：画面标注“教材示意 · 非实测数据”，曲线只表现走势，没有数值 |
| 主要限制：异质环境、时间波动、迁移可促进共存；不能推断所有同质产品必然价格战 | 素材核查卡“主要限制”，即抽空段的两个提醒 |
| 咖啡店 | **假设情景**。核查卡写明航空同航线、共享单车仍是待核案例，公司故事必须先补原始公告、口径、时间线和因果证据，不足时改用标注“假设”的教学情景 |
| 检查表的四个维度 | 核查卡“应用”：对照客户选择维度、成本、空间与容量条件 |
| 巴菲特、芒格引语 / 企业财务数字 | 核查卡写明“本卡不使用”，本片遵守 |

结尾按投资研究视角落到研究问题（和对手争的是不是同一批客户、客户靠什么选它），不给买卖建议。
