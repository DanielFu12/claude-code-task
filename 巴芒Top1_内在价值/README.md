# 内在价值：没有把握，就不知道它值多少 · 巴芒精华库 Top 1 竖屏短片

- 成片：`内在价值_巴芒Top1_1080x1920.mp4`（9:16 竖屏，1080×1920，30fps，约 4 分 21 秒，H.264 + AAC）
- 预览版：`内在价值_巴芒Top1_预览版.mp4`（同分辨率，压到 30MB 以内）
- 字幕文件：`字幕_中英.srt`（与画面字幕同一时间轴；画面里的中英字幕已经烧录）
- 内容来源：`巴芒股东大会数据库/` 的 Top 100 第 1 名，即条目 **1994-A22**（1994 年股东大会下午场第 22 章「Calculating intrinsic value」，巴菲特讲如何计算内在价值）。

## 声音与画面的来源

- **巴菲特原声**：1994 年伯克希尔股东大会下午场的原始录音，包括股东提问和巴菲特约 3 分钟的完整回答，不剪不改。
  - 取自 archive.org 收录的全场录像 `youtube-A2J-_BNkqm8`（3:31:28）的 3:17:26–3:20:55，即下午场开场后约 45:39–49:08。
  - `src/fetch.py` 按区间只读取这 280 秒的音频，不下载整片。
  - 处理只有三步：合成单声道（原录音两声道几乎相同）、去掉 70Hz 以下的低频隆隆声、统一响度。
- **没有现场画面**：CNBC 巴菲特档案里，1994 年下午场本来就只存音频；archive.org 这份在这一段也只是"Audio Only"卡片。所以原声段落的画面是按原话逐句卡点的动态图形，配上实时的原声波形。画面顶部全程标注"1994 年原始录音 · 本场仅存音频，无现场画面"。
- **为什么不直接用 CNBC 和 YouTube**：
  - `buffett.cnbc.com` 的 Akamai 防护会拒绝数据中心 IP（返回 403）。
  - YouTube 对数据中心 IP 要求登录做人机验证。
  - archive.org 可以正常访问。
- **英文字幕**：
  - 文字逐字取自 CNBC 逐字稿 1994-A22，只省略口头重起的半句（如 "Well, the —" 里的 "the —"）。
  - 时间来自 faster-whisper（medium.en）的逐词时间戳：把逐字稿和识别结果做序列匹配，99% 的单词能对上，其余按前后词插值。
  - 识别结果只用来定时间，不用作字幕文字。
- **中文字幕**：本片翻译。
- **投资启示**：原声之后的中文解说为本片撰写，用 AI 配音，画面标注"解说为 AI 配音"。
  - 配音模型是 sherpa-onnx 的 Kokoro v1.1-zh，音色 `zm_015`，语速 0.9。
  - 选这个音色的办法：45 个中文男声全部合成一遍，用语音识别检查发音，再比较音高（越低越沉稳）、语调起伏（3–4.5 个半音为宜）和语速（每秒约 3.5 字），取最接近纪录片解说的一个。
  - 句间停顿 0.3–0.85 秒。

**音乐**：取自仓库根目录 `opus5.5涌现.mp4`（约 112 BPM）。
- **片头**：从 0 秒播放原曲，原声开始前淡出。原始录音期间不垫音乐。
- **投资启示**：原曲从重拍（17.09 秒，按能量突变精确定位）前 1.5 秒淡入，重拍正好落在投资启示开始处。
- **跳回**：解说快结束时，在同一小节相位的节拍上无缝跳回原曲 8.6 秒，于是"抽空 → 上扬 → 重拍"再走一遍，重拍落在片尾文字出现的那一刻。
- **混音**：解说时音乐压低 14dB。原声和解说的有声部分统一到同一响度，最后整体归一到 -16 LUFS。

## 品牌（按 `CLAUDE.md` 和 `brand/BRAND.md`）

- **右上角角标**：全程用 `brand.Hud`（`Hud(scale=1.0, frame_w=1080)`）逐帧合成。
  - logo 约 60px，带淡蓝光晕，配金色「巴芒价值」+「BUFFETT · MUNGER」，流光每 7.5 秒一次。
  - 片尾也保留，只在整片最终淡出时和画面一起消失。
- **片尾 logo**：只用 `brand/logo_baman.png`，经 `brand.load_logo(240)` 读取并做预乘 alpha 缩放；光晕颜色、σ、强度按 `SPEC` 等比放大。
  - 粒子汇聚只把 logo 的 alpha 通道当作目标形状，粒子颜色取自 logo 原图对应像素。
  - 粒子到位后淡出，最终显示的是原始 logo。
- **片尾文字**：直接取自 `brand/hud_lockup@4x.png` 的文字区（按 `hud_layout.json` 的 `text_box` 裁切），是官方预渲染的品牌金色渐变，没有重新排字。流光时长取 `SPEC['shimmer_dur']`（1.4 秒）。
- **其余配色与字体**：画面里的金色、蓝色取自 `brand.py` 的 `GOLD_STOPS`、`SUB_GOLD`、`SPEC['glow_rgb']`；标题用品牌字体 Noto Serif SC Black（由 `brand.py` 下载到 `brand/fonts/`）。
- **片尾参考**：用户提到的 `love_video/render.py` 在仓库和 git 历史里都不存在，片尾做法参考了 `不开心视频/src/video.py`。

## 重新生成

```bash
./build.sh   # 需要 ffmpeg、python3：numpy opencv-python-headless pillow soundfile librosa scipy sherpa-onnx faster-whisper
```

**网络**：需要访问 archive.org、GitHub release（Kokoro 模型约 330MB）、Hugging Face（faster-whisper 模型）和 Google Fonts。已下载过模型时，可用 `KOKORO_DIR=/path/to/kokoro-multi-lang-v1_1 ./build.sh` 跳过下载。

**单帧检查**：`cd src && python3 render.py stills OUT_DIR 20 60 250 ../work`。
