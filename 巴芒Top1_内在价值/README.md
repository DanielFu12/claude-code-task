# 内在价值：没有把握，就不知道它值多少 · 巴芒精华库 Top 1 竖屏短片

- 成片：`内在价值_巴芒Top1_1080x1920.mp4`（9:16 竖屏，1080×1920，30fps，约 2 分 02 秒，H.264 + AAC）
- 预览版：`内在价值_巴芒Top1_预览版.mp4`（同分辨率，压到 30MB 以内）
- 字幕文件：`字幕_中英.srt`（与画面字幕同一时间轴；画面里的中英字幕已经烧录）
- 内容来源：`巴芒股东大会数据库/` 的 Top 100 第 1 名，即条目 **1994-A22**（1994 年股东大会下午场第 22 章「Calculating intrinsic value」，巴菲特讲如何计算内在价值）。

## 重要说明：为什么没有用会议原视频

“剪辑 #1 的视频”最理想的做法是直接剪 CNBC 巴菲特档案里的原片。本次运行环境的网络策略屏蔽了 `buffett.cnbc.com`、YouTube、archive.org、Bilibili 等所有视频站（代理返回 403），**拿不到原始画面和巴菲特本人的声音**。所以本片改为：

- 画面：按原话内容逐句设计的动态图形（折现柱状图、预测区间、天平、财务报表、估值四问、决策流程）。
- 英文原话：逐字取自 CNBC 逐字稿 1994-A22（只把句首的 But 去掉、句首字母改成大写），用 AI 配音朗读（Kokoro 英文男声）。**画面上全程标注“AI 配音朗读，非巴菲特本人原声”**，不冒充本人。
- 中文旁白（开场、提问、投资启示）为本片撰写，同样是 AI 配音（Kokoro 中文男声）。
- 中文字幕里的原话翻译、英文字幕里的旁白翻译，均为本片翻译。
- 原片位置写在画面底部：CNBC 巴菲特档案 · 1994 年股东大会下午场 · 第 22 章，约 0:59:09–1:01:27（按逐字稿词数估算，不是精确时间码）。原片地址：
  https://buffett.cnbc.com/video/1994/04/25/afternoon-session---1994-berkshire-hathaway-annual-meeting.html?amp=&start=3489&amp=&end=3747

网络放行后，可以把这段原片下载下来，用 `work/timeline.json` 里的分句和中英文本直接替换配音和图形（字幕时间需按原声重新对齐）。

背景音乐取自仓库根目录 `opus5.5涌现.mp4`（约 112 BPM）。从 0 秒开始播放原曲，原曲第一个重拍（17.09 秒，按能量突变精确定位）正好是巴菲特原话开始的地方。旁白快结束时（1:48.5），在同一小节相位的节拍上无缝跳回原曲 8.6 秒（鼓点抽空的前一小节），于是“抽空 → 上扬 → 重拍”再走一遍，重拍（1:56.98）落在片尾文字出现的那一刻。有人声时音乐自动压低 15dB，最后整体响度归一到 -16 LUFS。

## 品牌（按 `CLAUDE.md` 和 `brand/BRAND.md`）

- 右上角全程用 `brand.Hud`（`Hud(scale=1.0, frame_w=1080)`）逐帧合成：logo 约 60px，带淡蓝光晕，配金色「巴芒价值」+「BUFFETT · MUNGER」，流光每 7.5 秒一次。片尾也保留，只在整片最终淡出时和画面一起消失。
- 片尾 logo 只用 `brand/logo_baman.png`（经 `brand.load_logo(240)` 读取，预乘 alpha 缩放），光晕颜色、σ、强度按 `SPEC` 等比放大。粒子汇聚只把 logo 的 alpha 通道当作目标形状，粒子颜色取自 logo 原图对应像素；粒子到位后淡出，最终显示的是原始 logo。
- 片尾文字直接取自 `brand/hud_lockup@4x.png` 的文字区（按 `hud_layout.json` 的 `text_box` 裁切），是官方预渲染的品牌金色渐变，没有重新排字。流光时长取 `SPEC['shimmer_dur']`（1.4 秒）。
- 画面里其余的金色、蓝色取自 `brand.py` 的 `GOLD_STOPS`、`SUB_GOLD`、`SPEC['glow_rgb']`；标题字体用品牌字体 Noto Serif SC Black（`brand.py` 下载到 `brand/fonts/`）。
- 用户提到的参考文件 `love_video/render.py` **在仓库和 git 历史里都不存在**。片尾做法参考了仓库里现有的 `不开心视频/src/video.py` 片尾，并按本次要求改为“粒子汇聚 → logo → 重拍出字 → 流光 → 淡出”。

## 重新生成

```bash
./build.sh     # 需要 ffmpeg、python3：numpy opencv-python-headless pillow soundfile librosa sherpa-onnx
```

首次运行会从 GitHub 下载 Kokoro 模型（约 330MB）和字体；已下载过模型时可用 `KOKORO_DIR=/path/to/kokoro-multi-lang-v1_0 ./build.sh` 跳过下载。单帧检查：`cd src && python3 render.py stills OUT_DIR 20 60 118.5 ../work`。
